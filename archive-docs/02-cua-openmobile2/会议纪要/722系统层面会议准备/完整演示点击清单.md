## 2. 多数据 + 任务可验证（2–3 分钟）★

### 2A 注入空车（多数据）

控制台或脚本：

```js
await __SIM__.setState({ apps: { taobao: { cart: [] } } })
```

或：

```bash
python -m bench_env.scenarios.smoke_test --scenario taobao/empty_cart
```

打开购物车 → **空态**（中文「购物车还是空的」/ 英文 Cart empty）。

### 2B store 真变

1. 进任意商品 → **加入购物车**  
2. 再读 `getState().apps.taobao.cart.length` → 从 0 变 1  
3. 口述：前端假高亮骗不过 getState；任务 `AddItemToEmptyCart` 判的就是这个

### 2C 咔皮任务判定

```js
await __SIM__.setState({ apps: { kapi: { bills: [/* reimburse_mix 两笔，或直接跑任务 prepare */] } } })
```

更稳：跑任务 `ToggleReimburse` / 手点报销开关 → `bills[].reimburse` 翻转。

示范任务 id：

| suite | task |
|---|---|
| taobao | `AddItemToEmptyCart`、`PayOrderWithAlipay`、`AddItemToCart` |
| kapi | `ToggleReimburse`、`AddExpenseBill` |

## 5. 共享数据（1 分钟）★

### 剪贴板

1. 淘宝购物车 → 分享 → **复制链接** → toast「已复制」  
2. 任意输入框长按粘贴 / 或读 `__OS__.clipboard.getText()`

### ContentResolver（咔皮）

1. 咔皮首页 → 分享页  
2. 海报下方可见：**系统相册共 N 张（ContentResolver）**  
3. 证明业务 app 能读系统媒体库，不只关在自己 store

---

## 6. 跨 app（2–3 分钟）★

### 6A 淘宝 → 支付宝支付（ForResult）

1. 购物车勾选 → 结算 → 确认订单  
2. 支付方式保持 **支付宝** → 立即支付  
3. 应拉起 **支付宝收银台** → 完成支付  
4. 回淘宝成功页；`orders` 中新单 `payMethod==='支付宝'` 且已付  
5. 任务口径：`PayOrderWithAlipay`（含 exclude：未误开微信订阅）

### 6B 分享到微信

- **淘宝**：购物车分享 → **微信** → `ACTION_SEND` 拉起微信  
- **咔皮**：分享页 → **发到微信** → 同样 `ACTION_SEND`

### 6C（口头对照）

老路径 12306→支付宝：框架早已有；本轮是在 **新复刻 app** 落地。
