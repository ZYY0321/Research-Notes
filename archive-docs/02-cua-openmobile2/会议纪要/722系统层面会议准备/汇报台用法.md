# 汇报台用法

地址：**http://localhost:3000/?deck=1**

## 必看条目（本轮按真实交付改过）

1. **多套真实数据**：场景 A 活跃 88VIP ↔ 场景 B 新号空态 — 打开首页 +「我的」对比（不是只看购物车）
2. **任务级验证**：准备单件待结账 → 右侧完整结算支付 → 跑结算判定（新已付订单 + 购物车条目移除）
3. **共享数据**：咔皮保存图片 → 打开系统相册应能看见
4. **微信分享**：发到微信 → 选人 → 确认发送 → 进入会话
5. **后续安排**：职责/成本总表；文档见 `后续安排.md`

## 字号

用 A− / 标准 / A+，不要浏览器整页缩放。
