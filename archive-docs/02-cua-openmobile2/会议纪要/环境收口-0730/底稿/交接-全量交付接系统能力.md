## 0. 目标与边界

**目标：** 自建业务 App **有入口就真接** MobileGym 系统能力，能用来 roll 轨迹（主链路写 Store、跨 App/相册真通道）。


| 做                                  | 不做（除非改口径）           |
| ---------------------------------- | ------------------- |
| 支付 / 分享 / **相册** / 剪贴板 / 主链路 Store | 全库英文化、全页深色抠色        |
| 有入口 → 真调 API；假 toast 清掉            | 全库多套场景 JSON         |
| 底盘冒烟 + 通道实跑                        | GUI+Tools / 生产力 App |
| 修挡 roll 的环境洞（如 openApp 映射）         | 无入口硬造能力；无关大重构       |


**两层：**


| 层        | 内容                                                                                              | 全量交付时                   |
| -------- | ----------------------------------------------------------------------------------------------- | ----------------------- |
| A 平台     | TimeService、getState/reset/隔离、剪贴板、轨迹、locale/深色开关、Intent、ContentResolver/MediaService、场景接口、Judge | 一般不重写；坏了修；跑 showcase 冒烟 |
| B App 接入 | 按钮是否真调 A；主链路是否写 Store                                                                           | **主战场**                 |


示范抄：支付淘宝/瑞幸；分享咔皮；相册 `os/albumBridge.ts` + 咔皮 SharePage。
