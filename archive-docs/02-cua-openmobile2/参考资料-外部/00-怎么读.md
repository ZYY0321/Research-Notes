3. **Hybrid**：试验床 / plus，不合成总分。见 `5-写作讨论/56-…口径.md`、`06-Hybrid指标对齐.md`。
4. **任务设计**：先 `67` 原则，再 `60` 管线，再 `69/70/71/72`。
