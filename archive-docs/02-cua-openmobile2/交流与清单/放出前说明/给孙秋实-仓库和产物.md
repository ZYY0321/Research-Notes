## 打开手机

线上可点的手机：`https://mobilegym-mock-production.up.railway.app`

代码在私有仓库 `https://github.com/ZYY0321/mobilegym-mock`，分支 `codex/env-tooluse-integration`。这个分支才是约 50 个应用都在的那份。不要用别的分支做网站演示。

克隆之后：

```bash
git clone git@github.com:ZYY0321/mobilegym-mock.git
cd mobilegym-mock
git checkout codex/env-tooluse-integration
cd trial_apps/mobilegym
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

壁纸、铃声、部分应用图片不在 git 里。要么下载数据包（约 1.4 GB）：

```bash
curl -L -o mobilegym-data.tar.gz \
  https://github.com/Purewhiter/mobilegym/releases/download/data-v1.0/mobilegym-data-v1.tar.gz
tar -xzf mobilegym-data.tar.gz
```

解压后的目录按 `trial_apps/mobilegym/docs/getting-started.md` 里的说明放到模拟器能读到 `/cdn/` 的位置。要么构建时加上：

```bash
VITE_CDN_BASE=https://cdn.mobilegym.dev npm run build
```

线上那次部署已经把首页壁纸指到 `https://cdn.mobilegym.dev`。本地 `npm run dev` 如果不下数据包，壁纸会空。

评测再跑一道题：还是在 `trial_apps/mobilegym` 里，看 `docs/getting-started.md` 的 Quick path。需要 Python 3.11、`pip install -r bench_env/requirements.txt`、`playwright install chromium`。没有模型 key 也能打开手机；跑 agent 才要一个 OpenAI 兼容接口。不要把 `.env` 或 key 放进网站仓库。
