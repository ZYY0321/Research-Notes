2026-08-31。来源：你转的写作用法（11:51）+ 瞰之 abs 开门见山 + 秋实标题不要只压 Hybrid。

## 0. 用法（abs / intro / 这章开篇都按这个）

1. **组织**自己定，或和人讨论。4.6 不代定结构。
2. 每句先写「我要别人读完这句话之后相信什么」。这句意图是作者的。
3. 再把意图 + 硬约束（不能说的数字）交给 4.6 **只改措辞**。同一句可以改很多遍。
4. **禁止**：让 4.6 写一整段逻辑、自己补贡献、自己排重要性。

abs+intro 尤其如此。正文机制、代码、表可以后放。

## 1. 别人第一眼要留下什么（整篇，不是环境章细节）

读完 abs 前四句，审稿人应能复述：

> OpenMobile-2 是一套**开源**的手机 agent 栈。底座不是真机，是**可重置的 mock 商业 App 世界**：同一初态、跨 App、成败看业务 store 写没写上。上面才有开源训练数据和「GUI 与 App 工具可混用」的试验能力。

「很重要」落在这里，不落在 Hybrid 涨了几分、也不落在 120+：

- 真机 bench 皮肤真，但携程/京东/BOSS **重置不了**，也很难判「事办完没有」。
- 上一版 MobileGym 已经能 reset、能读 JSON，但商业复刻和真跨 App 不够。
- 我们把这件事做成别人能训、能评、能只跑 GUI 的 playground。Tool 是同一世界的能力，不是这张 Bench 存在的理由。

「很 nb」能撑住的只有这组：**可重置 + 可验终态 + 商业 App + 同一世界可跨 App**。  
撑不住的：比真机更真、120+ 已锁、369 SR、Bench 为 Hybrid 而建。

## 4. 你自己这章开篇：第一眼，不是先倒 census

现在初稿第一段其实已经接近第一眼。问题是第二段立刻进 64 分队，读者还没觉得重要就被数字淹没。

**开篇三段只做这件事，数字和四件套往后放：**

| 段 | 要表达什么 | 现在初稿 |
|---|---|---|
| E1 | 这是 mock 商业世界，不是真账号；我们问的是 store 上事办完没有。 | 已有，保留。 |
