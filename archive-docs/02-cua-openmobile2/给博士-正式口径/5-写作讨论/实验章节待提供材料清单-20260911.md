# 实验章节待提供材料清单（供后续写作）

环境与 Bench 章节先固定方法和任务定义；实验章节需要补的是同一版本下的可复核结果。后续按下面顺序提供即可：

1. **实验设置**：模型名称与版本、GUI-only/Hybrid 的运行策略、最大步数、并发数、随机种子、重复次数、运行日期和环境版本。
2. **任务与分组**：最终任务总数，以及单 App、跨 App、信使和七个领域的分组；若任务筛选仍在变化，先给当前运行批次对应的任务清单。
3. **主结果**：每个模型和通道的成功数、总数、成功率；最好同时给逐任务结果，便于核对分母和异常项。
4. **效率与失败**：成功轨迹平均步数、全轨迹含步数上限的平均步数、达到上限比例，以及失败类型或失败轨迹样例。
5. **工具分析**：工具调用任务数、调用总数、调用成功率（若有可靠判定）、工具介入前后的成功率和步数；区分“使用过工具”和“工具调用本身成功”。
6. **对照与消融**：GUI-only 与 Hybrid 的配对结果；如有 mock/emulator、长链/跨 App 或工具开关对照，提供相同任务和初态下的结果。
7. **定性洞察**：代表性成功/失败轨迹、跨 App 信息传递案例、工具解决或未解决的 UI 死结案例，以及这些案例对应的任务 ID。

步数建议在论文中写成：成功轨迹平均步数刻画完成条件下的交互效率；成功率刻画可靠性；全轨迹均值或达到上限比例作为辅助，避免把两种性质混成一个数字。
