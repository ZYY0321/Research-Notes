# App 复刻阶段性反馈

这轮走查发现，问题主要集中在页面还原、交互链路和数据联动。请大家重新完整体验自己负责的 App，不要只检查“按钮能不能点”。

自查重点：

1. **按真实 App 还原**：不要参考同类 App 自行增加按钮或流程；没有证据的功能宁可移除，不要让 AI 猜。
2. **完整走通主链路**：每个 App 至少测试一条“搜索/筛选 → 详情 → 操作 → 返回首页”的高频流程。
3. **检查真实数据变化**：Tab、筛选、日周月切换不能只变高亮；不同搜索词不能返回相同结果。
4. **检查状态联动**：评论、转发、删除历史、设置修改后，相关页面和计数都要同步，重新进入不能恢复成硬编码数据。
5. **检查导航和返回**：不能跳错页面、循环返回、进入后无法退出。
6. **检查视觉和数据**：不要用 Emoji 代替正式图标；修复图文重叠、空白遮罩；长期记录类 App 要有跨日期、多分类数据。

典型问题（这轮实际发现的，供大家对照自查）：

- **Flomo**：点标签后没有正确链路返回主页；点“三个点”展开后背景变空白；点头像没跳到正确页面。这类交互流断裂比较严重。
- **唯品会**：部分页面导航/返回错误；功能太简单、少了很多主业务 Tab、页面不还原；出现真实页面没有的按钮（如购物车“去凑单”）——怀疑是参考淘宝做的，请务必按真实唯品会页面还原。
- **拼多多**：部分页面交互按键有问题，请按真实购物链路重走一遍。
- **Boss 直聘**：整体还原不错，但数据有问题：切到“算法工程师”筛不出任何数据；工资区间除“全部”外，选任何一档都筛不出条目（很严重，很多任务都要靠筛选）；兼职页用了 Emoji 图标且 Tab 切不动。做的时候至少要模拟一条完整常用交互跑通，不能只点按钮看有没有反应。
- **喜马拉雅**：搜索任何字段结果都一样、搜索栏还会被自动重置（很严重，很多任务靠 agent 搜索）；搜索历史是固定的，删除后返回又出现；返回按钮要点很多次循环才能回主页；选音质无论选啥页面都显示“高清音质”（但选择确实被记录了）；点“三个点/更多”往下滑会自动跳回顶部；互动消息跳转错误。
- **豆瓣**：整体做得不错、也还原，核心功能都有；但评论并转发帖子后，个人主页动态不展示、个人主页数据好像不更新（首页却显示了评论）；顶部一些图标还用 Emoji，有图片和文字重叠。
- **百词斩**：主要功能基本可以，但页面太不还原；有一个 Tab 所有功能都没实现（这种可考虑直接不做这个页面）；商城生成了一些图，但商品详情页很多 Tab 点了不切换。
- **番茄 ToDo**：统计数据切日/周/月没有任何变化；数据太少（构建时只截了某一天，导致全 App 只有一天数据）；有一页统计几乎点所有按键都没效果，时间轴 Tab 功能基本没开放；一些小图标用了彩色 Emoji。
- **美柚**：数据问题，评论回复显示 0 条。
- **微博**：设置里比较重要的隐私设置、屏蔽设置、通用设置一个都没做——这类好做且常用的设置该补上。
- **微信读书**：页面太不还原，很多按键根本没法点。

共性提醒：记账、任务这类长期记录 App 数据不能只有一天；数据要统一管起来，不能硬编码。请优先修复导航/返回、搜索筛选、状态联动和核心链路。暂时不做的入口请**移除或明确提示**，不要保留无响应空壳。
