| 本地目录 | 固定职责 | 默认允许修改 |

| `D:\OpenMobileV2` | 主工程、集成与项目管理工作区 | OS/系统层、公共组件、公共工具、正式流程规范、路线图、团队合并后的验收 |
| `D:\mobilegym-mock` | 单 App 复刻工作区 | 只关注当前目标 App 的 `trial_apps/mobilegym/apps/<App>/` 和 `docs/<app>-replication/`；主线带下来的其他 App 不属于本工作区的维护范围 |

默认约束：

- 两边的 `main` 都不直接开发。`D:\OpenMobileV2\main` 需要持续同步远端；`D:\mobilegym-mock\main` 不要求每次开工都同步，只在需要最新公共框架、准备变基或提交 PR 时同步。

- `D:\mobilegym-mock` 中其他同学的 App 即使随主线存在，也不主动检查、修改或维护；不得为了精简目录而删除这些受 Git 跟踪的内容。
- App 过程中发现公共问题时，先单独记录；需要修改公共代码时，转到 `D:\OpenMobileV2` 建系统/工具分支处理。
- 原始会议笔记、个人排障材料保留在本目录，不上传；形成团队共识后再提炼到正式 `docs/` 文档并走 PR。
