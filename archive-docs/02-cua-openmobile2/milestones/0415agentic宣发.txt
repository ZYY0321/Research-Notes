  - 周报整理与审核

- 模型宣发计划调整
  - 原计划推迟
    - Openworld 延迟：卢乐炜指出原 Openworld 规划预计十几号上线，但目前会延迟，计划调整为下周按原定排期独立宣发模型。
    - 宣发目标：宣发目标是在一些知名的靠 ranking 的榜单上冲 leader 榜第一，至少是前三，同时强调办公相关能力，如数分和 PPT 展示。
  - 新计划补充
    - 上海比赛：张行程提到 5 月中上海有个比赛，几家模型厂商提供 API，公司将提供 3.7B 模型及 API 供参赛队伍使用。
    - calling plan 推进：徐立一直打算推动 calling plan，原计划 10 号上 open Router，因进展不符合预期，改为商汤自己上模型，需讨论模型宣传点。
- PPT 生成能力优化
  - PPT 核心优势
    - 单页效果突出：王博表示 PPT 目前主要分单页效果和整体效果，单页效果方面，在量级或成本下，公司模型生成的单页 PPT 视觉效果最好。
    - 模型核心作用：张行程询问做 PPT 的核心是 agent 模型还是 Neo 模型，卢乐炜解释是 HTML 形式的 PPT，两个功能都会上小浣熊，核心优势在 12B 或 3.7B 模型，具备较好的排版和审美生成能力。
  - HTML 转 PPTX 问题解决
    - 现有方案及问题：目前模型直接输出的是 HTML 代码，没有直接输出 PPTX 的功能，王博尝试调用小浣熊 API 和自己编写脚本进行转换，但都存在一些 feature 未覆盖的问题，有一定损失。
    - 新方案探索：张行程提出可尝试用 Openclaw Claude 4.6 生成数据，构造数据管线，将数据蒸馏到公司模型，让模型具备调用工具的能力，王博表示先按此思路尝试。
- 数据分析能力提升
  - 数据分析优势挖掘
    - 场景与能力探索：张行程认为数据分析要突出优势场景和能力，如能处理多个 Excel 文件的交叉互锁逻辑、处理大文件、对 Excel 进行精准编辑等，洪嘉伟表示需要进行测试寻找。
    - 与 PPT 结合：张行程提出数据分析能否与 PPT 结合，如根据报表生成年报、财报 PPT，洪嘉伟表示再看一下。
  - 增加用户信任度
    - 展示与验证：张行程指出数据分析容错率低，需要让用户相信模型分析结果的准确性，可通过展示复杂 case 和提供自证方法增加信任度。
    - 外部模型验证：卢乐炜建议找外部强大的模型如 call 迪斯配合 GB5.4 canvas stream high 进行验证，张行程认为可展示能做到 GPT 和 Claude 做不到的事情，增强说服力。
- 公司内部模型推广
  - 推广目的与方式
    - 涌现 showcase：么天阔建议让公司其他人使用公司自己的模型进行内部测试，希望涌现出一些 showcase，更有说服力地展示模型优势。
    - 小范围试用：武焕提议拉小范围人员试用，如大装置和么天阔这边的部分人员，他们使用过多种 copilot，能给出实际生产中的 good case。
- 运营安排
  - 专人负责：张行程强调需要有人负责公司内部模型运营，拉群吸引潜在用户，手把手教使用，收集问题反馈，出数据报表和挖掘 case。
  - 人员确定：武焕安排罗嘉鹏和么天阔会后确定一个全职和一个实习生负责运营，辛昱磊协助，张行程表示会找外援指导运营工作。
