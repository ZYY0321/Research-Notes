- 数据校验机制优化
  - 机制问题分析：么天阔指出，目前数据校验机制存在问题，各专项数据倾向不同，信息同步不及时，整体 check 不够严密。
  - 优化方案：建立三层校验机制，各专项自行校验、统一校验和数据集成校验，提交数据需附带数据检测报告和人工检测报告，确保数据质量。

  - 模型短板问题
    - 问题表现：洪嘉伟提出，模型在 Windows 环境写代码能力差，前端展示写 JSON 代码易出错，导致 agentloop 长。
    - 解决措施：已安排同学快速补约数据，长远来看需增加 agentic code 数据，安排人力做好相关工作。林达华要求史亚冰盯一下，短期力量不足可与嘉伟或乐炜合作。
  - 主线数据重刷与训练策略
    - 数据重刷：洪嘉伟表示，主线基数据需同步重刷，对比不同模型思维链，发现 GLM 是合适选择，目前正在逐步实验用 GLM 5.2 升级数据。
    - 训练策略：MTP 训练目前较优策略是冻结主模型只训 MTP，成本小且接收率能提升 70% 左右；长文训练需探索小模型扩展到 510K 的方法。
  - 数据分析任务规划
    - 交付目标：7 月中旬要交付 27B 用于私有化部署，整合数分任务规划、PPT 生成等功能，支持最新 Harness。
    - 任务安排：下周三前升级任务规划数据，基于 27B 版本做 DPO 训练，适配新管线，初步出一版数据；用 Hermes harness 做的数据已验证完毕，预计周六日做出基于 agentv3 管线的数据；评测适配开放题评测；协调文民适配数据分析到新管线。

    - 大日志问题：大日志资源到位，数据回流率稳定，但发现唯一 message 接口有处理问题，chatcompletion 接口回流率较好。

- 量化进展汇报
  - 数据筛选与训练
    - 数据筛选：肖鹏称，data science skill 持续优化，针对数据筛选、刷写和训练实现多套 harness，适配数据多样性和 RL 训练稳定性。

    - 基模型能力：基于原生 7B 模型训练，在量化领域能力欠缺，长时间训练效果有限，训练奖励趋于平稳。
