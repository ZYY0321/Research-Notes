- 沙盒需求讨论
  - 沙盒作用及现状：沙盒主要用于保护训练和推理过程，避免程序崩溃影响宿主机。目前腾讯沙盒不打算维护，其重点在推理调度；公司部分组使用腾讯或火山沙盒，大装置沙盒客户较少。
  - 沙盒需求判断：对于沙盒在推理上的需求，存在不同看法。有人认为用户可根据权限选择是否使用沙盒，目前用户多在自己架构上使用；也有人认为未来 server 端 runtime 趋势下，沙盒需求会增加。刘文民表示小浣熊实践中对沙盒有强需求，维护了自己的沙盒体系，准备扩展沙盒池子。
  - 决策方向：林达华提出需判断沙盒从业界角度是否有量，若有量可向杨帆反馈，目前需进一步了解情况，再从公司层面布局。
- 后续工作重点规划
  - 工作主线确定：林达华提出后续工作重点聚焦两条主线，一是围绕工作流的 agent，专注于对比 search、数据分析及整体工作流驱动；二是围绕最高水平的 AI presentation 打造，包括 UE 和 agent generation 等，形成统一的 roadmap 推进。
  - 评测工作安排：孙文秀需明确区分两条主线进行评测工作，在不同会议中分别开展相关评测。
  - 资源调配决策：林达华指出 agent RL 的 Infra 是当前 agent 训练未 scale 起来的关键瓶颈，要求龚睿昊和卢乐炜对齐计划，短期内从主线调配一部分用于迭代 infer 的资源，解决该问题。
