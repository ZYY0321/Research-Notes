本次周会围绕 PPT 合成、数据处理、质量审查、评分标准等工作展开讨论，参会人员汇报进展、分析问题并制定后续计划，旨在提升 PPT 生成质量和效率，内容如下：
- PPT 合成与优化
  - 韩世凡工作进展
    - 合成场景与合理性完善：韩世凡基于刘波 PPT query 合成逻辑，从用户回流数据提取有效文件，分析主题、分析维度和色系风格随机搭配的不合理现象，将可随机组合的元素归类，绑定强关联的色系和风格。
    - 合成成功率提升：针对 pptquery 合成到 html 成功率低的问题，分析原因并优化，抽取 100 个合成 query 进行三次测试，平均成功率达 91%，但仍存在模型指令不跟随和服务出现 none 的现象。
    - 质量审查与多轮对话功能：增加 PPT 质量审查环节，结合 anthropic 的 PPTX skills 和王博的 PPT superpower，引入视觉审查；增加与用户的多轮对话功能，使用 LLM 模拟用户 feedback。
  - 王博建议
    - 更换 API：王博建议停用 Gemini 的 TT Chat，更换为之前测试效果好的 API 平台，认为该平台效果好，甚至可不用做后续审查环节。
    - 确保 query 合理性：强调确保 query 的合理性，丰富 query 内容，先做端到端的 query，提高 PPT 合成质量。
    - skill 版本规划：skill 维持小浣熊和针对开源的版本，小浣熊利用 agent V3 框架，system nova 用 openclaw 框架，韩世凡用 BOT 进行改造。
- 数据生成与处理
  - 王浩工作进展
    - PD agent 搭建与数据生成：王浩搭建 PD agent 为 pipeline 并测试效果，改写成 agent 自主规划形式，生成 2000 条 plan 数据，因 Gemini 3.1 深度不稳定，并发量低，合成速度慢。
    - PPT 合成与测试：根据一然提供的 PPT 类别重新组合，合成 171 万张左右 PPT，预计明天早上完成所有合成，用于测试人工标注和模型标注的一致性。
  - 秦世龙工作进展
    - 管线搭建与数据生成：秦世龙搭建从 query 到 plan 再到 html 的管线生成数据，测试不同 prompt 对最终数据效果的影响，找到稳定 prompt 并生成数据，本周准备从 Gemna 增 20K 数据，从 Claude 4.7 增 20K 数据。
- 后续计划：下周按王博需求建新 pipeline，补充 badcase 相关数据并训练模型，同时了解多轮数据及训练方法。
- 管线流程介绍：用户提供材料和图片后，先让模型分析图片描述和建议用途，进行整体结构规划，再进行每一页的单独规划指导，模型制作 html 后渲染成 png 及代码，进行 review，选择最佳结果存储。

- 内容评测与标注
  - 张荧滢工作进展
    - 数据补充与平台构建：张荧滢推进数据补充、内容评测管线和标注指南迭代工作，补充人工标注数据作为自动管线的 ground truth，构建新标注平台并迁移内容。
    - 内容评测结果：内容评测管线在 48 题上全部跑完，区分力提升，指标标准差达 0.25 左右，内容真实性评估更准确，但与人评排名相关性低。
    - 标注指南优化：基于标注员分歧案例统一标注指南，先看可用性硬性问题，再看整体视觉印象，引入 PPT 收集标准作为参照，标注同学正在试用。
    - 问题与协同需求：自动管线在美学方面与提示词对不齐，可尝试新美学标准；标注平台新增题库和题型，但商用 agent 数据未收集；部分 API 模型生成慢。需协同制定美学标准，组织人员到标注平台标注。
  - 刘承杰工作进展
    - 标注平台开发：刘承杰开发的标注平台基本可用，可分用户登录进行评分评价。
    - 增源 AI 修改 PPT 平台：马征提出让大模型修改自己生成的 PPT，收集高质量人的 critical，与模型对比，考虑将模型建议作为 code star 数据，人的标注作为高质量 SFT 数据训练 Critic model。
- 模型训练与实验
  - 陈锦豪工作进展
    - 实验跑通与问题：陈锦豪跑通 e ToB open cloud 沙盒的 black box RL 方式，在 4B 的 QWEN 3.5 上初步验证， reward 曲线正常，但存在沙盒无法访问内网 IP 和 rollout 节点 GPU 利用率不高的问题。
    - 解决方案与计划：目前采用轮询读写方式解决沙盒访问问题，后续关注能否解决沙盒访问内网 IP 问题；分析步数超长导致 context 爆掉的原因，下周尝试新的 credit assignment 工作。
  - 陈一然工作进展
- PPT 素材关联度分析：陈一然用王浩提供的脚本制作 PPT 素材，分析模型生成 PPT 与 prompt 的关联度，发现模型在有图片要求时无法生成，prompt 量不足时会填充自带文本。
- 评分标准制定：从正向推导和反向推导两个路径制定评分标准，最终人工打分和 AI 自动化评价结果相近，结合两种方式形成通用维度评价标准，但人工评判中间项时因审美风格主观未统一。
