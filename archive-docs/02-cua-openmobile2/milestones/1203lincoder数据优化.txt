 打标提示词问题分析
问题1: application development 定义过于宽泛

### application development
Dialog focuses on building end-user applications (web, mobile, desktop), 
feature implementation, UI logic, or business logic.

关键问题: "feature implementation" 这个词太宽泛了！
错误理解: 实现一个排序算法也被认为是"feature implementation"
  
问题2: 算法题被误判的原因

很多算法题的描述方式：
"I will give you a programming problem. You need to write a solution..."
"Implement a function that..."
"Create a program that..."

打标模型看到 "implement"、"create"、"program" 这些词，就认为是在"实现功能"，从而错误地分类为 application development。

问题3: 与其他类别的边界不清

algorithm design and analysis 定义**:
Includes algorithm correctness, time/space complexity, data structures, 
searching, sorting, graph algorithms, etc.

问题: 这个定义太学术化了，没有包含"编程练习"、"算法实现"等常见场景。

data science and engineering 定义**:
Covers data cleaning, ETL, analysis, visualization, statistics, 
or working with large datasets.

问题: 没有明确包含"数据处理算法"、"统计计算"等编程任务。

💡 建议的提示词修改

1. 修改 application development 定义**:
### application development
Dialog focuses on building REAL end-user applications (web servers, mobile apps, 
desktop software), business logic implementation, user authentication, database 
integration, API development, or production system features. 

EXCLUDE: Algorithm problems, coding exercises, mathematical computations, 
data structure implementations, or academic programming tasks.

2. 扩展 algorithm design and analysis 定义**:
### algorithm design and analysis
Includes algorithm correctness, time/space complexity, data structures, 
searching, sorting, graph algorithms, coding challenges, programming contests, 
LeetCode-style problems, mathematical problem solving, or any algorithmic 
implementation tasks.

KEYWORDS: "programming problem", "algorithm", "complexity", "solve", "implement algorithm"

3. 扩展 data science and engineering 定义**:
### data science and engineering
Covers data cleaning, ETL, analysis, visualization, statistics, mathematical 
computations, numerical algorithms, data processing tasks, or working with datasets.

INCLUDES: Statistical calculations, data manipulation, scientific computing
加上机器学习和深度学习，怼着这几个python 库：
暂时无法在飞书文档外展示此内容
4. 添加明确的排除规则:
IMPORTANT CLASSIFICATION RULES:
- If dialog contains "I will give you a programming problem" → algorithm design and analysis
- If dialog asks to "implement a sorting/searching algorithm" → algorithm design and analysis  
- If dialog involves mathematical calculations → data science and engineering
- If dialog builds actual web/mobile applications → application development
