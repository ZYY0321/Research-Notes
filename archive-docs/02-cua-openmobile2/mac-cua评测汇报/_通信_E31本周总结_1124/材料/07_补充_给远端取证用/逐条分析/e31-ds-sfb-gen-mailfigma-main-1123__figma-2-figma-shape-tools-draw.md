3. **A5.1 当前焦点状态判断错误（兼 A4.4 时机不当）**：步骤 25 返回已明示 `Page name` 文本字段处于编辑/选中（`Selected text: Page 9`），模型在步骤 28 仍发 `pressKey('f')` 期望激活 Frame 工具，结果把页面重命名为 `f`（步骤 30 证据）。受阻层次：模型本身。影响：对用户文件产生一次非预期改名。恢复状态：已恢复（步骤 32 `setValue` 改为 `Export`）。
4. **A4.3 操作方式不当（Return 语义）**：步骤 81 将 4 组 `setValue+Return` 串在一次调用，报 element ID 失效；步骤 83–84 显示矩形被 Return 带入矢量编辑（`heading Vector`、X/Y 置灰）。受阻层次：模型本身（对 Figma 中 Enter=进入编辑的语义判断）。影响：浪费步骤 81–93 若干步，一度无法改坐标。恢复状态：已恢复（步骤 85 退出编辑，步骤 93–95 改用 typeText+Tab）。
5. **A4.2 输入内容错误**：步骤 97 单击宽度字段后直接 typeText，值变成 `10020`（AX 回显 `Width, Value: 10020`）。受阻层次：模型本身。影响：一次错误几何值，若未察觉会污染产物。恢复状态：已恢复（步骤 99 三击全选改为 20；步骤 166 像素级确认）。
