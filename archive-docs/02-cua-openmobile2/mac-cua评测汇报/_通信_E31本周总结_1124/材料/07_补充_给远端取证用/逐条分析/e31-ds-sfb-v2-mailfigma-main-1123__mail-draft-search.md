### 7. 值得注意
- 模型能力：会区分"控件值已写入"（步20 AX 验证主题与正文）与"任务状态已生效"（步28 搜索计数），并用等待而非重复点击来处理索引延迟；在正文无 AX 节点时改用坐标点击 + `paste` 落字，之后用 AX 回证（步19–20），是桌面 CUA 的合理替代定位策略。
- 后端/框架：默认 diff 式 AX 返回（步5）在需要节点索引时信息不足，需显式 `disableDiffing`；Mail 保存草稿后搜索索引有秒级滞后，容易诱发"保存提示=任务完成"的误判。
- 出题/评分启发：带「如果收件箱是空的」这类前置条件的题面，应明确非空分支的期望行为（跳过并说明，还是仍须让搜索可见目标草稿），否则同一轨迹可被判为"达成结果"或"做了未要求的改动"两种相反结论；评分时也宜要求核对搜索结果行的主题而非仅计数。
