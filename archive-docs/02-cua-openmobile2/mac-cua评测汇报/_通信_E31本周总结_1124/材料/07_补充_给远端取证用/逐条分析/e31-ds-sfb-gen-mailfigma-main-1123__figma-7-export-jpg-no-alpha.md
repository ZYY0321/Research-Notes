### 7. 值得注意
- 后端能力不对称：同一 app 对象上索引点击可用、坐标点击/拖拽直接 `noWindowsAvailable`（步骤23/29/31）。这对"必须拖拽创建对象"的 Figma/画布类任务是硬约束，出题时应预期模型走预设或数值输入路径。
- AX 索引在 Figma 右侧面板高度易失效：任何一次写值/点击都可能重排索引（步骤68、69 的自我诊断）。驱动若能提供稳定元素 ID 或"按 ID 点击"，可显著降低此类误触。
- Figma 侧栏在 AX 写值后出现几何回弹（400×300）与导出设置被重置为 PNG/2x（步骤67）；评分若只看 UI 面板文本可能被 AX 文本与实际视觉不一致误导，建议像本轨迹一样以磁盘产物（`file`/`sips`）为硬判据。
- 评分提示：本题"1 倍"与"32×16"可通过产物像素联合验证；"添加一条导出设置"建议明确是否允许画框名为预设默认名（此处为 "iPhone Duo, Closed - 1"）。
