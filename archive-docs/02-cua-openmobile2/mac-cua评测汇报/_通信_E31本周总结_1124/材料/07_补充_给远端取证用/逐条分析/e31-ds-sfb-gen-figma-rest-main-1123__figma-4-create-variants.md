### 7. 值得注意
- **模型能力**：在坐标通道完全失效时，依次尝试工具栏/菜单/Actions/SVG 粘贴，最终用 Figma 自身解析能力建图形（步76），再用 Add variant 一步得到组件集（步89），路径选择效率高；并且主动用终端做像素级产物校验（步206、219、251），避免了"工具成功=任务完成"。
- **框架/后端问题**：①坐标 `click/drag` 恒返回 `noWindowsAvailable` 而元素点击可用，疑似窗口句柄获取缺陷；②`pressKey` 键名集合不可发现且大小写/别名不一致；③`setValue` 对 Figma 自绘 Web 控件常常只改变选中而不提交值；④AX 对 State 组合框返回 `Value: Hover` 与文本 `Default` 并存（步192/195），直接诱发了误导出。这三四点都值得作为后端 issue 跟进。
