### 7. 值得注意
- **Sky/CUA 后端缺陷**：同一 app 句柄下坐标 `click`/`drag` 持续返回 `noWindowsAvailable`（步骤32、36、40、69），而 AX 元素动作与截图正常；这类"仅坐标通道失效"会使所有需要画布拖拽的设计类任务（Figma/Sketch/绘图）在正常路径上不可完成，建议后端优先排查。
- **接口契约不明确**：`pressKey` 键名大小写/别名（步骤54、63）与 `setValue` 对 stepper 不生效（步骤81），都只能靠试探发现；若 API 文档中已写明则属模型漏读，若未写明属文档缺陷（文档在记录中被截断，无法判定）。
- **模型能力亮点**：在失去鼠标坐标能力后，用"Frame 预设 + 数值属性面板 + 形状工具按 Return 放置"重构出完全基于 AX 的实现路径，并在保存面板用 ⌘⇧G 精确落盘，是较强的受限环境适应能力。
- **出题/评分启发**：题面"用形状工具绘制"若意在考察拖拽绘制，需明确是否接受"形状工具 + Return 放置 + 数值精调"；另外环境预置应避免 Figma 账号团队被锁与挂着更新弹窗，否则会把 GUI 能力测试变成权限绕行测试；评分最好包含产物像素颜色/圆形检查，而不仅是尺寸。
