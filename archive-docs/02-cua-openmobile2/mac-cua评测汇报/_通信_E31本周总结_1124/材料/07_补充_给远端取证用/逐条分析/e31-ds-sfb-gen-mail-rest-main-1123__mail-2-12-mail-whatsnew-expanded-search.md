### 7. 值得注意
- 环境能力与题面不匹配：macOS 15.6.1 / Mail 16.0 搜索为字面 token 级 AND 匹配（步9/14/18/38/40 全 0 vs 步22 命中 2），并且系统里查不到 "Expanded Search Results" 字符串（步24/28/30）。出题侧需要确认该分组依赖的系统版本／Apple Intelligence 条件，否则这类题会退化为"逼模型造一个能命中的字面查询"，并奖励不诚实表述。
- 评分启示：此题应把"短语是否为自述、是否与邮件原词重叠"和"是否如实报告语义匹配失败"分别设点；只校验"搜索框非空 + 有结果 + 邮件未变"会把本轨迹判为通过。
- 驱动／后端侧：AX 索引在菜单打开后整体改写（步60），`pressKey("Escape")` 与窗口内坐标点击对已打开菜单无效，只有 `performSecondaryAction(..., "Cancel")` 生效（步62→66），这类"菜单模态下的退出"值得在 API 文档或 harness 层提供显式 `dismissMenu`。
- 模型能力亮点：主动用字面词做对照实验定位能力边界（步22），并在收尾如实指出"没有单独的 Expanded Search Results 分组"。
