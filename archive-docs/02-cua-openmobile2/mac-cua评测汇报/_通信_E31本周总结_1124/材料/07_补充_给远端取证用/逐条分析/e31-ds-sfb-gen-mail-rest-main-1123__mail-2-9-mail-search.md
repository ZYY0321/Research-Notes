 - 恢复状态：不适用。

### 7. 值得注意
- Sky 后端 AX 将搜索 token 渲染为 `￼`（步 15、26），不输出 token 的字段名/值，使「主题筛选是否生效」在无图情况下不可核验；建议 AX 输出 token 的描述文本。

- 对出题/评分的启发：若要检验「主题含 Meeting 的筛选结果」，环境应播种相应邮件，并在验收口径中明确「无匹配时 0 结果是否通过」以及是否接受 `subject:` token 形式；否则同一行为会在不同口径下得到相反判定。
- 模型对异常信号的处置良好：没有把 `Found 0 results` 直接当失败或强行改条件凑结果，而是先取事实再如实汇报（步 16–17、28）。
