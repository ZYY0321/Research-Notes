### 7. 值得注意
- **框架/后端**：`cua.drag(from,to)` 在剪映这类自绘时间线应用中疑似无法触发真实拖放（两次调用零状态变化），而剪映素材入轨高度依赖拖放；若该 API 确实不产生中间移动事件，这类"拖素材到轨道"任务会系统性失败，建议核查 drag 实现或为 CUA 增加按下/移动/释放分步接口。
- **后端/桥接**：`getApp("com.lemon.lvpro")` 因同 bundle id 多副本报歧义，错误信息给出了可行替代（全路径），模型一次纠正成功，这是好的错误设计。
- **模型服务**：web search 未开通时返回的是 `stream disconnected before completion` 并走重连逻辑，而不是一次性的工具不可用拒绝；这把一个"能力不可用"放大成了"运行终止"，对评测可靠性有实质影响，建议在桥接层把此类账号级错误转为不可重试的明确报错。
- **模型能力**：探索顺序合理（双击→拖放→右键→菜单栏），但在确认"无菜单/无右键入口"后没有尝试自己已经设想的悬停"+"按钮，也没有尝试"选中素材后按回车/快捷键"等低成本试探，表现出"卡住就外求信息"的倾向。
- **出题/评分**：此类任务建议在轨迹中额外采集最终磁盘产物（导出文件、草稿目录）与关键截图，否则"是否真的入轨/是否导出"只能靠 AX diff 间接推断。
