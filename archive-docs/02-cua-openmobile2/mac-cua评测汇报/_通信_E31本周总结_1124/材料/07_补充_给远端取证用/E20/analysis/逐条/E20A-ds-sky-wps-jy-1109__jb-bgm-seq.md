### 7. 值得注意
- **后端问题**：截图实际 1920×1090 却以 1792×1008 呈现（步122–127），而 `click` 使用原始像素，这个落差没有在工具文档中体现（步2 文档明确说"screenshots use original pixel coords"），对所有依赖视觉定位的 macOS CUA 任务都是系统性坑；模型靠解析 JPEG SOF 头自行发现，属于不错的自救，但代价极高。
- **应用特性**：剪映时间线、右侧属性面板几乎不暴露 AX 元素（步84、步142 的树里只有 `滚动条`/`文本`），只有右键菜单可用 AX 索引点击；出题/评分时应预期代理会高度依赖右键菜单路径，评分不宜只认"音量滑块置 0"一种关声实现。
- **评分启发**："关闭原声"存在"轨道静音 / 片段音量 0 / 分离音频后删除"多种合法实现，建议 rubric 以最终导出无原声为准；"放到主轨道"若允许"新建时间线"这类路径，需要明确草稿中多条时间线时以哪条为准。
- **平台配置**：web_search 未开通导致整条流中断（而非返回一个可恢复的工具错误），这是会直接吞掉任务的基础设施问题。
