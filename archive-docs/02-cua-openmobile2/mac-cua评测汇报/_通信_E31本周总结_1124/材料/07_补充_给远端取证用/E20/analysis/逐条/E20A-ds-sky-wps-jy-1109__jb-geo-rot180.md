### 7. 值得注意
- **Sky 后端坐标缩放（≈0.897）是本案最大成本来源**：工具文档宣称截图为原始像素坐标，实际点击需按 1/0.897 换算；模型靠"点击后看光标位置"自行标定（步86、95、99），这是很好的能力表现，但环境应修复或显式声明比例。
- **剪映属 Qt 自绘界面，AX 树几乎只有占位名**（`automation*`、`material.library.item...`），右侧属性面板的"旋转"数值框完全未暴露；AX `click(index)` 对这类控件常无效，而原生 NSOpenPanel 与右键菜单可用。出题/评分时应预期 agent 走右键菜单路径。
- **导出对话框里 Return 直接触发导出**（步152→154），没有二次确认；若文件名未正确提交会直接产出错误文件名，风险较高，值得作为评分观察点。
- **评分建议**：除检查产物文件名/分辨率外，若还检查草稿 JSON（主轨道 segment、`rotation: 180`），需明确"新建时间线"是否算满足"放到主轨道"，否则该用例判定会有争议。
