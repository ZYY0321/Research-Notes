- **Sky 后端/驱动问题（高价值）**：`click` 的坐标语义不自洽——文档（步骤 65 `Click.d.ts`）称"X coordinate in the app-window screenshot"，但步骤 102 的报错把 `(900,600)` 变成 `(900.0,625.0)` 并判定无窗口，而同窗口同 API 在步骤 81 又成功。截图实际为 1920×1090 而工具渲染为约 1718×969（步骤 89），缩放信息未暴露给模型，模型只能靠解析 JPEG 头＋`magick` 裁剪反推（步骤 85–89、136–139）。建议后端直接暴露窗口 bounds／截图缩放比。

- **工具描述未给出 `press_key` 键名规范**（步骤 2 的 API 文档在本记录中被整理截断，无法确认原文是否包含），导致模型连续 3 次参数错误并最终去读源码。建议在工具描述中明示 keysym 命名。
