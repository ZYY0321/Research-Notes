### 7. 值得注意
- 后端能力缺口：窗口级截图/AX 不暴露 Qt 的 `QMenu` 弹窗（步骤 8–24），而 macOS 菜单栏弹窗可暴露（步骤 50）——这类不对称极易让模型误判「点击无效」，建议后端补充全屏截图或弹窗枚举，或在返回中提示「存在前台瞬态窗口」。
- `pressKey` 键名契约不透明：`"TAB"`/`"Cmd"` 直接 `keyNotFound`（步骤 18、46），`"Command+Q"` 被接受却无效（步骤 48），对需要全局快捷键（Cmd+Q、Cmd+S）的任务是系统性风险；评分若要求字面 Cmd+Q，需先确认后端能投递 Command 修饰键。
- 出题/评分启发：本任务「Cmd+Q」应明确是手段还是硬性要求；同时应在任务或 rubric 中明确「只读的 CLI 校验」是否允许，否则同一轨迹会因口径不同得到相反判定。
- 模型能力亮点：用「窗口是否失活」作为弹窗存在的间接信号，并用菜单 typeahead 绕过不可见菜单，是较强的状态推断与替代路径能力。
