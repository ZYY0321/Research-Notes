### 7. 值得注意
- **后端坐标语义是本案最大技术缺口**：AX 树不提供元素 bounds，`App.click(Vec2)` 的参考系（截图像素/窗口相对/屏幕绝对/缩放）不可自证，模型只能靠误点反推偏移（步35/49/55/61/124/136/138 的推导彼此矛盾）。建议后端在 AX 输出中附 frame，或提供"按截图坐标点击"的明确语义。
- **"无法点击窗口外"是硬阻塞**：macOS 上大量自绘 popover 只能靠点击外部关闭；当前后端对窗口外坐标直接报 `windowNotFoundAtPosition`，等于把这类 UI 变为不可逆陷阱。建议提供桌面级点击或 `dismissPopover`/`pressKey` 到系统层的能力。
- **自绘 UI 的 AX 伪影**：侧栏 checkbox 的 value 会变但界面不切换（步22-32），多个 checkbox 同时为 1（步30/32），容易让模型误判状态；评分时应把这类"值变了事没成"与模型误判区分开。
- **出题/评分启发**：美图秀秀的字号、字体、颜色均为自绘弹层，在当前后端能力下该任务可能接近不可完成；此类案例的评分应能区分"后端能力缺陷导致失败"与"模型错误操作导致失败"——本案两者并存，且模型的 `cmd+W`+"No, thanks" 属独立可归责错误。
- **一个可教的保底原则**：进入高风险/不可逆控件前先在无害区域校准坐标；以及在出现保存提示时优先落盘保底而非丢弃。
