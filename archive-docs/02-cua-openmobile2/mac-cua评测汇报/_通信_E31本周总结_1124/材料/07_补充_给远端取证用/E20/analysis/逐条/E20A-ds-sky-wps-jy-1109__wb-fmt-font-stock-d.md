### 7. 值得注意
- **Sky 后端缺陷**：同一 `click([x,y])` 在子对话框可用、在主窗口报 `-10005 noWindowsAvailable`（步骤 65/70），且重新 `getApp` 无效——这是可复现的后端问题，直接决定了本题成败，建议作为框架 bug 跟进。
- **AX 覆盖不足**：WPS（Qt）把表格区、功能区按钮、单元格格式对话框的颜色下拉几乎都未暴露为可操作 AX 元素（步骤 31/63 树），只剩"坐标点击"一条路；一旦坐标点击在主窗口失效，题目即不可解。
- **模型能力亮点**：名称框 `setValue` 选区、Cmd+1 走对话框、列表点击失败后改 `setValue` 字形、先落地加粗再图设色——路径选择务实；也主动否决了"粘贴 HTML 重写 D 列"的高风险方案（步骤 75）。
- **出题/评分启发**：本题应在环境侧预先确认工具栏坐标点击与字体颜色下拉可交互，否则是环境不可解；评分若只看最终 xlsx，会把后端缺陷记为模型失败。另外应为此类"GUI 内无入口"的任务明确是否允许 CLI/脚本兜底。
- **平台配置**：火山账号未开通 web search 却仍把 web_search 暴露给模型，造成 8 次断流并直接杀死运行，属应修的环境配置问题。
