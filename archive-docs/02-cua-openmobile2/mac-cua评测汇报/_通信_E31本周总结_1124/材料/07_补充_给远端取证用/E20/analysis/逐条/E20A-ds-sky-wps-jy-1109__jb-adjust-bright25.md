### 7. 值得注意
- **后端能力缺口**：cua_repl 似乎只暴露 `drag(from,to)` 而无 mouseDown/mouseMove/mouseUp 分步接口（模型在步骤 107 推理中明确意识到）。剪映这类自绘时间线应用的拖放通常需要带中间移动与停顿的真实拖拽；若后端的一次性 drag 不能满足，这类"素材拖入轨道"的题目在当前后端上可能系统性不可解，建议出题前先验证 drag 对该应用是否生效。
- **AX 可操作性不足**：素材卡片（元素 27/9）只有 `Raise` 这一个 secondary action，右键菜单（步骤 54）也没有"添加到时间线"，意味着除拖拽外缺少可达的替代入口；模型对 AX 的枚举与判断本身是正确的。
- **坐标系一致性**：首页截图与编辑器截图尺寸不同（模型推测 1174×780 / 1760×994 / 对话框 800×449），同一会话内截图坐标与点击坐标的换算关系不透明，是本轨迹 2 次无效点击的直接诱因；建议在工具返回中显式给出截图尺寸与缩放比。
- **环境配置**：火山账号未开通 web search 却仍把该工具暴露给模型，一次调用就打断整条轨迹（步骤 108–118）。评测前应关闭未授权工具，或至少让其返回可恢复的工具错误而非流断开。
- **对评分的启发**：本例的失败点在"素材入轨"这一步，若评分只看最终导出文件，会掩盖"导入已成功、只差拖放"的信息；建议对此类任务设置分阶段检查点（草稿已建／素材已导入／轨道有片段／亮度参数／导出文件名）。
