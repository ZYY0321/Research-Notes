### 7. 值得注意
- **Sky 后端问题**：`app.click([x,y])` 返回 `-10005 noWindowsAvailable` 而同时刻 AX 与截图均正常（步骤 28/32/36/38），这是一个可复现的能力缺口。WPS（Qt 自绘）功能区按钮几乎不进 AX 树，若坐标点击不可用，则「字段列表」「透视表字段拖放」这类任务在该后端上基本不可达——建议环境侧优先修复或在 API 文档中明确坐标系要求。
- **模型能力**：菜单探索能力不错（会先 `getAXState` 看菜单项再点，而不是盲点坐标），对话框默认值核对也到位；短板是异常后缺少「场内穷尽」纪律——自己想到的 `pressKey` 方案一次未试，却反复调用明显不可用的外部工具。
- **框架／账号配置**：web_search 未开通直接把失败升级为 stream 断开并终止整轮（步骤 46–59），这是把「工具不可用」放大成「运行终止」的脆弱设计，建议对未授权工具返回可恢复的工具级错误而非断流。
- **出题／评分启发**：此类任务建议在评分前确认目标环境的功能区/浮动面板是否可被当前后端驱动；同时评分点应区分「透视表已创建但字段为空」与「完全未创建」，本例属前者，是有部分进度的失败。
