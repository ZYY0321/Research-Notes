- **AX setValue 与应用模型脱节**（步99–110）是 WPS 这类 Qt 应用的通用坑；`paste` 是有效替代（步115），值得写进能力提示。

- **自我 trace 可被 agent 读到**（步128 输出）：评测沙箱应把 `/private/tmp/mac-cua-agent-*` 对 agent 屏蔽，否则存在评测污染。
