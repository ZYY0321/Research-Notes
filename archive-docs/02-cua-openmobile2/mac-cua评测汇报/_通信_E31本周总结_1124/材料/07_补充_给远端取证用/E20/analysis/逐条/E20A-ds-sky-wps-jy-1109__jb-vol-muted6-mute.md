- **框架/后端**：(a) `cua.getApp` 对中文显示名直接 Invalid、对 bundle id 歧义，需全路径，首步开销大（步骤 4–10）；(b) `pressKey("Escape")` 在上下文菜单与应用菜单下均未生效，只有 AX `performSecondaryAction(…,"Cancel")` 能关闭（步骤 33/47/51），这是 CUA 后端值得修的按键路径问题；(c) 菜单打开时 `getScreenshot` 直接返回 “Screenshot unavailable”、`getAXStateAndScreenshot` 的 screenshot 字段变成不可 emit 的值（步骤 39–43），会让模型失去视觉证据；(d) `drag()` 在该应用素材→时间线场景下未产生任何可观察效果，建议单独做 DnD 能力探针（macOS 原生 DnD 常需按下-移动多帧-停顿-释放）。
