### 7. 值得注意
- 剪映（VideoFusion）自绘 UI 的 AX 暴露极弱：时间线上的片段、文本轨道、属性面板控件几乎没有可寻址元素（步骤 15/84 的 AX 树只有按钮壳与 scrollbar），且 `material.library.item....apply` 这类后缀不是可执行的 secondary action（步骤 56 报 -10005）。这类任务高度依赖坐标点击与拖放。

- 同一 bundle id 对应多个 .app 导致 `getApp` 歧义（步骤 7），环境可预置完整路径以减少无谓步骤。
- 系统「打开」面板中双击文件夹被应用直接当作“导入文件夹”（步骤 25–27），出题/评分时应容忍素材库里多出文件夹层级。

- 评分提示：本任务若按“草稿内第一条时间线”检查，步骤 66 产生的「时间线01 空 / 时间线02 有素材」结构可能造成误判，宜明确以当前时间线或导出产物为准。
