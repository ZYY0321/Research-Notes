- Sky 后端在 WPS（Qt）下 `click(Vec2)` 三次返回 `noWindowsAvailable`，而同 handle 的 AX 元素点击/`setValue`/`performSecondaryAction` 均正常：这是明确的后端能力缺口，需要核实该接口是否要求显式窗口或 screenshot 区域上下文。若坐标点击在该类应用确实不可用，则所有"表格画布/ribbon 内操作"类任务在当前后端近乎不可完成。
