### 7. 值得注意
- 剪映的时间线为自绘视图，AX 树里完全没有轨道/片段节点（步骤 18/30/40 均无 track 相关元素），只能靠截图坐标拖放；本任务对 `drag` 的真实可用性高度敏感，建议出题/评测方先单独验证 Sky 后端对剪映时间线拖放是否生效，否则任务可能从一开始就不可达。
- 剪映同 bundle id 对应三个 .app 路径，`getApp(bundleId)` 直接报歧义（步骤 7），对 CUA 后端是可复用的已知坑；模型用完整路径恢复是正确处理。
- `pressKey` 与后续 `click(旧ID)` 放在同一 cell 容易踩 ID 失效（步骤 63），框架侧可考虑在 ID 失效时返回更明确的“状态已变更，请重新观察”提示。
- 评分启发：本例应能区分“环境/驱动导致入轨失败”与“模型重复无效检索导致机会耗尽”，二者都存在，归因不宜只记一方。
- web search 未开通表现为 `stream disconnected`＋8 次自动重连，会无谓吃掉大量轨迹长度；建议对该类不可用能力做一次性熔断。
