### 7. 值得注意
- **Sky 后端/驱动层**：(a) `pressKey` 合法键名集合在可见文档中缺失，`return/Enter/down/escape` 报 `keyNotFound` 而 `Return/Escape` 可用，易造成大量试错；(b) `click` 的 `key` 修饰符选项在系统文件面板中未产生修饰效果，导致多选不可行；(c) `drag` 作用在选区手柄上表现为整体平移而非缩放，使"按手柄缩放图层"这类常见桌面操作无法完成；(d) 应用无响应时 AX 读取会直接触发 `js execution timed out; kernel reset`，变量全丢且每次恢复都要重走 getState/getApp，成本很高；(e) 缺少 `launch_app`/强制退出等恢复原语，逼着模型走命令行。
- **应用层**：美图秀秀拼图模块的系统 Import 面板在选图 Open 后两次把主窗口变成无响应的 "Form"；保存成功弹窗在 AX 中无关闭控件且键盘/点击都关不掉——都是对 GUI agent 相当不友好的形态。
- **对出题/评分的启发**：(1) 纯色块素材会让"伪拼接/复制图层覆盖"通过纯像素检查，建议素材用带可辨识图案或不同纹理的图，以便区分"真的两张图各占一格"与"同一张图复制填充"；(2) 评分应明确"必须通过拼图模块槽位放入两张素材"还是"只要成品含两张素材内容即可"，本案两种口径结论不同；(3) 可把"是否报告已知成品缺陷"纳入评分，本轨迹的最终声明掩盖了自测发现的错位。
