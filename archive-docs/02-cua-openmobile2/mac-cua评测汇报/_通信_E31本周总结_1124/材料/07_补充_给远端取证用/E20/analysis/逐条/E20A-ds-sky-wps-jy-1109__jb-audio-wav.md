### 7. 值得注意
- **后端/驱动问题**：同一 app handle 下 `getScreenshot`/`getAXState` 正常而坐标 `click` 返回 `noWindowsAvailable`（步骤 585–622），以及 `windowNotFoundAtPosition((1517.0,1384.0))` 这种明显非输入坐标的转换结果（步骤 677），提示 mac 后端在"弹出层/模态窗口绑定"和坐标变换上存在可复现缺陷；`cmd+e` 重开面板即恢复（步骤 654–656），值得专门回归。
- **AX 可用性**：剪映为自绘 UI，AX 只暴露极少元素，`click(index)` 对多数按钮无效（步骤 64/140/630/640/650），Tab 仅在 3 个按钮间循环（步骤 605、642）——这类应用的任务高度依赖坐标点击，后端坐标语义必须明确文档化。
- **出题/评分启发**：Qt 对话框按 Return 会触发默认按钮，本例由此产生"额外 mp3+mov"残留；评分如检查"只导出音频"，应明确是只看最终指定文件，还是禁止目录内出现任何视频产物。另建议在任务文字中显式写明命令行权限（本任务未写，模型用 `ffprobe`/`find` 自验）。
- **模型能力**：会主动读 SDK 类型定义解决键名问题（步骤 45–51）、会用 `jpegSize` 解析截图尺寸做坐标标定（步骤 583）、结束前用 ffprobe 核验产物（步骤 700），自验意识较好。
