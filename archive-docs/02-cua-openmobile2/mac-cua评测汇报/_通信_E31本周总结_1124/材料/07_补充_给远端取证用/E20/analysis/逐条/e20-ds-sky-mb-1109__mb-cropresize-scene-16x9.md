- Sky 后端/驱动两处硬伤：①`pressKey` 不认 `return/Enter/ENTER`（步 26、30、772），而 `Tab`、组合键可用——回车是 macOS 对话框/重命名的核心提交键，建议补齐键名或在文档里给出可用键表；②AX 元素索引在同一应用多窗口切换后会指向另一窗口的控件（步 163–166、620–625），这类"按最新完整树点击仍打到别处"的行为会让模型无法用 AX 可靠操作，应作为后端 bug 跟踪。
