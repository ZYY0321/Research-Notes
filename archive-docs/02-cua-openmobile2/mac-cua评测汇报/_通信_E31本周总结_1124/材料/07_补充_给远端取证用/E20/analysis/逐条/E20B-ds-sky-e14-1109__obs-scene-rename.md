### 7. 值得注意
- **Sky 后端能力缺口（高优先）**：`click(..., {mouseButton:"right"})` 在 Qt 应用（OBS）上不产生上下文菜单，且 `{key:"ctrl"}` 修饰点击亦无效——这会让所有“右键→菜单项”类 macOS 桌面任务（OBS 场景/源重命名、Finder 右键、列表项菜单）系统性不可完成，建议优先核查右键事件注入与 ctrl-click 映射。
- **菜单态下的观察/操作退化**：菜单打开时 `getScreenshot` 直接返回 “Screenshot unavailable”，菜单内元素被判 offscreen 而拒绝点击（步骤 92–98），且 `getAXStateAndScreenshot` 在“无变化”时似乎不产图（步骤 94）——使 agent 在菜单交互阶段几乎盲操。
- **键名契约不一致**：大小写与别名规则不统一（`"shift+F10"` 可用、`"shift+f10"` 不可用；修饰键名 `ctrl` 而非 `Control`），应在 `cua_repl` 文档中显式列出合法键名表，否则每个任务都会浪费数步试错。
- **模型侧表现可圈点**：严格遵守“只用 GUI”约束，主动识别并否决“用 TextEdit 改 scene JSON”“新建场景+删除旧场景替代重命名”等变通（步骤 53、87），并正确区分 “Scene Collection → Rename” 改的是场景集合而非场景（步骤 67）；这些是可用于约束遵循类评测的正向信号。
- **对出题/评分的启发**：此题的唯一主路径强依赖右键菜单，建议在环境预检中加入“右键能否在 Qt 应用唤出上下文菜单”的探针；同时为环境所致失败与模型所致失败设置可区分的评分口径。另需注意本环境未开通 web search，应在工具清单中关闭该工具，避免 agent 调用后触发反复断流而耗尽轨迹。
