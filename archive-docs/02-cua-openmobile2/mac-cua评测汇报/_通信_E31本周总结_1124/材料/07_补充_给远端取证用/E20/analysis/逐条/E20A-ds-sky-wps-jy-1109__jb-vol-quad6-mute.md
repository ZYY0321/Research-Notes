### 7. 值得注意
- **截图坐标系未自描述**是本案最大坑：`getScreenshot` 不返回尺寸/缩放，模型只能靠落盘后 `sips` 反推（步84），建议后端在截图结果中带上 width/height/origin。
- **pressKey 不支持 return/enter/escape**（步18/24/30），使"文本框输入后回车提交"这一最常见模式失效，剪映/Finder 类任务会被系统性卡住。

- **合成 drag 对剪映素材库无效**（步101），使"拖素材到主轨"这一出题默认路径不可达；出题/评分需明确是否接受「根据选中素材新建时间线」等替代路径。
- **评分口径提示**：若按草稿 JSON 校验，需注意"音量 -∞dB"与"静音开关"字段可能不同，以及步105 可能产生的多时间线/子草稿结构，以及素材库中多出的 `cua-basic` 目录。
