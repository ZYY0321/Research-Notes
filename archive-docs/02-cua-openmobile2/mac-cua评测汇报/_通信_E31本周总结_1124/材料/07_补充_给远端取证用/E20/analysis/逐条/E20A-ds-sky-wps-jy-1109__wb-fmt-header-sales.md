- 标签：A4.2（输入内容／参数错误）

- 归因：预期发送 ⌘B 加粗 → 实际按键名不被后端识别而报错；支持原因是模型在未确认 pressKey 键名约定时凭猜测传参（步骤 29 自述「pressKey Meta invalid; use Command+B maybe key names? ... docs absent」）。尚未排除的解释：后端键名文档确实未在工具说明里给出（步骤 2 返回被整理截断，无法核对该段）。

**次要问题 2：坐标点击被后端拒绝**
- 标签：E5（工具／框架／应用异常）
- 定位：步骤 30、34 `wps.click([394,123])` → `noWindowsAvailable`，而紧邻的步骤 32 `getApp` 明确返回「0 标准窗口 销售明细.xlsx」
