# 怎么收紧

下面只是建议。这次没有改 `evaluation.py`，也没有改 `e31_grade.py`。

1. 文本的 `contains` 如果是字符串，就把它当成一整句。现在飞书两道用列表，整句才算数；两道邮箱题和 SVG 用字符串，就变成逐个字符。函数里收口，比逐题改 PARAMS 稳。

2. 图不要只留几个抽样点。给一张参考图，算平均绝对差，或者至少抽一整格而不只是题面点名的那几个坐标。`not_flat` 改成「至少多少种颜色」或「和纯色的平均差要超过一个数」。现在差 1 个像素就过。

3. png_rgba 把 alpha 放进条件。可以要求若干个像素的 alpha 低于一个值，或者抽样里带上 alpha。现在 20 道完全透明都是 1 分，没有 alpha 通道的 RGB 都是 0 分。颜色类型查了，透明度没有。

4. 署名挡得住「一个字都不写」。要求署名的那些题，sips 或 Pillow 直接存盘、不写 `Adobe Photoshop`，是 0 分。它挡不住事后写上这几个字。PNG 看的是 tEXt / zTXt / iTXt，JPEG 看的是 APP1 或 Photoshop APP13，PSD 看的是资源 1057 并且要像 202x，同时拒绝 CC 2014 样例。把版本号写得更严，仍然是字符串。像素和参考图的差，比再加长这串字有用。

5. JPEG 要能解出图像，不要停在 SOF 的宽高。质量如果要查，查量化表。`ps-jpeg-q60` 的题注已经说明 60 不在通过条件里。

6. prefix 后面再查一点结构。TIFF 看版本号 42，PDF 看到 `%%EOF`，SVG 解析出元素，而不是只看开头几个字节。差一个字节现在已经是 0 分，所以缺的是文件头之后。

7. PSD 的标记要落在文字图层记录里，不要在整个文件里搜字节。图层数 0 且图层区长度是 0 的空壳，不要当成已经合并。CC 2014 样例这道门可以留着，它现在是关着的。

8. 草稿在开跑前记下已有的 id，评分只认新 id。密送题要有 BCC 字段，现在的导出文本里没有这一栏。正文子串太宽，「夹带那几个字」就会过；主题的整句相等可以留着。

9. 旗标的基线不要只信任务目录里的那个 txt。评分自己数收件箱里的旗标，再和开跑时它自己写下的数比。现在改基线、或者把收件箱写成 0 再放跳过文件，就是 1 分。旗标数没变会被打成 0，那一部分可以留着。

10. `all` 的每一项用上面更严的检查。对象蒙版的 PSD 现在只看 `8BPS` 四个字节。多次导出不看尺寸。裁切那一张只看 40×30。
