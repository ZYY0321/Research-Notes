## 图是怎么来的

集群把客机桌面上的导出文件收进了每题的 `outputs/files`，收据里有大小和 sha256，没有修改时间。模型在轨迹里打开过这张图时，查看器能按这个 sha256 把字节给出来。没打开过的，这个接口是 404，导出图本身不在本机。那些题改看结束时的整屏截图，截图和导出文件不是同一张，文中会写明。

桌面文件的时间来自轨迹里的 `ls -l`。虚拟机时钟是 11 月 23 日。第一轮导出集中在 14:16–15:37，第二轮在 17:20–17:45，v2f 那张是 17:58。第二轮的时间都落在第二轮里，不是把第一轮留在桌面上的文件再交一次。

## 同一题的两轮

第二轮不是把第一轮留在桌面上的 PNG 再交一次。能对上时间的文件，第一轮是 14:21–15:37，第二轮是 17:20–17:45，都是当轮新写的。

云端文件是接着用的。新建经常被团队锁挡住，人就进已经打开的草稿。第一轮布尔并集画在跑步记录那份旧稿里。第二轮布尔并集打开的是早已存在的 `Untitled`（文件 id `qlHTTqWeKi3oTRx7TepLy6`），模型自己写这个文件不是空的，里面已经有 Pencil Sketch、Shape Task、Mask 这些页。第二轮的自动布局列表打开的是第一轮命名过的 `Figma 2 Auto Layout`。

22 道里有 11 道两轮导出字节完全相同：自动布局、布尔并集、橙色圆弧、三条红条、蒙版裁切、左上蒙版、红圆、纯蓝斜杠路径、JPG、取消填充显示、三个红矩形。这些题把坐标和颜色写死了，再画一遍、再导出，Figma 会给出同一个文件。哈希相同不能单独证明第二轮没重画。界面步数也还在：布尔并集 81 对 73，三个红矩形 76 对 61，都不是点一下导出就结束。

能看出是拿已有画框导出的，是这几道。两条导出设置的第一轮，模型写了没改设计，PNG 就是蒙版那张左上蓝块，JPG 是它的 2 倍。第二轮的 PNG 透明导出和第二轮的两条导出设置 PNG 是同一个文件。切片导出来的是空白区域。

从 0 变成 1 的两道，第二轮是重做的，不是把第一轮的 0 分文件再交上去。嵌套那道第一轮角上是灰的，得 0；第二轮角上是蓝、中间有黄，得 1，字节也不同。布尔合并图层第一轮得 0，第二轮这张蓝块得 1。`figma-2-frame-nested` 两轮都是 0。
