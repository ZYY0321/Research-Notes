# 5. 怎么排

先修收取，再修桌面权限，再谈题面。现在继续把队列里的生成式、Neural Filters、要 Pillow 的准备脚本跑满，买到的是每题大约 60 分钟的 0 分，或者做完了也不评分。

保留，而且值得在修好下面两件事后重跑。这些题的成品是本地像素或本地滤镜，模型已经写出文件，只是没被评分：

- `ps-2-11-clipping-mask`
- `ps-2-11-vector-mask`
- `ps-2-11-mask-disable-apply`（已经 1 分，用来对照）
- `ps-2-16-ps-pen-filled-shape`
- `ps-2-16-ps-shape-rectangle`
- `ps-2-18-stylize`

同一类、还没跑到或刚失败、修完环境后可以排的：图层蒙版其余几道、形状、查找边缘这类本地滤镜、`File > Save As`（`ps-2-25-ps-save-as-format` 已经走到 TIFF 对话框，被桌面权限挡住）。

要改的：

- 桌面文件夹权限。在镜像里事先允许 Photoshop 写 `~/Desktop`，或者把成品目录挪出桌面。现在模型的绕法是写到暂存目录再 `mv`。停机一旦失败，这次 `mv` 的结果也不会被收上来。
- `control.stop_unconfirmed` 时仍然把 `~/Desktop/e31-newapps/out` 收上来评分。上面 5 道就是被这一步丢掉的。只在题面里加「做完后不存储并退出」对不上代码：停机并不关 Photoshop，vector 的窗口也没有星号。
- 准备脚本不要在客机那个没有 Pillow 的解释器里 `import PIL`。队列里还会踩中的是 remove-bg、remove-tool、fill-objects，以及三道 crop（drag-edges、nondestructive-restore、redraw-frame）。`ps-2-9-crop-rotate-straighten` 的准备脚本不 import PIL。
- `ps-2-25-ps-quick-export-png` 的署名检查。快速导出的 PNG 没有 `Adobe Photoshop` 文本块。要么改检查，承认这种 PNG；要么题面改成会写入 XMP 的存储方式。这道不用按「模型没做」重跑。
- 题面第一句「能用终端就先用终端」。它把模型推进 JSX，再加终端移动。成品仍是 Photoshop 写的，界面截图也能看见蒙版红叉。如果这批要的是「Photoshop 交出带署名的文件」，这句可以留，优先修收取和权限。如果要的是菜单点击本身，这句和「不要用 AppleScript、不要用别的程序生成文件」叠在一起，模型会继续走脚本菜单，而不是把时间花在点工具上。

先别排、或从当前队列拿掉：

- `ps-2-1-ps-whatsnew-generative-upscale`：没进功能，413，Finder「打开方式」。
- `ps-2-13-ps-repair-generate-background`、`ps-2-13-ps-repair-content-aware-fill`：入口或权限框耗满大约 60 分钟，没有可收的成品。生成式在登录和网络没确认之前不要成批排。
- `ps-2-18-neural-filter`：面板写明要另装插件。装上之前下线。
- `ps-2-21-ps-action-play-on-image`：录制控件没响应，60 分钟，文件不在。

机时。两台从 01:28 到 10:00，封卷 24 道，官方 1 分 1 道。真正做题的大约 50–62 分钟一道；timeout 的回执是 3600 秒。准备失败的四道几乎不占模型时间，但会占一次虚拟机起停。

10:00 时两台都没闲着：Mac1 在 `ps-2-13-ps-repair-patch`，当时轨迹末尾是存储对话框，可访问性 `timeoutReached`；Mac2 在 `ps-2-25-ps-save-copy`。这两道已经跑进去了，这份记录没有动它们。

后面若原队列继续：Mac1 还剩红眼、去背、移除工具、整组调色、画笔、填充、画直线；Mac2 还剩新建文档、画板、描边、图案、四道裁剪。其中 6 道会在准备阶段因 PIL 立刻失败，生成式和 Neural 类会再买一小时 0 分。本地、不靠生成式、准备阶段不 import PIL 的题，要等桌面权限和「停失败也评分」这两件事做了再排，否则和今早这 5 道一样，文件写出来也没有分。
