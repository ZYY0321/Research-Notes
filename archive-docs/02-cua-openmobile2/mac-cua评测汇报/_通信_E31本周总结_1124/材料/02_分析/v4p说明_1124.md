## selftest

每道题在本机用纯 Python 跑了 `selftest.py`。109 道都通过。

评分脚本在 import 时要 `task_api`。这个模块是客机提供的，本机没有。跑的时候在临时目录放了一个只有两个空类的 `task_api.py`，用 `PYTHONPATH` 指过去，再把题包的 `shared` 加进去。这个临时文件不在题包里。

没有打开任何图形界面应用，没有用 osascript 或 osacompile。准备脚本里的 `open -a` 在这次 selftest 里不会执行：selftest 测的是评分函数。

另外把 109 道准备脚本的家目录指到 `/tmp` 下的临时目录，把 `open` 换成直接返回成功，再执行。109 道都返回 completed，种子文件能写出来。`~/e31-newapps` 还不存在时，写文件前会建目录。描边那道先建 `~/e31-newapps/out`，父目录一起建好，再把种子写到 `~/e31-newapps/e31-seed.png`。

有 6 道 selftest 自己仍 `import PIL`。它们是评分夹具，不是客机准备脚本。本机 Python 3.9 装了 Pillow，所以这 6 道也过了。换一台没有 Pillow 的 Python 跑 selftest，这 6 道会在 import 处失败。客机准备阶段不跑 selftest。这 6 道是：移除背景、移除工具、星形、模糊、导出透明 PNG、模板加图案。
