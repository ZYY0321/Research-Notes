# 给晨阳：代讲荧滢这周进展的一段话（约 1 分钟）

荧滢这周接了 Photoshop、Mail、Figma、飞书四个新应用，用 DeepSeek 按官方帮助文档一个功能出一道题。主题包是 196 道，到周一中午跑了 235 次，评分通过 71 次。不过目前确认能用的数据还是 0，原因是评分本身不可靠：现在的评分大多只检查尺寸、几个点的颜色和文件头，既会放过没做成的，也会误杀做成的。她实测过几种情况。Mail 草稿题，开跑前放一封旧草稿，模型什么都没做也能通过。Figma 新建文件被团队锁挡住，模型就改在别人的设计稿里画，照样通过。反过来，评分一收紧，有些本来就是单色的正确答案又被判成了失败。另外，评不了分的 115 道题，恰好是组件、协作、邮件规则这些核心功能。所以她这周后半段把重点放在了验证上：按结果存在哪里，分别想怎么取证，并和泽豪的读状态方案、鸣谦的评估口径做了对照。具体的案例、验证方法和出题的问题，都在附件里。需要大家帮忙的有两件：一是收数据的标准，她写了一个提议，周五我们俩对一下；二是账号，这几个要登录的应用，数据能不能刷、能刷多快都卡在账号上，后面扩量需要测试号或者付费席位。
