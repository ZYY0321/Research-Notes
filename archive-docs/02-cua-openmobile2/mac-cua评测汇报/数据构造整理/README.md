# 桌面应用 GUI 训练数据的构造与质量把关

这里整理桌面应用这条线上，数据怎么构造、质量怎么把关。内容按主题组织：每个主题有一份文件，长期维护，有新的尝试和案例就补充进对应的文件。

## 可以对外展示的整理

- **《GUI 训练数据质量把关中的关键问题：出题、环境、验证与轨迹质量》**（`数据质量把关_重要问题_1125.md`）：按出题、环境与账号、结果验证、轨迹质量四个环节，讨论需要靠设计和决策来回答的问题。
- **《GUI 任务的结果验证：按结果的存放位置选择取证方式》**（`验证方法_按结果存在哪取证_1125.md`）：包括六类结果的取证方式、模型裁判的适用范围、评分器本身怎么测试，以及组内已有方案的借鉴之处和适用边界。
- **《桌面应用 GUI 训练任务的出题方法：现有做法、暴露的问题与可借鉴的方案》**（`出题方法_现状与差距.md`）：两轮出题的做法，暴露的问题，以及组内和公开基准可借鉴的方案。
- **《评分通过但不宜直接用于训练的轨迹：六类典型问题》**（`轨迹质量_bad_case辨析.md`）：每一类给出定义、案例、规模和处理建议。
- **《需要登录的桌面应用在数据生产中的共性障碍》**（`应用环境与账号.md`）：先讲各应用共有的问题，再分应用讲具体情况，最后列出需要的资源。
