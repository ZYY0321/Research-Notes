# 数据构造整理

这里是「桌面应用这条线的数据怎么造、质量怎么样」的常驻整理，按主题组织，不按周组织。

每个主题有一份主文件，常驻维护：每周的新尝试、新案例、新数字，都加进对应主题的文件里，并标上日期。周会材料只放当周的周报和口播；附件直接链接到这里的主题文件，不再每周新开一套附件。
