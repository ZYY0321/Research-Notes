# 桌面应用 GUI 训练数据的构造与质量把关

这里整理桌面应用这条线上，数据怎么构造、质量怎么把关。主文档按数据生产的阶段分：出题、环境与初始化、验证、质检，再加一份跨阶段的关键问题总览。每份长期维护，新的证据、调研、修改和新问题都补进对应阶段的文件，并在文末「更新记录」里按日期记一笔。

## 可以对外展示的整理（按阶段）

- **`00_关键问题总览.md`**：《GUI 训练数据质量把关中的关键问题：出题、环境、验证与轨迹质量》。跨四个阶段，讨论需要靠设计和决策来回答的问题，以及四个阶段背后的同一个原因。
- **`01_出题.md`**：《桌面应用 GUI 训练任务的出题方法：现有做法、暴露的问题与可借鉴的方案》。两轮出题的做法、暴露的问题，以及组内和公开基准可借鉴的方案。
- **`02_环境与初始化.md`**：《需要登录的桌面应用在数据生产中的共性障碍》。账号与登录、初始化状态，先讲共性问题，再分应用，最后是出路和需要的资源。
- **`03_验证.md`**：《GUI 任务的结果验证：按结果的存放位置选择取证方式》。六类结果的取证方式、模型裁判的适用范围、评分器本身怎么测试。
- **`04_质检.md`**：《评分通过但不宜直接用于训练的轨迹：六类典型问题》。每一类给出定义、案例、规模和处理建议。
