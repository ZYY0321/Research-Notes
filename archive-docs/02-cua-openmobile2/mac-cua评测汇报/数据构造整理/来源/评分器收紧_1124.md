# 改了什么

全透明：RGBA 里每个像素的 alpha 都是 0，0 分。颜色类型仍要是 6，没有 alpha 通道的 RGB 还是 0 分。环、蒙版这种有不透明像素的图过。

单一颜色：整张只有一种颜色，0 分。有抽样点时，抽样点以外如果只剩一种颜色（或者第二种颜色不到 2 个像素），也是 0 分。左半红、右半蓝这种图过，因为抽样点以外两种颜色都有一大片。

署名：`require_app_signature` 为真，或者题注写了要 Photoshop 署名 / 由 Photoshop 生成，或者成品文件名以 `ps-` 开头，文件里必须有原来的 Photoshop 署名。题注写「不核 Photoshop 署名」的 Figma 题不加这条，否则真的 Figma 导出会被打成 0。

文件本身：PNG 要魔数、`.png`、块的 CRC、IHDR 在前、IEND 在最后、后面没有多余字节。JPEG 要 `.jpg`/`.jpeg`、开始标记、SOF 尺寸、SOS 之后至少有一段扫描数据、文件以结束标记收尾。PSD 要 `.psd`、`8BPS` 版本 1、宽高和位深合法，颜色区、资源区、图层区的长度要落在文件里，并且后面有压缩方式为 0–3 的图像数据。标记文字要出现在图层区里（图层名或文字引擎数据），接在文件末尾不算。CC 2014 样例署名仍然是 0。

prefix：TIFF 要 `II*\0`、版本 42、IFD 放得下。PDF 至少 64 字节，并且有 `trailer` 或 `startxref`，以及 `%%EOF`。SVG 要有 `>` 和 `</svg>`。`8BPS` 开头的当 PSD 查整段结构。一份最小的合法 PDF、TIFF、SVG 用新库打是 1 分；文件头后面接 `THIS IS NOT A REAL DOCUMENT` 是 0 分。

整句：`contains` 如果是字符串，整句都要连续出现。三处都在这一处收口。

1. `mail-2-6-mail-mailbox-delete` 的 `'DELETED'`。`DELTA` 是 0，`DELETED` 是 1。
2. `mail-2-6-mail-mailbox-create-sub` 的 `'MBOX=E31P26/E31S26'`。字符用竖线拆开是 0，整行在是 1。
3. `figma-7-export-svg-editable-text` 的 `'<text'` 和 `'E31 Editable'`。散字符是 0。一份 `<svg ...><text>E31 Editable</text></svg>` 是 1。
