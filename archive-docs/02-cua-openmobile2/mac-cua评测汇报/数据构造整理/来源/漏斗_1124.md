## 口径

一行是一个「题 × 批次 × attempt」。同一道题跑了两次，就是两行。`summary.csv` 只留最后一次，这份表不跟它折。

`summary.csv` 里 `attempts=0`、磁盘上还没有 `attempt-00N` 目录的，是写进批次、还没派出。这样的题 19 道，不在下面的 235 里。Mac1 的 `e31-ds-sfb-ps-smoke-r1-1122.bak-lockonly-1122` 只有空锁文件，也没有算。

阶段是嵌套的：后一格一定是前一格的子集。

| 阶段 | 怎么算 |
|---|---|
| 派出 | 生产机上有 `tasks/<题>/attempt-00N/`，或集群已拉取 JSON 里有 `attempt` 字段 |
| 开跑 | `agent` 不是 `not_started`，也不是空。`running`、`completed`、`agent_error`、`timeout`、`supervisor_error`、`interrupted` 都算开跑 |
| 做完 | `agent=completed` |
| 有 Sky session_end | 做完，并且没有 `gui_evidence_failed`。生产机还要求 Sky 日志里有 `"phase": "session_end"`。两台机器上，做完的 48 行这两条是齐的：没有这条失败码的 37 行都有 `session_end`，有这条失败码的 11 行都没有。集群 128 份 JSON 里没有 `session_end` 这几个字，这一格用 `materials.gui_events` 不是 `failed` |
| 有分 | 上一格，并且 `grade=graded`，分数可以是 0 |
| 1 分 | 有分，并且分数是 1 |

`gui_events=missing` 不算 `gui_evidence_failed`。有的 1 分题没有界面调用，Sky 日志仍有 `session_end`，例如 night2 的 `mail-draft-recipient`。

题包按每行 `task.json` 开头认，对得上启动命令：

- `v1`：题面直接从「Adobe Photoshop」或「Mail 已经打开」起句，没有命令行前缀。目录是 `zyy-e31-newapps-v1`。不并进 v1-cli。
- `v1-cli`：开头是「优先用命令行完成，包括 AppleScript」。
- `v2-cli`：开头是「能用终端就先用终端」，题号是短名（`ps-canvas-resize`、`mail-draft-save` 这种）。
- `gen-v1p`：题号是 `ps-2-`、`mail-2-`、`figma-2-` 这类，批次不是 v2f。
- `gen-v2f`：批次 `e31-ds-sfb-v2f-figma-main-1124`。

应用按题号前缀：`ps-`、`mail-`、`figma-`。
