## 每一道怎么自己核对

下面每道三步。PSD 题的第 1 步相同：看文件头，再用评分库把标记打出来。第 3 步在客机上用 Photoshop 打开同一份文件，看图层面板。面板里有、打印出来没有，就是解析和真文件不一致，这道先不要当可评分。不要在这台开发机上打开 Photoshop。

把 `PATH` 换成收回来的那一份文件：

```python
import sys
sys.path.insert(0, "/Users/zhangyingying/CUA/评测集建设/maccua-tasks/zyy-e31-gen-v3s/shared")
import e31_grade_psd as P
path = "PATH"
data = open(path, "rb").read()
print("magic", data[:4])
doc = P.parse_psd(data)
print("mode", doc["mode"], "channels", doc["channels"], "color_bytes", len(doc["color"]))
print("resources", sorted(doc["resources"]))
print("layers", [sorted(key.decode("latin1") for key in layer) for layer in doc["layers"]])
print("has_1057", 1057 in doc["resources"])
```

`magic` 应是 `b'8BPS'`。`has_1057` 应为 True。读者字符串里应能看到 Photoshop 和 2020 年及以后的版本，而不是 `CC 2014`。

1. 对 `ps-2-7-ps-adjustment-fill-layer.psd` 跑上面的脚本。
2. `layers` 里应出现调整或填充键之一，例如 `brit`、`curv`、`levl`、`SoCo`、`GdFl`、`PtFl`。只有空的图层字典，就是没做成。
3. 在客机里打开这份 PSD，图层面板应有一个调整或填充图层。面板是普通像素图层、脚本却打印出上述键，或反过来，这条评分先停用。

3. 在客机里打开，图层面板的效果应是投影。若 Photoshop 把投影写成了别的键，脚本的 `layers` 里看不到 `DrSh`/`dsdw`，这条评分先停用。

### ps-2-8-artboard-properties

这道不读 PSD。题面交的是 PNG，评分只看导出图是不是 800×600、是不是 Photoshop 写的。一份随便做成 800×600 的 Photoshop PNG 也会过，它证明不了画板矩形被改过。

1. 确认文件是 `ps-2-8-artboard-properties.png`，前 8 字节是 PNG 签名（`89 50 4E 47 0D 0A 1A 0A`）。
2. 用标准库读 IHDR：宽高两个 4 字节大端整数应是 800 和 600。再在文件里找文本块，应含 `Adobe Photoshop` 和 2020 年及以后的版本。
3. 在客机里看导出图的像素尺寸。尺寸对、但画板其实不是 800×600，说明这道评分太松，先不要把它当成「画板属性改对了」。

读宽高：

```python
import struct
data = open("ps-2-8-artboard-properties.png", "rb").read()
assert data[12:16] == b"IHDR"
width, height = struct.unpack(">II", data[16:24])
print(width, height)
```

### ps-2-10-ps-save-load-selection
