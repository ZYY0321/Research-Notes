## 二、第三批：小浣熊数据扩充（86,471 张）

### 数据来源

内容页仍然来自**小浣熊回流的 36,571 页 PPT**（与第一轮相同），但每页搭配 3 个新的设计风格生成不同视觉效果的图片。

### 设计 prompt 来源

在第一轮 795 条设计 prompt 基础上，新增外包收集的 266 条，扩充至 1,061 条：

| 设计来源 | 数量 | 说明 |
|----------|-----:|------|
| L2 蒸馏 | 495 | 外部 19,150 条 prompt 经规则+LLM 两步蒸馏 |
| L3 人工精拆 | 300 | 高质量手工拆解 |
| 外包收集（0608） | 266 | 外包整理的高相关设计 prompt |

### 合成方式

每页随机抽 3 个候选设计 → LLM（Claude）选最佳匹配合成英文生图 prompt → gpt-image-2 生图。若 LLM 认为候选都不合适则退回通用 prompt。

### 生成情况

| 指标 | 数值 |
|------|-----:|
| 总任务 | 109,713（36,571 页 × 3） |
| 生图成功 | 86,471（78.9%） |
| 生图失败 | 22,206（主要被安全策略拦截） |
| 耗时 | 27.9 小时 |

**关于失败率 20.3%**：LLM 合成的 prompt 中有部分触发了 gpt-image-2 的内容安全策略（content policy），这在第一轮中也存在但比例较低。主要原因是设计池扩大后，部分设计描述与内容组合产生了敏感内容判定。

**关于通用退回**：约 32% 的任务 LLM 未选中任何候选设计，退回通用 prompt 生图。这部分图风格较为单一，且与第一轮通用退回的图可能存在重复（约 3,601 页两轮都退回了通用）。

### 输出

- 原始路径：`/data/ppt_distill/route_a_x3/`
- 上传包：`/data/ppt_distill/upload_20260622/standard_mode_expansion_20260622/images/G6-XX/`
- 命名：`std_{G6编号}_{ppt_id前12位}_p{页码}_s{slot}.png`
- meta：`meta_route_a_20260622.jsonl`

## 四、meta jsonl 字段说明

与第一轮格式一致，主要字段：

| 字段 | 说明 |
|------|------|
| `source` | `standard_mode_expansion` |
