### 分类方法（两批共用同一套逻辑）

采用**规则前置 + LLM 兜底**两级，兼顾准确率与成本：

1. **规则前置**（不调 LLM，快且准）：对版式特征明确的页面用 `page_type` 字段 + 标题关键词直接判定——
   - 封面/标题页 → G6-01；目录/大纲 → G6-02；"第X章/PART N" → G6-03；"谢谢/THANKS/THE END" → G6-13
   - 标准模式因无独立 page_type 字段，规则命中率较低（~3%），其余交给 LLM
2. **LLM 分类**（claude-sonnet-4-6，temperature=0）：规则未命中的页面，喂入 PPT主题+页面标题+内容/配图摘要，输出 `{label, confidence, reason, secondary_label}`。带 ≤15 次重试，多层 JSON 容错解析，超限兜底 G6-05。

**关键消歧规则**（写进 LLM 提示词，是分类质量的核心设计）：
- **G6-04 vs G6-05**：有大尺寸内容图 → G6-05；仅小图标/色块/纯文字列表 → G6-04
- **G6-06 优先**：只要含坐标系图表（柱/折/饼/雷达），无论多少文字/几栏，一律 G6-06
- **G6-07 对比页**：多栏 ≠ 对比！必须是同类事物横向对比（方案A vs B、优势/劣势）；并列展示归 G6-05/G6-09
- **G6-09 流程页**：必须有方向性/层级（箭头、Step序号、组织层级）；无箭头的并列卡片归 G6-05
- **G6-13**：只限纯致谢/结束页；总结/结论/展望归 G6-05/G6-11

- 置信度：标准模式 high≈88%、medium≈12%、low<0.1%
- 已知局限：**G6-04(纯文字) 与 G6-05(图文混排) 存在一定混淆**（版式边界本身模糊），两批一致，不影响整体可用性。

## 三、meta jsonl 字段说明

每行 = 1 张图的完整信息（图片路径 + 分类 + PPT来源 + 蒸馏中间结果）。

**通用字段**：
| 字段 | 说明 |
|------|------|
| `source` | 数据来源：`creative_mode` / `standard_mode` |
| `image_path` | AOSS 绝对路径（`s3://ppt-data/ppt-image-distill/...`） |
| `image_name` | 文件名（创意 `cm_` 前缀 / 标准 `std_` 前缀，两批不撞） |
| `g6_label` / `g6_label_name` | 13类编号 / 中文名 |
| `g6_confidence` | 分类置信度 high/medium/low |
| `g6_secondary_label` | 第二版式：一页同时具两种版式时记次要那个（如"图表+对比"→主G6-06、次G6-07）；多数页为 null |
| `g6_reason` | 分类依据（一句话） |
| `ppt_id` / `ppt_title` | 源 PPT 标识 / 主题 |
| `page_idx` / `page_title` | 页码 / 页面标题 |
| `image_prompt` | **生图提示词全文**（两批统一字段；创意模式从源回填） |
| `image_model` | `gpt-image-2` |

**标准模式额外字段**（蒸馏管线中间结果，创意模式这些字段为空）：
| 字段 | 说明 |
|------|------|
| `content_text` | 页面结构化内容 |
| `design_tier` | 设计来源层级：L3(人工精拆)/L2(蒸馏)/generic(通用兜底) |
| `design_asset_type` | 设计类型（infographic/report/...） |
| `chosen_design_id` / `chosen_reason` | 选用的设计prompt id / LLM选择理由 |
| `design_text` | 选用的设计参考文本 |

## 五、两批数据的生成管线

### 5.1 创意模式管线

思路：复用小浣熊创意模式回流的**单页生图 query 原文**，重新生图 + 分类，沉淀为带标签的数据集。

```
小浣熊回流数据(3,655套 / 20,283页)
   ↓  提取单页 image_prompt 原文(回流自带的完整生图query)
   ↓  规则+LLM 13类分类
gpt-image-2 重新生图 → 18,197 张带分类成品
```

- 特点：query 是回流原生的、信息密度高（平均数千字）；图与 query 一一对应。
- 产出落在 `images/G6-XX/`，metadata 记录分类+来源；本次交付已从源回填 query 全文到 `image_prompt`。

### 5.2 标准模式管线

思路：PPT 回流只有**内容无设计**，需外接设计 prompt 库，由 LLM 合成完整生图 query。

```
PPT回流内容(36,573页, 有内容无设计)
   ＋
外部设计prompt库  L3(300条人工精拆) + L2(19,150→规则粗筛732→LLM蒸馏495条)
   ↓  每页抽5候选(保底2条L3) → Claude择优合成 → 候选全不合适则通用兜底
英文生图prompt → gpt-image-2 → 13类分类
```

- L2 蒸馏：外部 prompt 库质量参差，经"规则粗筛(正向词≥2且无负向词) → LLM逐条判可用性并蒸馏成纯设计卡"两步，19,150 条精炼到 495 条可用设计。
- 设计来源占比：L2蒸馏 74.3%（25,093）、通用兜底 13.3%（4,484）、L3人工 12.5%（4,207）。
