## 如何按本文获取数据

| 步骤 | 做什么 |
|:----:|--------|
| 1 | 在本文找到目标数据的 **meta**（AOSS 路径或落地路径） |
| 2 | Query 类读 `attachments[].aoss_path`；图片类读 `image_path` |
| 3 | 走 AOSS：对路径字段用 `ads-cli cp` / `sync` 拉取；或走数据服务器：直接打开落地目录 |

```bash
# AOSS：下载单个对象（AK/SK 自行替换）
ads-cli cp \
  's3://<AK>:<SK>@ppt-data.aoss.ms-sc-01.maoshanwangtechapi-oss.com/<对象路径>' \
  ./目标文件名

# AOSS：同步目录
ads-cli --threads 20 sync \
  's3://<AK>:<SK>@ppt-data.aoss.ms-sc-01.maoshanwangtechapi-oss.com/<目录前缀>/' \
  ./目标目录/
```

## 三、蒸馏图片

### 数据来源与背景

在回流 PPT 内容（及外部设计 prompt）基础上，用 **`gpt-image-2`（1536×864）重新生图** 得到的训练用页图，并打版式标签。  
**不是**产品侧用户看到的回流原图；AOSS 前缀为 `ppt-image-distill/`，与第二节 `ppt-image-back-*` 分开存放。

| 批次 | 数据来源 | 图片数 | AOSS 路径 |
|------|----------|-------:|-----------|
| 一 创意模式（0615） | 小浣熊创意模式回流单页 query，按原生 image_prompt 重生图 | 18,197 | `ppt-image-distill/creative_mode_20260615images/` |
| 二 标准模式（0615） | 回流页内容 × 外部设计 prompt，经 LLM 合成生图 query 后生图 | 33,784 | `ppt-image-distill/standard_mode_20260615images/` |
| 三 标准扩充（0622） | 与第二批相同的 36,571 页内容，每页再配 3 种设计风格生图 | 86,471 | `ppt-image-distill/standard_mode_expansion_20260622/` |
| 四 视觉设计直出（0622） | 外部 prompt 池筛选海报 / 品牌 / 插画等视觉设计类，直接生图（非 PPT 页） | 6,639 | `ppt-image-distill/visual_design_20260622/` |
| **合计** | | **145,091** | |

前三批按 G6 共 13 类版式标注（标题 / 目录 / 章节过渡 / 纯文字 / 图文混排 / 图表 / 对比 / 时间线 / 流程 / 矩阵 / 汇总 / 产品 / 致谢）；第四批按设计类型标注。

### Meta 与路径

每条 meta 含 `image_path`（指向 AOSS 图片）、`image_prompt`（生图全文）、`g6_label`（版式类）等。

| 内容 | 行数 | 落地路径 | AOSS |
|------|-----:|----------|------|
| 0615 合并 meta（创意 + 标准） | 51,981 | `docs/交付_0615/meta_ppt_image_distill_20260615.jsonl`（相对仓库 `benchmark/`） | 图片在上表四批路径；合并 meta 以落地文件为准 |
| 0622 合并 meta（扩充 + 视觉） | 104,585 | `docs/交付_0622/meta_ppt_image_distill_20260622.jsonl` | 同上 |

获取图片：用合并 meta 中的 `image_path`，对 `ppt-image-distill/` 执行 `ads-cli cp` / `sync`；或在数据服务器上按 meta 对照 AOSS 已同步的蒸馏目录使用。

更细的字段与分类口径见：`0615_数据汇总_PPT图像蒸馏.md`、`0622_端午数据扩充汇总.md`。
