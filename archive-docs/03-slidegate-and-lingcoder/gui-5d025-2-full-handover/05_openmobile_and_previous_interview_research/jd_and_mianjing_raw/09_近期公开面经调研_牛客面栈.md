## 4. 八股 / 认知题：按主题归并（备考用）

### A. 对齐与 RL（算法面必杀）

- SFT vs DPO vs PPO/GRPO；为何 Agent 常先 SFT 再 RL  
- GRPO：组内均值/方差 → advantage；全对全错无梯度 → 动态采样 / DAPO  
- PPO clip：Advantage 正负哪侧约束  
- GSPO / DAPO 各改什么（能讲一句即可）  
- reward hacking：发现（reward↑人评↓）、止血、根治  
- 多轮 Agent reward：格式 / 最终 / 过程；工具失败计分；截断轨迹  
- 信用分配、熵崩溃、pass@1 vs pass@k  
- 蒸馏被封 → 自评测可验证任务 + 合成数据 + online RL  

### B. Agent / Harness / Skill / Memory（你 JD 主场）

- ReAct 一步：Thought → Action → Observation；终止条件  
- Harness 覆盖：任务环境、loop、工具权限、上下文、轨迹、评测  
- Skill vs Agent；Skill 逐步执行如何约束；Skill 太多上下文爆炸  
- 单 vs 多 Agent；通信如何可验证（结构化消息 > 纯自然语言）  
- 工具失败：可重试 vs 不可重试；重复调用抑制；max steps  
- 记忆：短/长/过时；压缩触发；异步压缩减感知延迟  
- 评测：成功率 vs 过程指标（工具正确率、无效步、成本、时延）  

### C. 基础与推理（组不同深浅）

- Attention 数学；多轮 Agent 下的局限（二次复杂度、长程依赖稀释）  
- KV Cache、GQA/MLA、FlashAttention、prefill/decode、vLLM（能讲原理即可）  
- LoRA / 全参；训推不一致（MoE+RL 更敏感）  

### D. RAG（应用/淘天常见）

- 切分、混合召回、rerank、RRF  
- 评估：检索命中、生成忠实度、端到端任务成功率  
- 「命中检索仍幻觉」分层定位
