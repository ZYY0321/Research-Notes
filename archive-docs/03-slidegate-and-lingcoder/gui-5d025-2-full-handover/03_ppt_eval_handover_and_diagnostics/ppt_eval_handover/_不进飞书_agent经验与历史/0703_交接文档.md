## 4. 跑批前必做：探活（doc §8，省得白跑一批）

**教训**：本轮第一次跑成功率只有 ~9%，根因是端点重启前处于异常状态（连得上但 HTML 生成静默失败）。重启后同配置一跑就是 91%。所以**每次跑前务必探活三步**：

```bash
export PATH="$HOME/.local/bin:$PATH"

# ① 沙盒通不通
uv run python -c "from tools.sandbox.sdk.client import SandboxClient; print(SandboxClient('http://10.210.0.52:3000',30).health_check())"

# ② 模型端点在不在 + 出文本（注意用 677）
curl -s http://10.210.9.11:677/v1/models
curl -s http://10.210.9.11:677/v1/messages -H 'content-type: application/json' -H 'anthropic-version: 2023-06-01' -H 'x-api-key: dummy' \
  -d '{"model":"flash-lite-v36-fp8-step4k","max_tokens":256,"messages":[{"role":"user","content":"say PONG"}]}'

# ③ 【最关键】沙盒内部能否连到模型（本机能连≠沙盒能连）
uv run python - <<'PY'
from tools.sandbox.sdk.client import SandboxClient
c=SandboxClient('http://10.210.0.52:3000',60); sid=c.create_session().session_id
code='''
import urllib.request,json
body=json.dumps({"model":"flash-lite-v36-fp8-step4k","max_tokens":256,"messages":[{"role":"user","content":"say PONG"}]}).encode()
req=urllib.request.Request("http://10.210.9.11:677/v1/messages",data=body,headers={"content-type":"application/json","anthropic-version":"2023-06-01","x-api-key":"dummy"})
try:
    r=urllib.request.urlopen(req,timeout=30); print("SANDBOX->MODEL OK",r.status)
except Exception as e: print("FAIL",type(e).__name__,str(e)[:120])
'''
print(c.run_code(session_id=sid,code=code).stdout)
PY
# 三步都 OK 才开跑。
```

## 5. 跑批命令

```bash
cd /home/gui-5d025-2/zyy/xhx_agent_v3
export PATH="$HOME/.local/bin:$PATH"
bash batch_run_test.sh        # 打印 OUT=output/testset_v2_<ts> PID=...
```

`batch_run_test.sh` 内部实际执行（照 doc §5 固化）：
```bash
uv run python scripts/run_batch_and_export.py \
  --input  data/added/ppt_testset_industry_balanced_v2.jsonl \
  --output output/testset_v2_<ts> \
  --config conf_v3_zh_flashlite_step4k_20260702.yaml \
  --concurrency 4 --max-turns 8 --seed 42 \
  --disable-tools web_search,image_search,image_generation,fetch_url,image_vqa,rerank_texts \
  --disable-skills deep-research
```
- 覆盖输入/配置：`INPUT=xxx.jsonl CONFIG=xxx.yaml bash batch_run_test.sh`
- `--disable-tools/--disable-skills` 是禁用的正道（别写进数据）。deep-research 是技能，必须用 `--disable-skills`，disable-tools 管不到。
- 断点续传：同 `--input/--output` 加 `--resume`，只重跑 infra_failed/killed。

## 8. 结果解读 / 已知现象（不是环境 bug，别误判）

- **图片显示占位符/裂图**：两种原因，都非环境问题。
  ① 跑批禁用了图片工具（image_search/generation/vqa），模型没法配图 → 留 placeholder（doc 规定的跑测条件）。
  ② 模型自己瞎编外部图片 URL（360/百度/天眼查等）→ 失效或跨域，加载不出（模型能力问题）。
- **排版换行 / 配色对比度低 / 字看不清**：模型生成 HTML 时写死的内联样式，页面零外部依赖 → 是模型视觉生成能力问题。流程里的视觉复核（阶段6 review）会跑、也能发现问题（生成 page_xxx.review.md，打分/判 needs_rewrite），但模型重写（阶段7）常修不好。
- 单 case 耗时波动大（十几秒到 70 分钟）：慢的多是走完整链路（生成+复核+重写），快的多是早退。
