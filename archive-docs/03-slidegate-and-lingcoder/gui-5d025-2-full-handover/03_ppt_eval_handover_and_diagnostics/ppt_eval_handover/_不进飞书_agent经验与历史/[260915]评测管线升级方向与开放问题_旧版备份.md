## 一、当前生产管线是什么

**旧版三维体系**，代码在 `benchmark/aggregator.py` + `benchmark/evaluators/`：

```
overall = page × 0.30 + deck × 0.35 + content × 0.35

checklist   = 0.20×L0 + 0.35×L1 + 0.45×L2
content     = 0.60 × checklist + 0.40 × faithfulness  （有可读源材料时）
content     = checklist                                （无源材料时）
```

- **L0**：内容/模块是否存在
- **L1**：内容是否具体（有细节，不只是标题）
- **L2**：重点/逻辑/受众适配是否合理
- **faithfulness**：有附件时内容是否有来源支撑

固定 checklist 库（`checklist_lib/industry_v2/`）是 bug 修复而非实验——之前动态生成导致不同模型用不同 checklist，分数不可横向对比；修复已在生产中。

## 二、"字多打不出"问题

这是当前管线最重要的已知问题。

**现象**：L1/L2 倾向于认为"内容越具体越好"，字多的 PPT 得分偏高，但字多的 PPT 视觉往往很差，实际用户体验也未必好。

**数据支撑（H3 实验）**：旧 `content_checklist_score` 与人类系统排名的 Spearman 相关只有 **0.455，且不显著**，是当前所有维度里对齐最差的。

**vNext 是否缓解了这个问题？**  
→ **部分缓解，但未根治**。vNext 新增的 must-cover 覆盖率（占内容分 30%）关注的是"必要内容有没有讲到"而不是"讲了多少"，这在方向上能抑制纯堆字。但 L0/L1/L2 仍占 70%，L1/L2 的评价方式未改变，字多问题仍然存在。  
→ 根本解决需要在 L2 中明确加入"简洁精准"的正向评价，或引入字数/密度惩罚项，这还没做。

详见：`benchmark/handoff/[260708]机器打分可靠性排查与内容分修复.md`

## 四、vNext 设计（完整但未进生产）

设计文档：`benchmark/handoff/[260824]下一版评测流程与计分方案_vNext.md`

### 4.1 新增指令遵循维度

独立评分，不进当前 overall；vNext 候选给指令 20% 权重：

```
hard_rate = (hard_pass + 0.5×hard_partial) / judgeable_hard
# 代码可判（页数/宽高比等）优先覆盖 LLM 判定
```

### 4.2 内容分改法

```
内容检查表_vNext = 0.70 × 旧L0/L1/L2检查表 + 0.30 × must-cover覆盖率
有源材料: content_vNext = 0.60 × 内容检查表_vNext + 0.40 × faithfulness
无源材料: content_vNext = 内容检查表_vNext
```

must-cover 是针对每道题预先生成"必须讲到的要点清单"，然后检查覆盖率，与 L1/L2 的"内容是否具体"是正交的。

### 4.3 流程改变

- 同一 query 三草案→合并→裁决→冻结，跨系统复用
- 全部原始页面分批输入，不抽样不拼页
- NA 门控：不可判的项记 NA，不进分母

## 六、实验体系（论文用，知会一声）

完整 E1–E18 实验总账见 `benchmark/handoff/[260824]实验总账_设置结果与Benchmark影响.md`。

主要结论一句话：指令/内容/视觉三维互不冗余（跨维 Spearman 0.09–0.29），视觉维度对齐最好（0.855），旧内容 checklist 对齐最差（0.455），vNext 方案在各子实验中均有验证支撑。

### 6.1 人评对局数：多少才合理

实际共评了约 **400 场**（pairwise 盲评）。以下是统计依据：

| 模型对数 | 每对场数（400 场均分） | 可可靠检测的最小胜率差 |
|---------|---------------------|----------------------|
| 1 对（2 个模型）| 400 | ≥ 7pp ✅ |
| 3 对（3 个模型）| ~133 | ≥ 12pp ✅ |
| 6 对（4 个模型）| ~67 | ≥ 18pp ⚠️ 中段名次不可信 |
| 10 对（5 个模型）| ~40 | ≥ 23pp ❌ 不够 |

**结论**：400 场对 3 个模型的两两比较是够的（能检测 ≥12pp 的胜率差）。如果参与比较的模型更多，中段排名的置信区间会很宽，不能下确定性结论，只能报置信区间。这也是论文中 H2 实验里"中段名次翻转"问题的根本原因——批次质量差异叠加样本量不足，中段名次不可信。

**人评机评一致性算法**：使用 Spearman 相关系数（系统级排名对比），参见实验总账 E4/E5。
