# PPT 模型产物 · 人工对比观察任务书（轻量版）

> 目的：机器打分有盲区（尤其内容质量、整体观感、"像不像人做的"）。这份任务**不打分、不逐题评委式评审**，
> 只借现成对比看板把几个模型的产物**横着摆一起看**，帮我们沉淀出每个模型**长什么样、毛病在哪、有没有比上一版进步**。
> 一次对比 20~30 分钟即可，产出就是一张"特点表"。

---

## 一、你要用的工具（不用装任何东西）

浏览器打开对比看板：**http://10.151.196.17:8770/** → 右上角点 **「↔ 跨版本对比」**

这个页面能做的事：
- 上方选一个 **case**（题目），下方**并排**显示 2~4 个模型对同一题产出的 PPT（逐页缩略图，横向摆）。
- 上方一排**版本 chip**，点一下勾选/取消要对比的模型 —— 一次建议只勾 **2 个**（左右对照最清楚），要看进步就勾"新版 + 旧版"。
- 「上一个 / 下一个」翻题；每个产物下方有它的自动分（总分/页面/全套/内容）供参考，但**以你眼睛看到的为准**。

> 一句话：选题 → 勾两个模型 → 左右对着看 → 记特点。

---

## 一点五、一次对比哪几个模型？（重要：别一次全上）

看板上有 7~8 个模型，**不要一次全摆一起排大榜**——人一次并排看 2 个最准，超过 3~4 个就看花眼、结论也不可靠。

**选法：先用机器分粗筛，再人眼精比少数几个。**

机器分不是全对，但**大趋势可信**：
- ✅ **可信**：页面渲染/成功率、总分的大档位（谁在第一梯队、谁垫底）。
- ⚠️ **不可信**：分差很小（几分以内）时的细排名，尤其"内容分"曾有口径 bug。

所以机器分负责**分档**，人眼负责**档内定胜负**。具体一次只比下面**一种**：

| 你想回答的问题 | 勾哪几个（2个为主） | 例子 |
|---|---|---|
| **新版有没有进步**（最常跑） | 新版 + 它的直接上一版 | step3k-DPO ↔ step3k |
| **机器分接近、分不出谁好** | 机器分差 < 3 分的两三个 | flash4k ↔ flashv1.1 |
| **怀疑机器分判错了** | 机器分说 A>B 但直觉存疑的两个 | 拉来人眼复核 |

**不用比的**：机器分档位差很大的（如第一梯队 Opus ↔ 垫底模型）——结论没悬念，省下来。

> 想要"全部模型总排名"时：用 **机器分定大档 + 人评定档内顺序** 拼出来，而不是让人一次并排 8 个。

## 二、你要交付什么（就一张表 + 一段小结）

**不需要**给每题打分。你只做两件事：

### 1. 每个模型攒一张「特点卡」
边看边往对应模型的卡片里丢观察。看够 10~15 题后，每个模型能总结出：

```
模型：<模型名，如 Flash-lite step3k DPO>
─────────────────────────────
👍 typical 优点（反复出现的）：
   - 例：配色统一、商务感强
   - 例：图表基本能对上数据
👎 typical 毛病（反复出现的）：
   - 例：右半页经常大片空白，版面左右失衡
   - 例：偶尔出现黄色占位色块 / 图片没填出来
   - 例：目录页文字被裁切
🔎 举证 case（能复现毛病/亮点的题号，2~3 个就够）：
   - q1289（占位色块）、q0206（右侧空白）、q0902（配图贴题，做得好）
一句话画像：<这个模型给人的总体印象>
```

### 2.（可选，看进步时）两版对照小结
如果是"新版 vs 旧版"，额外写一段：
- 新版明显**变好**的地方：____（附 1~2 个 case 号）
- 新版**反而变差 / 退步**的地方：____（附 1~2 个 case 号）
- 整体：新版更好 / 差不多 / 还不如旧版

> 就这些。有 case 号 + 一句话，就是好素材了。

## 三、看的时候重点盯什么（自动分看不出来的）

机器分对"页面渲染对不对"比较准，但下面这些**要靠你的眼睛**，也正是我们最想要的：

| 看点 | 具体问你自己 |
|---|---|
| **整体观感** | 扫一眼，像不像专业人做的？还是一看就"AI 感/半成品"？ |
| **内容实不实** | 文字是真有信息，还是套话/凑字/占位没填？跟题目要求对得上吗？ |
| **翻车点** | 有没有：空白大片、占位色块、图片没出来、文字被裁、排版错乱、每页风格打架 |
| **一致性** | 通篇像一套 PPT，还是每页像不同人做的？ |
| **进步感** | （对照旧版）同一题，新版是不是确实顺眼了/信息更足了？ |

**常见翻车点速查**（看到就记，是模型特性的关键证据）：
`右侧/左侧大片空白` · `黄色等占位色块` · `图片区域空白未加载` · `目录/正文文字被裁切` · `卡片错位叠压` · `各页配色/版式不统一` · `内容是空话套话` · `页数太少内容单薄`

## 四、操作示范（一次对比全流程）

1. 打开 8770 → 「↔ 跨版本对比」。
2. 版本 chip 只勾 2 个（例：`Flash step3k DPO` + `Flash step3k`）。
3. 选第 1 题，左右扫一遍缩略图；哪个顺眼、哪个翻车，往两张特点卡里记一笔（带题号）。
4. 点「下一个 →」，重复。看 10~15 题。
5. 收尾：把每张特点卡的优点/毛病归并成 3~5 条；写一句话画像；（如需）写两版对照小结。

**建议抽题**：不用 47 题全看。挑 10~15 题，尽量覆盖不同类型（工作汇报 / 宣传 / 教学 / 动画 等，题号旁有行业标签），够看出规律即可。

### 备注给内部
- 这套**不入库、不改看板**，产出是纯文本特点表，直接进周会/挑图素材。
- 想要更硬的结论（胜率数字、多人一致率）再说，先用这个轻量版跑一轮看够不够用。
- 自动分仅供旁参；已知机器"内容分"口径有过 bug（正在修/重判），**遇到自动分和你眼睛冲突，以眼睛为准并记下来**，这本身就是有价值的反馈。
