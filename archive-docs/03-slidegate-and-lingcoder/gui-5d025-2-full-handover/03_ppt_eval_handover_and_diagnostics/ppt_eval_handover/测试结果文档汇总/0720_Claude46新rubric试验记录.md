# 0720 Claude 4.6 新 rubric 试验记录

> 此文件的同步副本位于 `benchmark/docs/`，作为 benchmark 侧的实施记录；完整报告、原始分数和复跑入口均以 `评测任务文档/0720新rubric测试/` 为唯一文档入口。

## 1. 目的

验证“端到端评测维度”提出的新 rubric 是否能在既有 industry-balanced-v2 产物上工作，并与现有 `overall_score` 形成有效、方向合理的补充信号。

## 2. 实施内容

- 实现独立脚本 `scripts/eval_new_rubric_claude.py`，读取既有 benchmark JSONL 的 query/meta、渲染 PNG 与原 overall，调用 Claude Sonnet 4.6 评分。
- 评分维度固定写入 prompt：指令遵循、内容完整性、结构叙事、信息组织、排版设计、图表/图像质量、场景受众适配；无可靠源材料的事实性输出 N/A。
- 固定 20 题，对无模板 4 agent 评分 80/80，对模板 4 agent 的可用产物评分 76/76；支持并发、断点续跑与畸形 JSON 分数恢复。
- 模板源文件未提供给 judge，因此模板模式仅评最终产物质量，不评模板遵循。

## 3. 关键结果

| 范围 | 发现 |
|---|---|
| 新旧关系 | 无模板样本的新旧分 Pearson=0.365；同题最高分 agent 有 13/20 变化。 |
| 模式差异 | 同模型同题的 76 对样本中，无模板的新综合分平均高 0.09，63 对无模板更高、10 对模板更高、3 对相同。 |
| 维度信号 | 无模板−模板均差：指令 +0.59、完整性 +0.51、信息组织 +0.46、排版 +0.57、图表 +0.28、场景 +0.51。 |
| 风险 | 结构叙事和场景适配高分饱和；图表维度受题型影响大；等距 8 页抽样不适合判定未抽到页面的“缺失”。 |

## 4. 纠正性结论：当前不能用于模型排名

后续按“同模式、同题、模型配对”重新复核发现：无模板综合分的模型效应仅解释 1.7% 方差（case 效应 70.0%），模板模型效应仅 0.6%（case 效应 72.7%）；大部分模型 pair 的 95% CI 跨 0。因而此前的模板/无模板差异只能说明模式产物不同，**不能作为模型区分能力的证明**。

高分歧 case 还会受 8 页抽样和附件/模板未传入 judge 影响；低分歧 case 中存在肉眼可见页面质量差但总分相同的情况。当前结果不可用于模型总排名。

完整统计与人工复核见 `xhx_agent_v3/评测任务文档/0720新rubric测试/0720_模型间区分度复核.md`。

## 5. 后续

新 rubric 有合理的正向区分度，建议以“hard check 前置门槛 + 任务质量补充维度”方式接入试运行，暂不替换原 overall。下一步应：

1. 将约束 extractor 输出升级为结构化 `required/preferred` 元数据；
2. 各维加入固定 1/3/5 正反锚点，双判并复判大分歧；
3. 用全页/按章节抽样替换均匀 8 页抽样；
4. 扩展至全量 47 题、两种模式；模板模式传入模板源后再评模板遵循；
5. 事实性、兼容性、可编辑性、效率与合规接入源材料/PPTX/工程遥测后单列评分。

### 2026-07-21 全证据烟测补充

已在 q1585 实际接入两份 Excel、12 页模板参考和每个模型全部输出页（12–15 页）。四个无模板模型仍得到 0.960、0.980、0.990、1.000 的高分，第二次独立判分从 0.980 变为 0.998。结论：输入完整性问题已解决，但当前 1–5 锚点和单次 VLM 判分仍高分饱和，**不能用于模型比较**；下一步优先重写反例锚点和评分量尺，而不是直接扩跑题量。
