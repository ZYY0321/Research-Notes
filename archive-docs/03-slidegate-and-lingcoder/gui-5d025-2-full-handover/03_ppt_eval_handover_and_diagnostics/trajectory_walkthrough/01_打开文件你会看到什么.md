# 01 打开 `result.jsonl` 你会看到什么

样本：`/home/gui-5d025-2/zyy/xhx_agent_v3/output/testset_v2_loop2_qwen35-9B-decay-8753_tpl_20260928_190634/prod_26016eba/result.jsonl`

这是**一整份 JSON**（不是很多行小 JSON）。顶层键在本样本里是：

`case` · `id` · `input_text` · `message_records` · `messages` · `persisted_workspace_path` · `result` · `state` · `template` · `timestamp` · `tool_schemas`

## 逐个顶层字段（对照本样本）

| 字段 | 本样本里是什么 | 你要会说的话 |
|------|----------------|--------------|
| `id` | `"prod_26016eba"` | 题号 / case id，和目录名、`batch_summary.results[].id` 对齐 |
| `case` | 含 `query`、`session_id`、`supports_ask_user` 等 | 跑批入口塞进来的题目元信息 |
| `input_text` | `null` | 有的批次正文在这里；本样本题目正文在 `message_records` 的 `user_input` 里 |
| `message_records` | **65 条**结构化记录 | **读轨迹主战场**：谁说了什么、调了什么工具、子任务结果 |
| `messages` | 48 条 | 给模型看的「编译后对话」；排障优先看 `message_records`，更完整 |
| `tool_schemas` | `main` / `delegate` 两套工具说明书 | 主 Agent 与子任务可用工具不同；本样本 main 含 `read_file`、`execute_shell_command`、`create_subtask`、`ask_user` 等 |
| `persisted_workspace_path` | `.../output/sandbox/batch_prod_26016eba_c8cea4` | 沙盒工作区落盘位置；HTML/task_pack 在这里找 |
| `state` | 大状态快照 | 含再次嵌入的 `message_records`、`runtime_control`、`todolist` 等 |
| `result` | `success` + 最终 `response` 等 | 运行结束摘要；本样本最终 response 含 `<ppt_task_finished>` |
| `timestamp` | 结束时间戳 | 何时写完这份 result |
| `template` | `null` | 本字段在此样本为空；模板名在 user 题干「dark-green」和 skills 路径里 |
