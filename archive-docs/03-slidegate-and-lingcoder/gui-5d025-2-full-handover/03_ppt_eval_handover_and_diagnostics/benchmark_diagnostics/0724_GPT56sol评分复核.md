## 1. 公式：为什么人眼和总分对不上

```
page    = hard×0.35 + aes_fine×0.40 + aes_high×0.25
overall = page×0.30 + deck×0.35 + content×0.35   （有 content 时）
content = checklist（无源）或 0.60×checklist + 0.40×faithfulness（有源材料）
checklist = 0.20×L0 + 0.35×L1 + 0.45×L2
```

人眼扫看板/逐页 ≈ 主要看 **page（权重只 30%）**。  
总分里 **deck+content 占 70%**，打的是：整套结构是否完整、跨页是否一致、checklist 要点是否覆盖、有没有占位/破图/没改完。

notpl 47 题统计：

- 最弱维：**content 25 题 / deck 22 题**；page 几乎从不垫底  
- `page − content` 均值约 **+0.25**（页好看、内容分明显更低是常态）
