\section{Benchmark}
Each evaluation instance comprises a natural-language request, optional input materials, and structured metadata. Requests describe the topic, intended use, audience, and format. \emph{Parseable sources} are attachments from which the evaluation pipeline can extract text or structure, such as documents and spreadsheets. Images used only as visual references, or inputs without extractable evidence, are distinguished from these sources. Metadata records scenarios, input forms, and observable requirements for stratified analysis; it does not introduce additional scoring requirements.

SlideGate contains 40 tasks covering seven scenarios and five input forms (Table~\ref{tab:tasks}). Nine tasks combine multiple input types, and 12 have no attachments. The frozen instruction specifications contain 2,191 atomic constraints, approximately 55 per task. The main collection includes 240 decks from six commercial systems. Anonymous pairwise judgments by three professional designers support visual validation (Section~\ref{sec:validation}). Figure~\ref{fig:tasks} illustrates representative inputs and outputs.
