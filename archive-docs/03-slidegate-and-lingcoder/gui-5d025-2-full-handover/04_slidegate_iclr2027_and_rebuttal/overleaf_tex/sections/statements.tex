\subsection*{AI use statement}
Generative AI tools were used to assist with English translation, drafting and revising manuscript sections, literature retrieval, feedback on evaluation methodology, implementation and execution of supplementary analysis code, and interpretation of results. Model-based generation of candidate verification specifications, critique and merging, and output evaluation are components of SlideGate itself, as described in Section~4. The reported supplementary screening analysis was rerun and checked against the existing score records. These uses do not constitute independent human validation of model judgments. Responsibility for the manuscript, citations, experimental claims, and released artifacts remains with the authors.

\subsection*{Ethics statement}
The evaluation includes commercial-system outputs, source attachments, and human judgments. Materials intended for release require review for personal or sensitive information and redistribution rights. Model-generated failure labels should be interpreted within the stated evaluation scope; they are not a certification that a presentation is suitable for every downstream use. Human judgments and source materials should be released only within the applicable permissions.
