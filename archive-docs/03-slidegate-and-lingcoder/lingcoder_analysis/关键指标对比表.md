1. **software_engineering在所有任务上都表现不佳**
2. **algorithm_python和python_ds在多语言任务上下降明显**

### ✅ 推荐组合

**最优组合**: nonpython_ds + database + algorithm_python

- database: 多任务均衡
- algorithm_python: 科学计算任务有帮助
