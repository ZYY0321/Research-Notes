# LingCoder数据集有效性分析报告

## 一、实验设置概述

### 1.1 基线模型
- **qwen3-30b-a3b-Thinking-2507_from_sftalpha_9.3.6.1_1201v2_20251206_1000**
  - 作为对比基线，用于评估lingcoder数据的贡献

### 1.2 实验配置
- **基础训练配置**：400k base数据 + 100k lingcoder数据
- **训练步数**：800步和1000步（用于验证训练步数影响）

### 1.3 数据子集分类
根据context分类的lingcoder数据子集：
1. **算法相关Python** (`algorithm_python_1a`)
2. **算法相关Go**（新增）(`algorithm_go_1e`)
3. **数据科学相关Python** (`python_ds_2a`)
4. **非Python数据科学** (`nonpython_ds_2b`)
5. **数据库相关** (`database_3a`)
6. **软件工程相关** (`software_engineering_3b`) - 已更新
7. **base_only 1000步** - 作为lingcoder数据的对比基准

## 二、测试任务类型说明

### 2.1 核心代码生成任务
- **HumanEval plus**: 164个手写编程问题，评估基础代码生成能力
- **HumanEval X**: 多语言代码生成评估（包括Python、C++、Go、Java、JavaScript等）
- **MBPP_sanitized**: 约1000个Python编程问题，评估基础编程能力
- **LiveCodeBench**: 动态代码生成评估，包含v5和v6版本

### 2.2 专业领域任务
- **DS1000**: 1000个数据科学问题，涉及NumPy、Pandas等7个Python库
- **SciCode**: 科学计算代码生成任务
- **BigCodeBench**: 包含多个子类别（General、Computation、Visualization、System、Network等）

### 2.3 全栈开发任务
- **fullstackbench**: 全栈开发基准测试，包含多个子任务：
  - BP (Backend Programming)
  - AP (API Programming)
  - DA (Data Analysis)
  - MA (Machine Learning)
  - ML (Machine Learning)
  - SC (System Configuration)
  - DB (Database)
  - DW (Data Warehouse)
  - OS (Operating System)
  - MM (Multi-Modal)

### 2.4 代码修复任务
- **HumanevalFix**: 代码修复评估，支持多种语言（Python、JS、C++、Go、Java、Rust）

### 2.5 其他专业任务
- **CruxEval**: 代码生成评估基准
- **SWE-bench verified**: 软件工程验证任务
- **Terminal Bench**: 终端命令生成任务
- **数据分析64题**: 数据分析专项测试
- **金融tosql-端到端**: 金融领域SQL生成任务
