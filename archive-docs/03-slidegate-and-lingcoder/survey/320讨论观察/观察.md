## 总结

**现有评测系统存在三个核心问题：**

**1. 评分由单一缺陷主导，而非全面质量**

总分公式为 `overall = mean(维度) × (min(维度)/10)^0.5`，`min` 的惩罚权重极大。一旦某页出现截断，`technical_execution` 被打到 3 分，即使其他四个维度均为 9 分，总分也只有约 4.4 分。反之，若截断恰好未被检出，则可轻松得满分。这使得总分几乎等价于"有没有被发现的硬性错误"，无法反映真实的整体质量。

**2. Pass 0 的一次性判断决定一切，稳定性差**

流程完全路径依赖于 Pass 0 对缩略图（480×270）的初始判断：Pass 0 误判了什么，后续全过程就会沿着误判方向放大惩罚；Pass 0 漏掉了什么，整个流程就视而不见。没有任何机制能纠正 Pass 0 的误判或弥补其遗漏。

**3. 维度间高度耦合，一个缺陷被重复计分**

截断、图片变形等问题往往同时拉低 `instruction_following`、`aesthetics`、`technical_execution` 三个维度，导致单一缺陷的惩罚被成倍放大，各维度失去独立意义。美学维度因缺乏对布局均衡、元素对齐等细粒度标准的约束，系统性虚高。

**根因：**

- 总分公式将最低分作为非线性惩罚因子，对局部硬性错误过度敏感；
- Pass 1a 通过 3×3 contact sheet 进一步压缩分辨率，细粒度视觉问题（对齐偏移、空白过大等）难以被检出；
- 各 Pass 之间没有交叉验证，模型的"一眼判断"直接决定最终走向；
- 评分 prompt 中各维度定义存在语义重叠，模型在打分时自然关联同一缺陷，造成耦合。

**我们期望：**

评测系统能稳定、一致地区分 PPT 的真实质量差异，而不是靠"运气"——运气好没被发现截断就满分，运气差被误判图片变形就不及格。具体而言，希望评分对局部渲染错误有合理而非过激的惩罚，各维度保持相对独立，且有可复现的基准标准（如评分 rubrics 或人类偏好标注）来约束模型的主观判断，使评测结果对研究者和使用者都具有可解释性。
