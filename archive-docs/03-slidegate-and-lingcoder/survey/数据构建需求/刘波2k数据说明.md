## 2) 附件如何下载

有文件数据里，每条样本通常包含：

- `file_id`（附件 id）
- `file_name`（附件名列表）
- `file_url`（下载 URL 列表）
- `session_id`

`file_url` 是可直接下载链接。若链接域名是内网域名（例如 `internal.xiaohuanxiong.com`），常见做法是：

1. 请求 URL 时把域名替换为内网 IP；
2. 同时在 Header 里保留 `Host: internal.xiaohuanxiong.com`。

本目录脚本 `build_query_dataset.py` 已支持该逻辑，且把关键配置抽成常量，方便改头部：

- `INTERNAL_DOWNLOAD_HOST`
- `INTERNAL_DOWNLOAD_IP`

如果环境迁移，只需改这两个常量，不需要改其它下载逻辑。

## 3) 2k 不够时如何继续构建

可以沿着两条线扩展：

- **无文件样本扩充**：继续用 `prompt_gen` 管线生成（参考 `prompt_gen/demo_usage.py`）。
- **有文件样本扩充**：继续从回流里抽取（参考 `xhx_prompt_extractor/README.md` 三步流程：抽取 -> 处理 -> 场景分类）。

再把新增 JSON 放到同类目录，按同样方式合并即可（保持原始结构，不必强转固定 CSV 格式）。
