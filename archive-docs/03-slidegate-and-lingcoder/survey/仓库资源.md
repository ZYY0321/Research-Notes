PPTC

- 仓库位置：PPTC/。
- 资源情况：  
  - 包含 benchmark 逻辑、API 执行器与PPTX-Match 评估系统实现：src/、main.py、test/ 等。  
  - 数据集通过脚本从可行 API 序列生成 label PPT 文件：PPT_test_input/（输入）、PPT_test_output/、basic_run/ 等。
- 数据集规模：  
  - README 未直接给出样本数量；只区分 dataset short（新建页）与 dataset long（编辑模板），需要运行  
    - python3 PPTC/main.py --prepare --dataset long  
    - python3 PPTC/main.py --prepare --dataset short
    才在本地生成完整 label PPT。
- 评测框架代码：  
  - 有：PPTX-Match 评估系统 + turn/session 级指标：执行 LLM 生成的 API 序列生成预测 PPT，再比对 label PPT。  
  - 评估入口：python PPTC/main.py --eval --dataset=... --evaluation_name ... --model=...。
- 质量评估方式：  
  - 结构一致性：检查对象是否满足标注的空间关系。  
  - 属性内容一致性：对对象属性（文本、图形、布局等）与 Label 逐一比较。  
  - 汇总成 turn-based / session-based accuracy。
