# 训练配置和启动指南

## 流程概述

每个训练配置（1A-1F）需要两个步骤：
1. **配置数据**：运行 `generate_config_1X.py` 生成数据文件和训练脚本
2. **提交训练**：运行 `submit_debug.sh` 提交训练任务

   - `code_ablation_lingcoder_algorithm_<语言>_<配置编号>_v1.json` - 数据元信息配置

2. **训练脚本**：
   - `code_ablation_lingcoder_algorithm_<语言>_<配置编号>_v1.sh` - 训练启动脚本

## 注意事项

1. **数据配置必须先运行**：在提交训练任务前，必须先运行 `generate_config_1X.py` 生成数据文件
2. **检查数据文件大小**：生成后检查 `.jsonl` 文件大小，确保数据筛选正确
3. **资源分配**：确保集群有足够的GPU资源（32个GPU = 4节点 × 8GPU）
4. **训练脚本路径**：确保 `submit_debug.sh` 中的 `TRAIN_SCRIPT` 路径与生成的文件名一致

## 快速启动所有配置

如果需要依次配置并启动所有训练：

```bash
# 配置数据
for dir in train1A train1B train1C train1D train1E train1F; do
    cd /mnt/afs/zhangyingying/$dir
    python generate_config_${dir:5:2}.py
done

# 提交训练（建议逐个提交，避免资源冲突）
cd /mnt/afs/zhangyingying/train1A && bash submit_debug.sh
cd /mnt/afs/zhangyingying/train1B && bash submit_debug.sh
# ... 依次提交
```
