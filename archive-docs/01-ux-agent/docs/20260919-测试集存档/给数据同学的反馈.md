## 标注口径（和计分有关）

1. **信息流最后一张被底栏切到**：算截断，还是可滑动、不算缺陷？微博外屏、头条频道底排、B 站历史最后一条都是这种。我们会滑一下：滑完字完整就消解，滑完还缺再报。希望 GT 按「滑出来还缺才算截断」。
2. **官方省略号、搜索轮播、图片里的字**：继续当负例，不要补框（携程首页已经是这样）。
3. **同一列多条同样的右切/底切**（阔折叠携程右侧栏、钉钉两张顶卡）：框可以都留，我们按列滑一次。有 `group_id` 更好，没有也能做。
4. **s1/s2/s3 是不是一次采集的多屏**：双折叠 truncated 32 组都是 s1+s2 成对。请确认 `g0x` = 同一任务的外屏+内屏，不要把外屏当独立题。
5. **这次验收计分范围**：只计 `截断-文字`，还是图标/组件截断、遮盖也计？
