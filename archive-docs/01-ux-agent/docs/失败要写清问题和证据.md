# 失败要写清问题和证据

日期：2026-09-21。

原交接稿（`给人看.md` / `给AI.md` 的 run-log）只要求：页级 ok/bad、人眼一句话、秒数。  
**没有写清：** 合作方筛查/真机的产出不只是打勾，还要找出当前算法的问题、说明是什么情况、留下改进方向和全部证据。现补上。

## 测完一条，产出必须能回答这四句

1. **算法有没有问题？** 在哪一段：模型框 / layout / 滑动落点 / 回滑恢复 / 环境作废。
2. **是什么情况？** 例如：横滑点到邻芯片被当成点击；回滑等距冲过头；dump 绑不上字；App 改版切没了。
3. **后面怎么改？** 一句话改进方向。没有方向就写「暂无，证据如下」。
4. **证据在哪？** 路径写全，后人不用翻聊天记录。

筛查（不连设备）至少写清：正负例、切的类型和方向、**为什么大概会过/会挂**。真机还要附证据。

## 必须在最新算法上测

测之前 `git pull`。这边改完滑动/layout **立刻 push**。不要拿过期的 `slide-verify.ts` / `verifier.ts` 跑完再对不上。

## 每次检测目录里必须有的文件

`npm run ux-detect -- --mode=slide --case=<文件名>` 会在 `HarmonyArena-fdu_agent/ux-detect-output/<true_truncation 或 testset_0928>/<和测试集相同的相对路径>/<时间戳>/` 写下这些。日志第一级目录用英文。`--case` 用测试集文件名，不带后缀，例如 `bifold_image_truncated_sample_g01_s1`。没有 `--case` 时只会落在时间戳目录，这种结果对不上测试集。`ux-detect-output/` 不进 git，本机留着，路径写进 run-log。

| 文件 | 记什么 |
|---|---|
| `snapshot.png` | 滑之前的现场图 |
| `snapshot_window.json` | 布局 dump |
| `snapshot_ui-tree.txt` | 给人看的 UI 树 |
| `model_http.json` | 官方检测接口的完整返回。证明是我们的模型在推理 |
| `model_result.json` | 解析后的框，和模型这一段的客户端耗时 |
| `layout_result.json` | layout 对每个框的判定 |
| `slide_result.json` | 滑动后每个框留下还是消掉 |
| `slide-ops.jsonl` | 每次滑动的坐标、像素差、有没有回滑 |
| `snapshot_slide_*.png` | 滑后图。有回滑时还有 `.restore.png` |
| `snapshot_ux.json` | 上面几段的汇总，含 `apiConfig.baseURL` |
| `snapshot_bbox.png` | 模型框画在图上 |
| `snapshot_bbox_final.png` | 最后留下的框画在图上 |

`model_http.json` 里每一条 `responses[]` 至少要有这些字段，run-log 里照抄值，不要只写「调用了模型」：

- `image_path`：服务器收到图之后的临时路径
- `total_inference_sec`：服务器自己记的推理秒数
- `pred_text`：模型吐出的原文
- `used_instruction`：这次实际用的审查指令
- `parse_status`：例如 `valid_root_json`
- `inference_error`：没有错误就是 `null`
- `pred_json`：解析后的 `overall` 和 `issues`

校园网官方接口由 `UX_DETECT_HTTP_URL` 决定。不要用 `UX_DETECT_FIXTURE` 代替这次调用。备用对话接口没有上面这些字段，那种运行要在 run-log 里写明不是官方检测。

## 真机记录（算法有问题或 unknown/bad 时用这个，过了可简写）

```
### BF-某某-G0x-S2
- GT：/Users/.../测试集/整理/...jpg（完整路径）
- XML：有 / 无；有则写 .xml 完整路径
- 现场图：HarmonyArena-fdu_agent/ux-detect-output/<ts>/snapshot.png
- 页级：ok / bad / unknown / 作废
- 算法秒数：
- 哪一段：模型 / layout / 滑动 / 恢复 / 环境
- 什么情况：（两三句，具体到框、方向、diff）
- 改进方向：
- 证据：
  - 现场：.../snapshot.png
  - 模型原文：.../model_http.json（抄 image_path、total_inference_sec、parse_status、pred_text）
  - 模型框：.../model_result.json
  - dump：.../snapshot_window.json
  - layout：.../layout_result.json
  - 滑动：.../slide_result.json 、 slide-ops.jsonl
  - 滑后图：.../snapshot_slide_*.png
  - 恢复图：.../snapshot_slide_*.png.restore.png
  - 总结果：.../snapshot_ux.json
```

`ux-detect-output/` 不进 git，路径必须写在 run-log 里，本机先留着。

## 不要写成这样

- 只写 `unknown`，不说是回滑失败还是没滑到。
- 只写「过了/没过」，没有改进方向。
- 证据只丢一张 snapshot，没有 dump / slide-ops。
- 环境不对（改版、弹窗、无 XML）写成算法挂了。
