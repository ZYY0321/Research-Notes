## 3. 检测链路怎么讲（对着 SI-002 说，不要背算法名）

1. Oracle 确认关于页（标题、版本信息）。没到页，后面都不计 UX 分母。  
2. 模型只看最终一张图，出框。  
3. 框绑到布局节点；比较 visible bounds / origBounds / clip / 固定层。  
4. 仍不确定才滑动；滑完必须能恢复。恢复失败 → 保持 unknown。  
5. 固定底栏挡住、键盘层、WebView/Canvas、无 Text 节点 → 不升格为截断。

V01–V16 可以当“我们想过哪些坑”的附录，不要当准确率。离线 lab 100% 只说明规则自洽。

## 4. 拍板问题（带我方建议，让对方改而不是空想）

### 拍板 1：五种问题按现象互斥，还是按根因可叠加？

任务书写了大图大字、截断、拉伸、横屏、避让。标注 PDF 写的是截断 / 遮盖 / 溢出。两套词现在是拧的。

建议现场画这张表，请对方勾一列：

| 现象 | 主标签 | 不标成 |
|---|---|---|
| 半个字、半张图，像素不完整 | 截断 | 大图大字 |
| 内容画出容器但笔画完整、无 clip | 溢出 | 截断 |
| 前景盖住目标，目标节点 bounds 仍完整 | 遮盖；系统层再标避让 | 截断 |
| 字/图完整，但尺寸过大压住相邻操作 | 大图大字 | 截断 |
| 图/视频显示比例被非等比拉开 | 拉伸 | 大图大字、截断 |
| 正常省略号、正常换行、可滚出来的 | 不是问题 | — |

**大图大字建议写成三条，缺一不可：**

1. 文字或图片相对当前槽位 / 安全区明显过大或未随屏态缩放；  
2. 并且造成遮挡相邻、操作不可用、阅读顺序乱、或跨屏态无法使用；  
3. 字大但排得下、图大但完整适配 → **不是**大图大字。

争议样例就用 `fault_bigtext_press` vs `fault_bigtext_clip`：  
- 压按钮、字完整 → 大图大字  
- 被槽切掉 → 主标签截断，可选备注“字号过大”  
不要两个都打正例，否则 9 月 30 日会重复计分。

Nanbiubiu 老师说过横屏不独立成类、最终体现为大图大字或截断。请再确认 9 月 30 日还要不要单独的“未适配横屏”指标。

### 拍板 2：unknown 怎么进分母？

建议：

- unknown **单独列**，不算正确，也不算漏报；  
- 环境失败（锁屏、无数据、模拟器掉线、IME 打不进字）**不进模型分母**；  
- 没到页 **不进 UX 分母**。

SI-002 第一次 unknown 若算漏报，我们当时是错的；若算“证据不足正确弃权”，规则才站得住。
