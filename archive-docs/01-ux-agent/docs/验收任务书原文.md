# 验收任务书原文

guiagent 应用于多设备 UX 问题的高效检测工具设计文档

top225app 场景问题 支持复现 80%多设备 ux 问题，大图大字、页面截断、视频图片拉伸、未适配横屏、避让异常等。

UX 标准参考鸿蒙应用生态治理应用测试标准。覆盖设备类型包括折叠、双折叠、三折叠、平板等。

检测某个 APP 指定页面的 UX 问题。每个任务包含高级指令、低级指令：到达指定页面后，判断是否有 UX 问题；若存在，进一步判断 UX 问题类型。

其中，高级指令定义为对整个任务目标的概括性自然语言描述，仅定义要完成什么；低级指令定义为对任务中单个具体操作的自然语言描述，对应每一步要执行的单步动作。

我读一下：

在评测集每个任务中，当开发者以任务目标加低级指令作为任务输入时，正确到达页面的准确率应该达到95%。

当开发者以任务目标加高级指令作为任务输入时，正确到达页面的准确率应该达到80%。

在评测集每个任务中，成功到达检测页面后，GUI Agent 正确发现 UX 问题的准确率应大于等于95%。

在评测集每个任务执行中，GUI Agent 执行每个动作的响应时间平均小于等于3秒，单步最大响应时间不超过5秒。

排除网络和资源这类非模型因素，在检测被测 APP 的三层界面中的 UX 问题时，端到端时间小于等于10秒。
