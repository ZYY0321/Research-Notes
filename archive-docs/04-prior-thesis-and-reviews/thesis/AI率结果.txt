Abstract
With the rapid advancement of large language models and multimodal perception, mobile GUI Agents driven by model reasoning have emerged as a new paradigm in human-computer interaction. However, existing systems still face critical limitations in real-world scenarios involving ambiguous user instructions, cross-application collaboration, and long-term knowledge accumulation. This thesis presents the design and implementation of Fairy, an interactive multi-agent mobile assistant system. Fairy adopts a three-tier hierarchical architecture comprising a Global Task Planner, an App-Level Executor, and a Self-Learner module, and introduces a dual-loop execution mechanism that decouples action execution from user interaction to enable proactive intent clariﬁcation during task execution. At the perception layer, the system integrates accessibility tree parsing with Set-of-Mark screenshot annotation to provide structured visual information for decision agents. For memory management, a hierarchical memory scheme is developed, combining short-term working memory with long-term knowledge memory; the latter enables App-level experience reuse via a vector-indexed RAG retrieval pipeline. Additionally, this work contributes to the design of AmbiBench, an evaluation benchmark for mobile agents under ambiguous instructions, proposing a four-level instruction clarity taxonomy and the MUSE multi-agent evaluation framework that assesses agents across Outcome Effectiveness, Execution Quality, and Interaction Quality. Experimental results demonstrate that the proposed system signiﬁcantly outperforms non-interactive baselines in user requirement fulﬁllment and intent alignment, with particularly notable gains under ambiguous instruction conditions.
