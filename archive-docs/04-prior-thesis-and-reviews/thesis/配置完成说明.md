## 运行说明

### 启动项目（原项目方式）：
1. 激活虚拟环境：`venv\Scripts\activate`
2. 运行任务：
```bash
# 方式1: 直接使用命令行参数 (如README.md所示)
python fairy_starter.py --task "你的任务描述" --task-name "任务名称"

# 方式2: 使用任务运行器 (推荐)
python run_tasks.py run luckin_003 1

# 方式3: 查看所有任务
python run_tasks.py list
```

### 任务配置：
- 按照原项目README.md的设计，使用命令行参数传递任务
- 不需要HTTP服务器，直接通过 `--task` 参数传递指令

### 日志输出：
- 日志文件将按照 `taskid_详细程度` 格式命名
- 例如：`ctrip_003_1`, `luckin_003_2` 等
