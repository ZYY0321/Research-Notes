# 主流Agent 范式

- https://arxiv\.org/abs/2508\.13167

## 主流 AI Agent 范式总结

以下是当前几种最主流的 AI Agent 范式，它们各有侧重，并常常被结合使用。

### ReAct \(Reasoning and Acting\) 范式

**核心思想：** ReAct 是目前最基础和最经典的 Agent 范式之一，它将“思考”和“行动”两个过程显式地结合起来。 Agent 不会直接输出最终答案，而是通过一个“思考\-行动\-观察”的循环来逐步解决问题。

- **思考 \(Thought\):** Agent 首先进行推理，分析当前任务状态，并制定下一步的行动计划。

- **行动 \(Action\):** 根据思考结果，Agent 决定调用某个工具（如搜索引擎、代码解释器、API 等）来获取外部信息或执行某个操作。

- **观察 \(Observation\):** Agent 接收来自工具的返回结果，并将其作为新的信息输入，用于下一轮的“思考”。

这个循环会一直持续，直到 Agent 认为已经收集到足够的信息来给出最终答案。

**优点：**

- **透明度高：** 可以清晰地看到 Agent 的每一步推理过程和决策依据。

- **纠错能力强：** 如果某一步行动失败或结果不理想，Agent 可以在下一轮思考中调整策略。

- **可处理复杂问题：** 通过与外部工具的交互，能够解决需要实时信息或复杂计算的问题。

**代表框架：** LangChain 的早期 Agent 实现、HuggingFace 的 Transformers Agent 都深度应用了 ReAct 思想。

### 反思/自我批判 \(Reflection / Self\-Criticism\) 范式

**核心思想：** 这种范式在 Agent 完成任务或部分任务后，引入一个“反思”环节，让 Agent 自我评估其行为和结果的质量，并从中学习和改进。

- **执行：** Agent 首先尝试完成任务或一个子任务。

- **反思/批判：** 另一个或同一个 LLM 实例会对之前的执行过程和结果进行评估，识别出其中的缺陷、错误或可以改进的地方。

- **改进：** 基于反思的结论，Agent 会修改其计划或行动，然后重新执行，形成一个迭代优化的循环。

**优点：**

- **提升任务完成质量：** 通过自我校正，可以显著减少错误，提升最终结果的准确性和可靠性。

- **增强鲁棒性：** 能够处理初始计划不完美的情况，通过迭代来完善解决方案。

**代表项目：** 斯坦福大学的 "Self\-Refine" 和 a16z 的 "Self\-Correcting LLM\-Powered Agents" 论文都深入探讨了这一范式。

### 规划 \(Planning\) 范式

**核心思想：** 这种范式强调在执行任务前进行详细的规划。Agent 会首先将一个复杂的目标分解成一系列更小、更易于管理的子任务，然后按计划逐一执行。

- **任务分解：** Agent 接收一个宏大或模糊的目标，并将其拆解成一个具体的步骤列表或任务树。

- **计划执行：** Agent 按照预定的计划顺序执行每个子任务，通常每个子任务都可能是一个 ReAct 循环。

- **计划更新（可选）：** 在执行过程中，Agent 可能会根据实际情况动态地调整或更新后续的计划。

**优点：**

- **结构化：** 使 Agent 能够有条不紊地处理复杂的多步骤任务。

- **可预测性高：** 任务的执行路径更加清晰和稳定。

**代表项目：** BabyAGI 和最近的很多自主 Agent 项目都内置了复杂的任务分解和规划模块。

### 多 Agent 协作 \(Multi\-Agent Collaboration\) 范式

**核心思想：** 这种范式不再依赖于单个 Agent，而是构建一个由多个专门化的 Agent 组成的团队，它们各自扮演不同的角色，通过协作来共同完成一个复杂的任务。

- **角色分配：** 通常会有一个“管理者” Agent 负责任务分解和协调，并将子任务分配给不同的“专家” Agent（如“程序员 Agent”、“测试员 Agent”、“文案撰写 Agent”等）。

- **交流与合作：** 各个 Agent 之间通过共享的“记忆”或直接的消息传递来进行沟通，协同工作。

- **结果整合：** 管理者 Agent 最终将所有专家 Agent 的工作成果整合起来，形成最终的解决方案。

**优点：**

- **模拟真实世界的工作流程：** 非常适合模拟人类团队的协作模式，能够解决极为复杂的系统性问题。

- **提升专业能力：** 每个 Agent 都可以被精调（fine\-tuned）以适应其特定角色，从而达到更高的专业水平。

- **可扩展性强：** 可以通过增加新的专家 Agent 来扩展整个系统的能力。

**代表框架：** Microsoft 的 AutoGen 和最近大火的 CrewAI 是多 Agent 协作范式的典型代表。

### 总结与趋势

当前的趋势是**融合不同的范式**。一个先进的 Agent 系统通常会同时运用多种范式。例如，在一个多 Agent 系统中，每个专家 Agent 内部可能都在使用 ReAct 循环来执行其子任务，并且在完成任务后还会有一个反思环节来检查工作质量。规划则作为所有行动的起点，贯穿始终。
