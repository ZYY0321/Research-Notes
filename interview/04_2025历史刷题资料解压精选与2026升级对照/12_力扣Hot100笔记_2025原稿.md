## 一、哈希类

### 1\. 最长连续序列

#### 思路

1. 用哈希集合存储数组元素，实现O\(1\)查找。

2. 遍历每个元素，若当前元素是序列起点（前一个元素不存在于集合），则向后查找连续元素。

3. 记录最长连续序列长度，避免重复遍历已统计的序列。

#### C\+\+代码

```C++
#include <vector>
#include <unordered_set>
#include <algorithm>
using namespace std;

int longestConsecutive(vector<int>& nums) {
    unordered_set<int> numSet(nums.begin(), nums.end());
    int maxLen = 0;

    for (int num : numSet) {
        // 确保当前元素是序列起点
        if (numSet.find(num - 1) == numSet.end()) {
            int currentNum = num;
            int currentLen = 1;

            // 向后查找连续元素
            while (numSet.find(currentNum + 1) != numSet.end()) {
                currentNum++;
                currentLen++;
            }

            maxLen = max(maxLen, currentLen);
        }
    }
    return maxLen;
}
```

## 二、双指针类

### 2\. 盛水最多的容器

#### 思路

4. 左右指针分别指向数组两端，计算当前指针构成的容器面积（宽×高，高取两指针最小值）。

5. 移动较矮的指针（因为移动较高指针无法增加容器高度，仅可能减小宽度）。

6. 迭代更新最大面积。

#### C\+\+代码

```C++
#include <vector>
#include <algorithm>
using namespace std;

int maxArea(vector<int>& height) {
    int left = 0, right = height.size() - 1;
    int maxArea = 0;

    while (left < right) {
        int width = right - left;
        int currentHeight = min(height[left], height[right]);
        maxArea = max(maxArea, width * currentHeight);

        // 移动较矮的指针
        if (height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }
    return maxArea;
}
```



### 3\. 三数之和

#### 思路

7. 排序数组，便于去重和双指针操作。

8. 固定第一个数，用左右双指针在剩余数组中寻找和为目标值（\-nums\[i\]）的两个数。

9. 跳过重复元素（固定数和双指针移动时），避免重复三元组。

#### C\+\+代码

```C++
#include <vector>
#include <algorithm>
using namespace std;

vector<vector<int>> threeSum(vector<int>& nums) {
    vector<vector<int>> result;
    int n = nums.size();
    if (n < 3) return result;

    sort(nums.begin(), nums.end());

    for (int i = 0; i < n - 2; i++) {
        // 跳过重复的固定数
        if (i > 0 && nums[i] == nums[i - 1]) continue;
        // 剪枝：最小三数和大于0，后续无可行解
        if (nums[i] + nums[i + 1] + nums[i + 2] > 0) break;
        // 剪枝：当前数+最大两数和小于0，当前数不可行
        if (nums[i] + nums[n - 2] + nums[n - 1] < 0) continue;

        int left = i + 1, right = n - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum < 0) {
                left++;
            } else if (sum > 0) {
                right--;
            } else {
                // 找到有效三元组
                result.push_back({nums[i], nums[left], nums[right]});
                // 跳过重复元素
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++;
                right--;
            }
        }
    }
    return result;
}
```



### 4\. 接雨水

#### 思路

10. 双指针分别指向左右两端，维护左右最大高度。

11. 若左侧最大高度小于右侧，计算左指针位置的蓄水量（左侧最大高度\-当前高度），并移动左指针。

12. 反之计算右指针位置的蓄水量，移动右指针，迭代更新最大高度和总蓄水量。

#### C\+\+代码

```C++
#include <vector>
#include <algorithm>
using namespace std;

int trap(vector<int>& height) {
    int n = height.size();
    if (n <= 2) return 0;

    int left = 0, right = n - 1;
    int leftMax = 0, rightMax = 0;
    int totalWater = 0;

    while (left < right) {
        if (height[left] < height[right]) {
            if (height[left] >= leftMax) {
                leftMax = height[left];
            } else {
                totalWater += leftMax - height[left];
            }
            left++;
        } else {
            if (height[right] >= rightMax) {
                rightMax = height[right];
            } else {
                totalWater += rightMax - height[right];
            }
            right--;
        }
    }
    return totalWater;
}
```

## 三、滑动窗口类

### 5\. 无重复字符的最长子串

#### 思路

13. 用哈希表记录字符最新位置，维护滑动窗口\[left, right\]。

14. 右指针遍历字符串，若当前字符已在窗口中，更新left为重复字符的下一个位置。

15. 迭代更新字符位置和最大窗口长度。

#### C\+\+代码

```C++
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

int lengthOfLongestSubstring(string s) {
    vector<int> charIndex(128, -1); // 假设字符为ASCII
    int maxLen = 0;
    int left = 0;
    int n = s.size();

    for (int right = 0; right < n; right++) {
        // 更新左边界，确保窗口内无重复
        left = max(left, charIndex[s[right]] + 1);
        // 更新字符最新位置
        charIndex[s[right]] = right;
        // 更新最大长度
        maxLen = max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

## 四、子串类

### 6\. 和为K的子数组

#### 思路

16. 用哈希表记录前缀和及其出现次数，前缀和为前i个元素的和。

17. 遍历数组，计算当前前缀和，若（当前前缀和\-K）存在于哈希表，累加对应次数。

18. 将当前前缀和存入哈希表，迭代统计结果。

#### C\+\+代码

```C++
#include <vector>
#include <unordered_map>
using namespace std;

int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> prefixSumCount;
    prefixSumCount[0] = 1; // 前缀和为0的情况出现1次
    int currentSum = 0;
    int result = 0;

    for (int num : nums) {
        currentSum += num;
        // 查找是否存在前缀和为currentSum - k的情况
        if (prefixSumCount.find(currentSum - k) != prefixSumCount.end()) {
            result += prefixSumCount[currentSum - k];
        }
        // 更新当前前缀和的出现次数
        prefixSumCount[currentSum]++;
    }
    return result;
}
```



### 7\. 滑动窗口最大值

#### 思路

19. 用单调队列维护窗口内的最大值候选（队列存储元素索引，保持元素值递减）。

20. 右指针入队前，移除队列中小于当前元素的索引（确保队列递减）。

21. 左指针移动时，移除队列中超出窗口范围的索引。

22. 窗口形成后，队列首元素即为当前窗口最大值。

#### C\+\+代码

```C++
#include <vector>
#include <deque>
using namespace std;

vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    vector<int> result;
    deque<int> maxQueue; // 存储索引，保持值递减
    int n = nums.size();

    for (int right = 0; right < n; right++) {
        // 移除队列中小于当前元素的索引
        while (!maxQueue.empty() && nums[right] >= nums[maxQueue.back()]) {
            maxQueue.pop_back();
        }
        maxQueue.push_back(right);

        // 移除超出窗口范围的索引（窗口左边界为right - k + 1）
        while (maxQueue.front() <= right - k) {
            maxQueue.pop_front();
        }

        // 窗口形成后，记录最大值
        if (right >= k - 1) {
            result.push_back(nums[maxQueue.front()]);
        }
    }
    return result;
}
```

## 五、普通数组类

### 8\. 最大子数组和

#### 思路

23. 动态规划，dp\[i\]表示以nums\[i\]结尾的最大子数组和。

24. 状态转移：dp\[i\] = max\(nums\[i\], dp\[i\-1\] \+ nums\[i\]\)（要么单独成组，要么加入前一个子数组）。

25. 用变量实时记录最大dp值，优化空间（无需额外数组）。

#### C\+\+代码

```C++
#include <vector>
#include <algorithm>
using namespace std;

int maxSubArray(vector<int>& nums) {
    int maxSum = nums[0];
    int currentSum = nums[0];
    int n = nums.size();

    for (int i = 1; i < n; i++) {
        currentSum = max(nums[i], currentSum + nums[i]);
        maxSum = max(maxSum, currentSum);
    }
    return maxSum;
}
```



### 9\. 合并区间

#### 思路

26. 按区间起点排序，便于合并重叠区间。

27. 初始化结果集，将第一个区间加入。

28. 遍历后续区间，若与结果集最后一个区间重叠（当前区间起点≤最后区间终点），则合并（更新终点为两者最大值）；否则直接加入结果集。

#### C\+\+代码

```C++
#include <vector>
#include <algorithm>
using namespace std;

vector<vector<int>> merge(vector<vector<int>>& intervals) {
    vector<vector<int>> result;
    if (intervals.empty()) return result;

    // 按区间起点排序
    sort(intervals.begin(), intervals.end());
    result.push_back(intervals[0]);

    for (int i = 1; i < intervals.size(); i++) {
        auto& last = result.back();
        if (intervals[i][0] <= last[1]) {
            // 重叠，合并区间
            last[1] = max(last[1], intervals[i][1]);
        } else {
            // 不重叠，加入结果集
            result.push_back(intervals[i]);
        }
    }
    return result;
}
```



### 10\. 螺旋矩阵

#### 思路

29. 定义上下左右四个边界，模拟螺旋遍历顺序（右→下→左→上）。

30. 右向遍历：从左到右，遍历完上边界后上边界\+\+。

31. 下向遍历：从上到下，遍历完右边界后右边界\-\-。

32. 左向遍历：从右到左（需判断上下边界是否交叉），遍历完下边界后下边界\-\-。

33. 上向遍历：从下到上（需判断左右边界是否交叉），遍历完左边界后左边界\+\+。

34. 循环直至边界交叉。

#### C\+\+代码

```C++
#include <vector>
using namespace std;

vector<int> spiralOrder(vector<vector<int>>& matrix) {
    vector<int> result;
    if (matrix.empty() || matrix[0].empty()) return result;

    int top = 0, bottom = matrix.size() - 1;
    int left = 0, right = matrix[0].size() - 1;

    while (true) {
        // 右向遍历
        for (int i = left; i <= right; i++) {
            result.push_back(matrix[top][i]);
        }
        if (++top > bottom) break;

        // 下向遍历
        for (int i = top; i <= bottom; i++) {
            result.push_back(matrix[i][right]);
        }
        if (--right < left) break;

        // 左向遍历
        for (int i = right; i >= left; i--) {
            result.push_back(matrix[bottom][i]);
        }
        if (--bottom < top) break;

        // 上向遍历
        for (int i = bottom; i >= top; i--) {
            result.push_back(matrix[i][left]);
        }
        if (++left > right) break;
    }
    return result;
}
```

## 六、链表类

### 11\. 反转链表

#### 思路（迭代法）

35. 定义前驱节点prev（初始为nullptr）、当前节点curr（初始为头节点）。

36. 遍历链表，保存curr的下一个节点next，将curr的next指向prev。

37. 更新prev为curr，curr为next，迭代至curr为nullptr。

38. prev即为反转后的头节点。

#### C\+\+代码

```C++
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* curr = head;

    while (curr != nullptr) {
        ListNode* nextTemp = curr->next; // 保存下一个节点
        curr->next = prev; // 反转当前节点指针
        prev = curr; // 更新前驱节点
        curr = nextTemp; // 更新当前节点
    }
    return prev;
}
```



### 12\. 回文链表

#### 思路

39. 快慢指针找链表中点（快指针走两步，慢指针走一步，快指针到尾时慢指针在中点）。

40. 反转后半段链表。

41. 双指针分别从表头和反转后的后半段表头遍历，比较节点值是否一致。

42. （可选）恢复链表结构。

#### C\+\+代码

```C++
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

// 反转链表辅助函数
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* curr = head;
    while (curr != nullptr) {
        ListNode* nextTemp = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}

bool isPalindrome(ListNode* head) {
    if (head == nullptr || head->next == nullptr) return true;

    // 快慢指针找中点
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast->next != nullptr && fast->next->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
    }

    // 反转后半段（slow的下一个节点为后半段起点）
    ListNode* secondHalf = reverseList(slow->next);
    ListNode* p1 = head;
    ListNode* p2 = secondHalf;
    bool result = true;

    // 比较两段链表
    while (result && p2 != nullptr) {
        if (p1->val != p2->val) {
            result = false;
        }
        p1 = p1->next;
        p2 = p2->next;
    }

    // 恢复链表（可选）
    slow->next = reverseList(secondHalf);
    return result;
}
```



### 13\. 环形链表

#### 思路（快慢指针法）

43. 快慢指针初始都指向头节点，快指针每次走两步，慢指针每次走一步。

44. 若链表有环，快慢指针终将相遇；若无环，快指针先到达nullptr。

#### C\+\+代码

```C++
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

bool hasCycle(ListNode *head) {
    if (head == nullptr || head->next == nullptr) return false;

    ListNode* slow = head;
    ListNode* fast = head->next;

    while (slow != fast) {
        if (fast == nullptr || fast->next == nullptr) {
            return false;
        }
        slow = slow->next;
        fast = fast->next->next;
    }
    return true;
}
```



### 14\. 环形链表II（找环入口）

#### 思路

45. 先通过快慢指针判断是否有环，若相遇则存在环。

46. 相遇后，将慢指针重置为头节点，快慢指针均每次走一步。

47. 再次相遇的节点即为环入口（数学推导：头节点到入口距离=相遇点到入口距离）。

#### C\+\+代码

```C++
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

ListNode *detectCycle(ListNode *head) {
    if (head == nullptr || head->next == nullptr) return nullptr;

    ListNode* slow = head;
    ListNode* fast = head;
    bool hasCycle = false;

    // 第一步：判断是否有环
    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            hasCycle = true;
            break;
        }
    }

    if (!hasCycle) return nullptr;

    // 第二步：找环入口
    slow = head;
    while (slow != fast) {
        slow = slow->next;
        fast = fast->next;
    }
    return slow;
}
```



### 15\. 合并两个有序列表

#### 思路

48. 递归法：比较两个链表头节点，选择较小节点作为当前节点，递归合并剩余链表。

49. 迭代法：用虚拟头节点简化边界处理，双指针遍历两个链表，选择较小节点接入结果链表。

#### C\+\+代码（迭代法）

```C++
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
    ListNode dummy(0); // 虚拟头节点
    ListNode* curr = &dummy;

    while (list1 != nullptr && list2 != nullptr) {
        if (list1->val <= list2->val) {
            curr->next = list1;
            list1 = list1->next;
        } else {
            curr->next = list2;
            list2 = list2->next;
        }
        curr = curr->next;
    }

    // 接入剩余节点
    curr->next = (list1 != nullptr) ? list1 : list2;
    return dummy.next;
}
```



### 16\. K个一组翻转链表

#### 思路

50. 先遍历链表，统计节点总数，确定需要翻转的组数。

51. 用虚拟头节点、前驱节点prev、当前节点curr辅助翻转。

52. 每组内翻转：通过迭代反转当前组的k个节点，连接前后组。

53. 迭代处理所有组，返回虚拟头节点的下一个节点。

#### C\+\+代码

```C++
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

ListNode* reverseKGroup(ListNode* head, int k) {
    if (head == nullptr || k == 1) return head;

    // 统计节点总数
    int count = 0;
    ListNode* curr = head;
    while (curr != nullptr) {
        count++;
        curr = curr->next;
    }

    ListNode dummy(0);
    dummy.next = head;
    ListNode* prev = &dummy; // 前驱组的尾节点

    while (count >= k) {
        curr = prev->next; // 当前组的头节点
        ListNode* nextGroup = curr; // 保存下一组的头节点（翻转后变为当前组尾）
        ListNode* groupPrev = nullptr;

        // 翻转当前组的k个节点
        for (int i = 0; i < k; i++) {
            ListNode* nextTemp = curr->next;
            curr->next = groupPrev;
            groupPrev = curr;
            curr = nextTemp;
        }

        // 连接前驱组和当前组（groupPrev为当前组翻转后的头）
        prev->next = groupPrev;
        nextGroup->next = curr; // 连接当前组和下一组
        prev = nextGroup; // 更新前驱组尾节点

        count -= k;
    }

    return dummy.next;
}
```



### 17\. 合并K个升序链表

#### 思路

54. 优先级队列（最小堆）法：将每个链表的头节点加入堆，堆顶为当前最小节点。

55. 取出堆顶节点接入结果链表，若该节点有下一个节点，将其加入堆。

56. 迭代至堆为空，结果链表即为合并后的有序链表。

#### C\+\+代码

```C++
#include <vector>
#include <queue>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

// 定义优先级队列的比较函数（最小堆）
struct Compare {
    bool operator()(ListNode* a, ListNode* b) {
        return a->val > b->val;
    }
};

ListNode* mergeKLists(vector<ListNode*>& lists) {
    priority_queue<ListNode*, vector<ListNode*>, Compare> minHeap;

    // 初始化堆：将每个链表的头节点加入
    for (ListNode* list : lists) {
        if (list != nullptr) {
            minHeap.push(list);
        }
    }

    ListNode dummy(0);
    ListNode* curr = &dummy;

    while (!minHeap.empty()) {
        // 取出最小节点
        ListNode* top = minHeap.top();
        minHeap.pop();

        // 接入结果链表
        curr->next = top;
        curr = curr->next;

        // 加入当前节点的下一个节点
        if (top->next != nullptr) {
            minHeap.push(top->next);
        }
    }

    return dummy.next;
}
```

## 七、二叉树类

### 18\. 二叉树的中序遍历（递归\+迭代）

#### 思路

- 递归法：左子树→根节点→右子树，递归遍历。

- 迭代法：用栈模拟递归过程，先遍历左子树并压栈，左子树遍历完后弹出节点访问，再遍历右子树。

#### C\+\+代码（递归\+迭代）

```C++
#include <vector>
#include <stack>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};

// 递归法
void inorderRecursive(TreeNode* root, vector<int>& result) {
    if (root == nullptr) return;
    inorderRecursive(root->left, result);
    result.push_back(root->val);
    inorderRecursive(root->right, result);
}

// 迭代法
vector<int> inorderIterative(TreeNode* root) {
    vector<int> result;
    stack<TreeNode*> st;
    TreeNode* curr = root;

    while (curr != nullptr || !st.empty()) {
        // 遍历左子树，压入栈
        while (curr != nullptr) {
            st.push(curr);
            curr = curr->left;
        }

        // 弹出节点访问
        curr = st.top();
        st.pop();
        result.push_back(curr->val);

        // 遍历右子树
        curr = curr->right;
    }
    return result;
}

vector<int> inorderTraversal(TreeNode* root) {
    vector<int> result;
    // 递归法调用
    // inorderRecursive(root, result);
    // 迭代法调用
    result = inorderIterative(root);
    return result;
}
```



### 19\. 对称二叉树

#### 思路（递归法）

57. 定义辅助函数，判断两个子树是否对称：根节点值相等，左子树的左孩子=右子树的右孩子，左子树的右孩子=右子树的左孩子。

58. 空树对称，单节点树对称，否则递归判断左右子树。

#### C\+\+代码

```C++
    TreeNode *left;
    TreeNode *right;

    if (left == nullptr || right == nullptr) return false;

    return (left->val == right->val) &&
           isSymmetricHelper(left->left, right->right) &&
           isSymmetricHelper(left->right, right->left);

    if (root == nullptr) return true;
    return isSymmetricHelper(root->left, root->right);
```

### 20\. 二叉树的层序遍历

#### 思路（BFS）

59. 用队列存储每一层的节点，初始化时将根节点入队。

60. 遍历队列，记录当前层节点数，依次弹出节点访问，将左右孩子入队（若存在）。

61. 每一层访问完后，将当前层节点值存入结果集，迭代至队列为空。

#### C\+\+代码

```C++
#include <vector>
#include <queue>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};

vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (root == nullptr) return result;

    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int levelSize = q.size(); // 当前层节点数
        vector<int> currentLevel;

        for (int i = 0; i < levelSize; i++) {
            TreeNode* node = q.front();
            q.pop();
            currentLevel.push_back(node->val);

            // 左右孩子入队
            if (node->left != nullptr) q.push(node->left);
            if (node->right != nullptr) q.push(node->right);
        }

        result.push_back(currentLevel);
    }
    return result;
}
```



### 21\. 从前序与中序遍历序列构造二叉树

#### 思路（递归）

62. 前序遍历：根→左→右，中序遍历：左→根→右。

63. 前序序列第一个元素为根节点，在中序序列中找到根节点位置，分割出左子树和右子树的中序序列。

64. 根据左子树中序序列长度，分割前序序列的左子树和右子树部分。

65. 递归构造左子树和右子树，返回根节点。

#### C\+\+代码

```C++
#include <vector>
#include <unordered_map>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};

class Solution {
private:
    unordered_map<int, int> inorderMap; // 中序值→索引，加速查找
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        int n = preorder.size();
        // 构建中序值到索引的映射
        for (int i = 0; i < n; i++) {
            inorderMap[inorder[i]] = i;
        }
        return build(preorder, 0, n - 1, inorder, 0, n - 1);
    }

    TreeNode* build(vector<int>& preorder, int preStart, int preEnd,
                   vector<int>& inorder, int inStart, int inEnd) {
        if (preStart > preEnd || inStart > inEnd) return nullptr;

        // 前序第一个元素为根节点
        int rootVal = preorder[preStart];
        TreeNode* root = new TreeNode(rootVal);

        // 找到根节点在中序的索引
        int rootInIdx = inorderMap[rootVal];
        int leftSize = rootInIdx - inStart; // 左子树节点数

        // 递归构造左子树和右子树
        root->left = build(preorder, preStart + 1, preStart + leftSize,
                          inorder, inStart, rootInIdx - 1);
        root->right = build(preorder, preStart + leftSize + 1, preEnd,
                           inorder, rootInIdx + 1, inEnd);

        return root;
    }
};
```



### 22\. 二叉树的最近公共祖先

#### 思路（递归）

66. 若当前节点为空或等于p、q，返回当前节点。

67. 递归遍历左子树和右子树，得到左子树结果left和右子树结果right。

68. 若left和right都不为空，当前节点即为最近公共祖先。

69. 若只有left不为空，返回left；若只有right不为空，返回right；否则返回nullptr。

#### C\+\+代码

```C++
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};

TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    // 递归终止条件
    if (root == nullptr || root == p || root == q) {
        return root;
    }

    // 递归遍历左右子树
    TreeNode* left = lowestCommonAncestor(root->left, p, q);
    TreeNode* right = lowestCommonAncestor(root->right, p, q);

    // 左右子树都找到，当前节点是LCA
    if (left != nullptr && right != nullptr) {
        return root;
    }

    // 只有左子树找到，返回左子树结果；否则返回右子树结果
    return (left != nullptr) ? left : right;
}
```



### 23\. 路径总和III

#### 思路（递归\+前缀和）

70. 前缀和：从根节点到当前节点的路径和，用哈希表记录前缀和出现的次数。

71. 递归遍历二叉树，计算当前前缀和，若（当前前缀和\-目标和）存在于哈希表，累加对应次数。

72. 递归左子树和右子树，回溯时删除当前前缀和（避免影响其他路径）。

#### C\+\+代码

```C++
#include <vector>
#include <unordered_map>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};

class Solution {
private:
    unordered_map<long long, int> prefixSumCount; // 前缀和→出现次数
    int target;

    int dfs(TreeNode* node, long long currentSum) {
        if (node == nullptr) return 0;

        int result = 0;
        currentSum += node->val;

        // 查找是否存在前缀和为currentSum - target的路径
        if (prefixSumCount.find(currentSum - target) != prefixSumCount.end()) {
            result += prefixSumCount[currentSum - target];
        }

        // 更新当前前缀和的出现次数
        prefixSumCount[currentSum]++;

        // 递归遍历左右子树
        result += dfs(node->left, currentSum);
        result += dfs(node->right, currentSum);

        // 回溯：删除当前前缀和（避免影响其他路径）
        prefixSumCount[currentSum]--;
        if (prefixSumCount[currentSum] == 0) {
            prefixSumCount.erase(currentSum);
        }

        return result;
    }

public:
    int pathSum(TreeNode* root, int targetSum) {
        target = targetSum;
        prefixSumCount[0] = 1; // 前缀和为0的情况出现1次（空路径）
        return dfs(root, 0);
    }
};
```

### 24\. 岛屿数量

#### 思路（DFS）

73. 遍历网格，若当前单元格为'1'（未访问的陆地），岛屿数量\+1。

74. 对当前陆地进行DFS，将所有相连的'1'标记为'0'（已访问）。

75. 迭代至网格遍历完毕，返回岛屿数量。

```C++
class Solution {

    int m, n;

    void dfs(vector<vector<char>>& grid, int i, int j) {

        if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] == '0') {

        // 遍历四个方向
        dfs(grid, i + 1, j);
        dfs(grid, i - 1, j);
        dfs(grid, i, j + 1);

            for (int j = 0; j < n; j++) {
                if (grid[i][j] == '1') {
                    count++;
                    dfs(grid, i, j);
                }
            }
        }
        return count;
    }
};
```

## 九、回溯类

### 25\. 全排列

#### 思路

76. 回溯法：交换当前位置元素与后续元素，生成不同排列。

77. 递归终止条件：当前位置等于数组长度，将当前排列加入结果集。

78. 迭代交换：遍历当前位置后的所有元素，交换后递归，回溯时恢复交换（确保不影响后续排列）。

#### C\+\+代码

```C++
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
private:
    vector<vector<int>> result;

    void backtrack(vector<int>& nums, int start) {
        // 递归终止：生成一个排列
        if (start == nums.size()) {
            result.push_back(nums);
            return;
        }

        for (int i = start; i < nums.size(); i++) {
            swap(nums[start], nums[i]); // 交换元素
            backtrack(nums, start + 1); // 递归处理下一个位置
            swap(nums[start], nums[i]); // 回溯：恢复交换
        }
    }

public:
    vector<vector<int>> permute(vector<int>& nums) {
        result.clear();
        backtrack(nums, 0);
        return result;
    }
};
```



### 26\. 组合总和

#### 思路

79. 回溯法：选择当前元素加入组合，或不选择当前元素，递归遍历所有可能。

80. 排序数组（便于剪枝），递归时记录当前组合和当前总和。

81. 终止条件：当前总和等于目标值，加入结果集；当前总和大于目标值，剪枝返回。

82. 避免重复组合：每次递归从当前索引开始（不回溯前序元素）。

#### C\+\+代码

```C++
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;
    int target;

    void backtrack(vector<int>& candidates, int start, int currentSum) {
        // 找到有效组合
        if (currentSum == target) {
            result.push_back(path);
            return;
        }
        // 剪枝：当前总和超过目标值
        if (currentSum > target) {
            return;
        }

        for (int i = start; i < candidates.size(); i++) {
            // 剪枝：相同元素跳过（避免重复组合）
            if (i > start && candidates[i] == candidates[i - 1]) {
                continue;
            }
            path.push_back(candidates[i]); // 选择当前元素
            backtrack(candidates, i, currentSum + candidates[i]); // 可重复选择，i不+1
            path.pop_back(); // 回溯：移除当前元素
        }
    }

public:
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        result.clear();
        path.clear();
        this->target = target;
        sort(candidates.begin(), candidates.end()); // 排序便于剪枝
        backtrack(candidates, 0, 0);
        return result;
    }
};
```



### 27\. 括号生成

#### 思路

83. 回溯法：记录当前括号组合、左括号数量、右括号数量。

84. 约束条件：左括号数量≤n，右括号数量≤左括号数量（确保括号有效）。

85. 终止条件：左括号数量=右括号数量=n，将当前组合加入结果集。

86. 递归生成：先添加左括号（若未达上限），再添加右括号（若未达左括号数量）。

```C++
    vector<string> result;
    int n;
```

### 28\. 单词搜索

#### 思路

87. 回溯法：遍历网格每个单元格，若当前单元格等于单词首字符，开始DFS。

88. DFS过程：标记当前单元格为已访问，遍历四个方向，查找下一个字符。

89. 终止条件：匹配完单词所有字符，返回true；越界或字符不匹配，返回false。

90. 回溯：恢复当前单元格标记（避免影响其他路径）。

#### C\+\+代码

```C++
#include <vector>
#include <string>
using namespace std;

class Solution {
private:
    int m, n;
    vector<vector<bool>> visited;
    // 四个方向
    vector<pair<int, int>> dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

    bool dfs(vector<vector<char>>& board, string& word, int i, int j, int index) {
        // 匹配完所有字符
        if (index == word.size()) {
            return true;
        }
        // 边界判断或已访问或字符不匹配
        if (i < 0 || i >= m || j < 0 || j >= n || visited[i][j] || board[i][j] != word[index]) {
            return false;
        }

        visited[i][j] = true; // 标记为已访问
        // 遍历四个方向
        for (auto& dir : dirs) {
            int ni = i + dir.first;
            int nj = j + dir.second;
            if (dfs(board, word, ni, nj, index + 1)) {
                return true;
            }
        }
        visited[i][j] = false; // 回溯：恢复标记
        return false;
    }

public:
    bool exist(vector<vector<char>>& board, string word) {
        if (board.empty() || board[0].empty() || word.empty()) {
            return false;
        }

        m = board.size();
        n = board[0].size();
        visited = vector<vector<bool>>(m, vector<bool>(n, false));

        // 遍历每个单元格作为起点
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == word[0] && dfs(board, word, i, j, 0)) {
                    return true;
                }
            }
        }
        return false;
    }
};
```



### 29\. 分割回文子串

#### 思路

91. 回溯法：递归分割字符串，记录当前分割的回文子串。

92. 辅助函数：判断子串是否为回文（双指针法）。

93. 终止条件：分割到字符串末尾，将当前分割结果加入结果集。

94. 递归分割：遍历分割点，若当前子串是回文，加入分割结果，递归处理剩余字符串，回溯时移除当前子串。

#### C\+\+代码

```C++
#include <vector>
#include <string>
using namespace std;

class Solution {
private:
    vector<vector<string>> result;
    vector<string> path;

    // 判断子串是否为回文
    bool isPalindrome(string& s, int left, int right) {
        while (left < right) {
            if (s[left] != s[right]) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }

    void backtrack(string& s, int start) {
        // 分割到末尾，记录结果
        if (start == s.size()) {
            result.push_back(path);
            return;
        }

        for (int i = start; i < s.size(); i++) {
            // 若当前子串是回文，进行分割
            if (isPalindrome(s, start, i)) {
                path.push_back(s.substr(start, i - start + 1));
                backtrack(s, i + 1); // 递归处理剩余字符串
                path.pop_back(); // 回溯：移除当前子串
            }
        }
    }

public:
    vector<vector<string>> partition(string s) {
        result.clear();
        path.clear();
        backtrack(s, 0);
        return result;
    }
};
```

### 30\. 数组中的第K个最大元素

#### 思路（最小堆）

95. 用最小堆维护当前最大的K个元素，堆大小为K。

96. 遍历数组，若堆大小小于K，直接入堆；否则若当前元素大于堆顶，弹出堆顶后入堆。

97. 遍历结束后，堆顶即为第K个最大元素。

#### C\+\+代码

```C++
#include <vector>
#include <queue>
using namespace std;

int findKthLargest(vector<int>& nums, int k) {

    priority_queue<int, vector<int>, greater<int>> minHeap;

    for (int num : nums) {
        if (minHeap.size() < k) {
            minHeap.push(num);
        } else if (num > minHeap.top()) {
            minHeap.pop();
            minHeap.push(num);
        }
    }

    return minHeap.top();
}
```

### 31\. 前K个高频元素

#### 思路

98. 用哈希表统计元素出现频率。

99. 用最小堆维护前K个高频元素（堆存储\<频率, 元素\>，堆大小为K）。

100. 遍历哈希表，若堆大小小于K，直接入堆；否则若当前频率大于堆顶频率，弹出堆顶后入堆。

101. 遍历堆，提取元素即为前K个高频元素。

#### C\+\+代码

```C++
#include <vector>
#include <unordered_map>
#include <queue>
using namespace std;

vector<int> topKFrequent(vector<int>& nums, int k) {
    // 统计频率
    unordered_map<int, int> freqMap;
    for (int num : nums) {
        freqMap[num]++;
    }

    // 最小堆：存储<频率, 元素>
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> minHeap;

    for (auto& [num, freq] : freqMap) {
        if (minHeap.size() < k) {
            minHeap.push({freq, num});
        } else if (freq > minHeap.top().first) {
            minHeap.pop();
            minHeap.push({freq, num});
        }
    }

    // 提取结果
    vector<int> result;
    while (!minHeap.empty()) {
        result.push_back(minHeap.top().second);
        minHeap.pop();
    }

    return result;
}
```

### 32\. 爬楼梯

#### 思路

102. 动态规划：dp\[i\]表示爬到第i阶的方法数。

103. 状态转移：dp\[i\] = dp\[i\-1\] \+ dp\[i\-2\]（从i\-1阶爬1步，或从i\-2阶爬2步）。

104. 初始条件：dp\[1\] = 1，dp\[2\] = 2。

105. 空间优化：用两个变量记录dp\[i\-1\]和dp\[i\-2\]，避免额外数组。

#### C\+\+代码

```C++
#include <vector>

int climbStairs(int n) {
    if (n <= 2) return n;

    int prev2 = 1; // dp[i-2]
    int prev1 = 2; // dp[i-1]
    int current = 0;

    for (int i = 3; i <= n; i++) {
        current = prev1 + prev2;
        prev2 = prev1;
        prev1 = current;
    }

    return prev1;
}
```

### 33\. 打家劫舍I/II

#### 打家劫舍I（无环）

##### 思路

106. 动态规划：dp\[i\]表示前i个房屋的最大抢劫金额。

107. 状态转移：dp\[i\] = max\(dp\[i\-1\]（不抢第i个）, dp\[i\-2\] \+ nums\[i\-1\]（抢第i个）\)。

108. 初始条件：dp\[0\] = 0，dp\[1\] = nums\[0\]。

109. 空间优化：用两个变量记录dp\[i\-1\]和dp\[i\-2\]。

##### C\+\+代码

```C++
#include <vector>
#include <algorithm>
using namespace std;

int robI(vector<int>& nums) {
    if (nums.empty()) return 0;
    int n = nums.size();
    if (n == 1) return nums[0];

    int prev2 = 0; // dp[i-2]
    int prev1 = nums[0]; // dp[i-1]
    int current = 0;

    for (int i = 2; i <= n; i++) {
        current = max(prev1, prev2 + nums[i-1]);
        prev2 = prev1;
        prev1 = current;
    }

    return prev1;
}
```



#### 打家劫舍II（有环，首尾相连）

##### 思路

110. 拆分问题：环的约束→不能同时抢首尾，因此分为两种情况：抢首不抢尾、抢尾不抢首。

111. 分别对nums\[0\.\.n\-2\]和nums\[1\.\.n\-1\]调用打家劫舍I的解法，取两者最大值。

##### C\+\+代码

```C++
#include <vector>
#include <algorithm>
using namespace std;

int robRange(vector<int>& nums, int start, int end) {
    if (start == end) return nums[start];

    int prev2 = 0;
    int prev1 = nums[start];
    int current = 0;

    for (int i = start + 1; i <= end; i++) {
        current = max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = current;
    }

    return prev1;
}

int robII(vector<int>& nums) {
    if (nums.empty()) return 0;
    int n = nums.size();
    if (n == 1) return nums[0];

    // 情况1：抢首不抢尾；情况2：抢尾不抢首
    return max(robRange(nums, 0, n-2), robRange(nums, 1, n-1));
}
```

### 34\. 买卖股票的最佳时机I/II/III

112. 动态规划：记录遍历过程中的最低价格，计算当前价格与最低价格的差值（最大利润）。

#### 买卖股票的最佳时机III（最多交易2次）

##### 思路

115. 动态规划：定义四个状态：dp\[i\]\[0\]（无交易）、dp\[i\]\[1\]（第一次持有）、dp\[i\]\[2\]（第一次卖出）、dp\[i\]\[3\]（第二次持有）、dp\[i\]\[4\]（第二次卖出）。

116. 状态转移：

    - dp\[i\]\[1\] = max\(dp\[i\-1\]\[1\], dp\[i\-1\]\[0\] \- prices\[i\]\)

    - dp\[i\]\[2\] = max\(dp\[i\-1\]\[2\], dp\[i\-1\]\[1\] \+ prices\[i\]\)

    - dp\[i\]\[3\] = max\(dp\[i\-1\]\[3\], dp\[i\-1\]\[2\] \- prices\[i\]\)

    - dp\[i\]\[4\] = max\(dp\[i\-1\]\[4\], dp\[i\-1\]\[3\] \+ prices\[i\]\)

117. 初始条件：dp\[0\]\[1\] = \-prices\[0\]，dp\[0\]\[3\] = \-prices\[0\]，其余为0。

##### C\+\+代码

```C++
#include <vector>
#include <algorithm>
using namespace std;

int maxProfitIII(vector<int>& prices) {
    if (prices.empty()) return 0;
    int n = prices.size();

    // 定义四个状态：第一次持有、第一次卖出、第二次持有、第二次卖出
    int hold1 = -prices[0], sell1 = 0;
    int hold2 = -prices[0], sell2 = 0;

    for (int i = 1; i < n; i++) {
        hold1 = max(hold1, -prices[i]); // 无交易→第一次持有
        sell1 = max(sell1, hold1 + prices[i]); // 第一次持有→第一次卖出
        hold2 = max(hold2, sell1 - prices[i]); // 第一次卖出→第二次持有
        sell2 = max(sell2, hold2 + prices[i]); // 第二次持有→第二次卖出
    }
```

### 35\. 零钱兑换

#### 思路

118. 动态规划：dp\[i\]表示兑换金额i所需的最少硬币数，初始化为amount\+1（不可达）。

120. 初始条件：dp\[0\] = 0（兑换0元需0枚硬币）。

121. 最终若dp\[amount\]仍为amount\+1，返回\-1（不可兑换）。

```C++
#include <vector>
#include <algorithm>
using namespace std;

int coinChange(vector<int>& coins, int amount) {
    int maxVal = amount + 1;
    vector<int> dp(amount + 1, maxVal);
    dp[0] = 0; // 初始条件

    for (int i = 1; i <= amount; i++) {
        for (int coin : coins) {
            if (coin <= i) {
                dp[i] = min(dp[i], dp[i - coin] + 1);
            }
        }
    }

    return dp[amount] > amount ? -1 : dp[amount];
}
```

### 37\. 最长递增子序列

### 38\. 最长回文子串

#### 思路（中心扩展法）

129. 回文串对称，分为奇数长度（中心为字符）和偶数长度（中心为两字符之间）。

130. 遍历每个可能的中心，向左右扩展，记录最长回文子串。

131. 迭代更新最长回文子串的起始位置和长度。

#### C\+\+代码

```C++
#include <vector>
#include <string>
using namespace std;

string longestPalindrome(string s) {
    if (s.size() < 2) return s;

    int start = 0, maxLen = 1;

    // 中心扩展辅助函数
    auto expand = [&](int left, int right) {
        while (left >= 0 && right < s.size() && s[left] == s[right]) {
            int currentLen = right - left + 1;
            if (currentLen > maxLen) {
                maxLen = currentLen;
                start = left;
            }
            left--;
            right++;
        }
    };

    for (int i = 0; i < s.size(); i++) {
        expand(i, i);     // 奇数长度回文
        expand(i, i + 1); // 偶数长度回文
    }

    return s.substr(start, maxLen);
}
```

### 2\. K\-means

#### 思路

3. 初始化：随机选择\\\(k\\\)个样本作为初始聚类中心（避免重复）。

4. 分配样本：计算每个样本到各聚类中心的欧氏距离，将样本归为距离最近的聚类。

5. 更新中心：计算每个聚类中所有样本的均值，作为新的聚类中心。

6. 迭代收敛：重复步骤2\-3，直到聚类中心变化量小于阈值或达到最大迭代次数。

7. 注意：需处理空聚类（可重新随机选择中心），避免迭代震荡。

#### C\+\+代码

```C++
#include <vector>
#include <cmath>
#include <random>
#include <algorithm>
#include <iostream>
using namespace std;

struct KMeans {
    int k; // 聚类数量
    int max_iter; // 最大迭代次数
    double tol; // 中心变化阈值（收敛条件）
    vector<vector<double>> centers; // 聚类中心
    vector<int> labels; // 每个样本的聚类标签

    KMeans(int k = 2, int max_iter = 100, double tol = 1e-4) {
        this->k = k;
        this->max_iter = max_iter;
        this->tol = tol;
    }

    // 欧氏距离计算
    double euclidean_dist(const vector<double>& a, const vector<double>& b) {
        double dist = 0.0;
        for (int i = 0; i < a.size(); i++) {
            dist += pow(a[i] - b[i], 2);
        }
        return sqrt(dist);
    }

    // 初始化聚类中心（随机选择k个不重复样本）
    void init_centers(const vector<vector<double>>& X) {
        int n = X.size();
        vector<int> indices(n);
        iota(indices.begin(), indices.end(), 0);
        shuffle(indices.begin(), indices.end(), default_random_engine()); // 随机打乱
        for (int i = 0; i < k; i++) {
            centers.push_back(X[indices[i]]);
        }
    }

    // 训练模型
    void fit(const vector<vector<double>>& X) {
        int n = X.size();
        int dim = X[0].size();
        labels.resize(n, -1);
        init_centers(X);

        for (int iter = 0; iter < max_iter; iter++) {
            vector<vector<double>> new_centers(k, vector<double>(dim, 0.0));
            vector<int> cluster_size(k, 0);

            // 步骤1：分配样本到最近的聚类
            for (int i = 0; i < n; i++) {
                double min_dist = 1e9;
                int best_cluster = 0;
                for (int c = 0; c < k; c++) {
                    double dist = euclidean_dist(X[i], centers[c]);
                    if (dist < min_dist) {
                        min_dist = dist;
                        best_cluster = c;
                    }
                }
                labels[i] = best_cluster;
                cluster_size[best_cluster]++;
                // 累加聚类内样本特征
                for (int d = 0; d < dim; d++) {
                    new_centers[best_cluster][d] += X[i][d];
                }
            }

            // 步骤2：更新聚类中心（处理空聚类）
            bool converged = true;
            for (int c = 0; c < k; c++) {
                if (cluster_size[c] == 0) {
                    // 空聚类：重新随机选择中心
                    vector<int> empty_indices;
                    for (int i = 0; i < n; i++) {
                        if (find(labels.begin(), labels.end(), i) == labels.end()) {
                            empty_indices.push_back(i);
                        }
                    }
                    if (!empty_indices.empty()) {
                        new_centers[c] = X[empty_indices[rand() % empty_indices.size()]];
                    } else {
                        new_centers[c] = centers[c]; // 无可用样本，保持原中心
                    }
                } else {
                    // 计算聚类均值
                    for (int d = 0; d < dim; d++) {
                        new_centers[c][d] /= cluster_size[c];
                    }
                }

                // 判断中心是否收敛
                double center_diff = euclidean_dist(centers[c], new_centers[c]);
                if (center_diff > tol) {
                    converged = false;
                }
            }

            centers = new_centers;
            if (converged) {
                break; // 收敛，提前停止
            }
        }
    }

    // 预测样本的聚类标签
    vector<int> predict(const vector<vector<double>>& X) {
        vector<int> pred_labels;
        for (auto& x : X) {
            double min_dist = 1e9;
            int best_cluster = 0;
            for (int c = 0; c < k; c++) {
                double dist = euclidean_dist(x, centers[c]);
                if (dist < min_dist) {
                    min_dist = dist;
                    best_cluster = c;
                }
            }
            pred_labels.push_back(best_cluster);
        }
        return pred_labels;
    }
};
```





### 3\. MHA（多头注意力）

#### 思路

8. 基于文档中Self\-Attention原理（🔶1\-170到🔶1\-189），MHA将注意力机制并行执行\\\(h\\\)次（多头），再拼接结果。

9. 步骤：

    - 线性投影：输入\\\(X\\\)通过三个权重矩阵\\\(W^Q, W^K, W^V\\\)生成查询\\\(Q\\\)、键\\\(K\\\)、值\\\(V\\\)。

    - 多头拆分：将\\\(Q, K, V\\\)按头数\\\(h\\\)拆分，每个头处理部分特征。

    - 单头注意力计算：计算注意力分数\\\(S = QK^T/\\sqrt\{d\_k\}\\\)，softmax得到权重，加权聚合\\\(O = AV\\\)。

    - 多头拼接：将所有头的输出拼接，通过输出权重矩阵\\\(W^O\\\)得到最终结果。

#### C\+\+代码

```C++
#include <vector>
#include <cmath>
#include <algorithm>
using namespace std;

// 矩阵乘法辅助函数（A: m×k, B: k×n → C: m×n）
vector<vector<double>> mat_mult(const vector<vector<double>>& A, const vector<vector<double>>& B) {
    int m = A.size(), k = B.size(), n = B[0].size();
    vector<vector<double>> C(m, vector<double>(n, 0.0));
    for (int i = 0; i < m; i++) {
        for (int l = 0; l < k; l++) {
            if (A[i][l] == 0) continue; // 稀疏优化（可选）
            for (int j = 0; j < n; j++) {
                C[i][j] += A[i][l] * B[l][j];
            }
        }
    }
    return C;
}

// Softmax函数（按行计算）
vector<vector<double>> softmax(const vector<vector<double>>& X) {
    int m = X.size(), n = X[0].size();
    vector<vector<double>> res(m, vector<double>(n, 0.0));
    for (int i = 0; i < m; i++) {
        double max_val = *max_element(X[i].begin(), X[i].end());
        double sum = 0.0;
        // 减最大值避免指数溢出
        for (int j = 0; j < n; j++) {
            res[i][j] = exp(X[i][j] - max_val);
            sum += res[i][j];
        }
        // 归一化
        for (int j = 0; j < n; j++) {
            res[i][j] /= sum;
        }
    }
    return res;
}

// 多头注意力实现
struct MultiHeadAttention {
    int d_model; // 输入特征维度
    int h; // 头数
    int d_k; // 每个头的维度（d_model必须能被h整除，d_k = d_model/h）
    vector<vector<double>> W_Q, W_K, W_V, W_O; // 权重矩阵

    MultiHeadAttention(int d_model = 512, int h = 8) {
        this->d_model = d_model;
        this->h = h;
        this->d_k = d_model / h;
        // 初始化权重矩阵（这里简化为随机初始化，实际需用Xavier等方法）
        random_device rd;
        mt19937 gen(rd());
        uniform_real_distribution<> dis(-0.1, 0.1);
        W_Q = init_mat(d_model, d_model, dis, gen);
        W_K = init_mat(d_model, d_model, dis, gen);
        W_V = init_mat(d_model, d_model, dis, gen);
        W_O = init_mat(d_model, d_model, dis, gen);
    }

    // 权重矩阵初始化辅助函数
    vector<vector<double>> init_mat(int rows, int cols, uniform_real_distribution<>& dis, mt19937& gen) {
        vector<vector<double>> mat(rows, vector<double>(cols));
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                mat[i][j] = dis(gen);
            }
        }
        return mat;
    }

    // 拆分多头（将m×d_model矩阵拆分为h×m×d_k）
    vector<vector<vector<double>>> split_heads(const vector<vector<double>>& X) {
        int m = X.size();
        vector<vector<vector<double>>> heads(h, vector<vector<double>>(m, vector<double>(d_k)));
        for (int i = 0; i < m; i++) {
            for (int c = 0; c < d_model; c++) {
                int head_idx = c / d_k;
                int dim_idx = c % d_k;
                heads[head_idx][i][dim_idx] = X[i][c];
            }
        }
        return heads;
    }

    // 拼接多头（将h×m×d_k矩阵合并为m×d_model）
    vector<vector<double>> concat_heads(const vector<vector<vector<double>>>& heads) {
        int m = heads[0].size();
        vector<vector<double>> X(m, vector<double>(d_model));
        for (int i = 0; i < m; i++) {
            for (int head_idx = 0; head_idx < h; head_idx++) {
                for (int dim_idx = 0; dim_idx < d_k; dim_idx++) {
                    int c = head_idx * d_k + dim_idx;
                    X[i][c] = heads[head_idx][i][dim_idx];
                }
            }
        }
        return X;
    }

    // 单头注意力计算
    vector<vector<double>> single_head_attention(const vector<vector<double>>& Q, 
                                                const vector<vector<double>>& K, 
                                                const vector<vector<double>>& V) {
        int m = Q.size(), n = K.size();
        // 1. 计算注意力分数 S = QK^T / sqrt(d_k)
        vector<vector<double>> K_T(n, vector<double>(d_k));
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < d_k; j++) {
                K_T[j][i] = K[i][j]; // K转置（k×n → n×k，这里d_k=k）
            }
        }
        vector<vector<double>> S = mat_mult(Q, K_T);
        double scale = sqrt(d_k);
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                S[i][j] /= scale;
            }
        }

        // 2. Softmax得到注意力权重
        vector<vector<double>> A = softmax(S);

        // 3. 加权聚合 V
        vector<vector<double>> O = mat_mult(A, V);
        return O;
    }

    // 多头注意力前向传播
    vector<vector<double>> forward(const vector<vector<double>>& X) {
        // 1. 线性投影生成 Q, K, V
        vector<vector<double>> Q = mat_mult(X, W_Q);
        vector<vector<double>> K = mat_mult(X, W_K);
        vector<vector<double>> V = mat_mult(X, W_V);

        // 2. 拆分多头
        auto Q_heads = split_heads(Q);
        auto K_heads = split_heads(K);
        auto V_heads = split_heads(V);

        // 3. 并行计算每个头的注意力
        vector<vector<vector<double>>> O_heads(h);
        for (int head_idx = 0; head_idx < h; head_idx++) {
            O_heads[head_idx] = single_head_attention(Q_heads[head_idx], 
                                                      K_heads[head_idx], 
                                                      V_heads[head_idx]);
        }

        // 4. 拼接多头
        vector<vector<double>> O_concat = concat_heads(O_heads);

        // 5. 输出投影
        vector<vector<double>> output = mat_mult(O_concat, W_O);
        return output;
    }
};
```

### 4\. LoRA（低秩适应）

#### 思路

10. 基于文档中参数高效微调（PEFT）理念（🔶1\-264），LoRA通过低秩矩阵分解减少微调参数数量。

11. 核心原理：对预训练模型的权重矩阵\\\(W\_0 \\in \\mathbb\{R\}^\{d\_\{in\} \\times d\_\{out\}\}\\\)，微调时不直接更新\\\(W\_0\\\)，而是引入低秩矩阵\\\(A \\in \\mathbb\{R\}^\{d\_\{in\} \\times r\}\\\)和\\\(B \\in \\mathbb\{R\}^\{r \\times d\_\{out\}\}\\\)（\\\(r \\ll d\_\{in\}, d\_\{out\}\\\)），总权重为\\\(W = W\_0 \+ A \\cdot B\\\)。

12. 步骤：

    - 冻结预训练权重\\\(W\_0\\\)，仅训练低秩矩阵\\\(A\\\)和\\\(B\\\)（\\\(A\\\)初始化为随机正态分布，\\\(B\\\)初始化为零矩阵）。

    - 前向传播：通过\\\(W\\\)计算输出，即\\\(Y = X \\cdot \(W\_0 \+ A \\cdot B\)\\\)。

    - 反向传播：仅更新\\\(A\\\)和\\\(B\\\)的梯度，大幅减少计算量和参数存储。

#### C\+\+代码

```C++
#include <vector>
#include <cmath>
#include <random>
using namespace std;

// 矩阵加法辅助函数（A和B维度相同）
vector<vector<double>> mat_add(const vector<vector<double>>& A, const vector<vector<double>>& B) {
    int m = A.size(), n = A[0].size();
    vector<vector<double>> C(m, vector<double>(n));
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            C[i][j] = A[i][j] + B[i][j];
        }
    }
    return C;
}

// LoRA实现（针对单个线性层）
struct LoRA {
    int d_in; // 输入维度
    int d_out; // 输出维度
    int r; // 低秩维度（r << d_in, d_out）
    double alpha; // 缩放因子（控制低秩更新的幅度）
    vector<vector<double>> W0; // 冻结的预训练权重
    vector<vector<double>> A; // 低秩矩阵A（d_in × r）
    vector<vector<double>> B; // 低秩矩阵B（r × d_out）

    LoRA(int d_in, int d_out, int r = 8, double alpha = 16.0) {
        this->d_in = d_in;
        this->d_out = d_out;
        this->r = r;
        this->alpha = alpha;
        // 1. 初始化预训练权重W0（这里简化为随机值，实际为预训练模型加载的权重）
        W0 = init_mat(d_in, d_out, 0.01); // 假设预训练权重已缩放
        // 2. 初始化低秩矩阵：A随机正态分布，B零矩阵
        A = init_mat(d_in, r, 1.0 / sqrt(r)); // 初始化方差为1/r，避免梯度爆炸
        B = init_mat(r, d_out, 0.0); // B初始为零，确保初始更新不影响输出
    }

    // 矩阵初始化辅助函数（mean: 均值，std: 标准差）
    vector<vector<double>> init_mat(int rows, int cols, double std, double mean = 0.0) {
        vector<vector<double>> mat(rows, vector<double>(cols));
        random_device rd;
        mt19937 gen(rd());
        normal_distribution<> dis(mean, std);
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                mat[i][j] = dis(gen);
            }
        }
        return mat;
    }

    // 前向传播（Y = X · (W0 + (A·B)·(alpha/r))）
    vector<vector<double>> forward(const vector<vector<double>>& X) {
        // 计算低秩更新项：A·B，再乘以缩放因子 alpha/r（平衡低秩更新幅度）
        vector<vector<double>> AB = mat_mult(X, A); // X: (batch × d_in) → AB: (batch × r)
        AB = mat_mult(AB, B); // AB: (batch × d_out)
        double scale = alpha / r;
        for (auto& row : AB) {
            for (auto& val : row) {
                val *= scale;
            }
        }

        // 计算预训练权重项：X·W0
        vector<vector<double>> XW0 = mat_mult(X, W0);

        // 总输出：XW0 + AB
        return mat_add(XW0, AB);
    }

    // 反向传播（简化版：计算A和B的梯度，假设已得到输出梯度dY）
    void backward(const vector<vector<double>>& X, const vector<vector<double>>& dY, double lr = 1e-5) {
        int batch_size = X.size();
        double scale = alpha / r;

        // 1. 计算B的梯度：dY^T · AB的梯度 → d_B = A^T · X^T · dY · scale
        vector<vector<double>> X_T(d_in, vector<double>(batch_size));
        for (int i = 0; i < batch_size; i++) {
            for (int j = 0; j < d_in; j++) {
                X_T[j][i] = X[i][j];
            }
        }
        vector<vector<double>> XdY = mat_mult(X_T, dY); // X^T·dY: (d_in × d_out)
        vector<vector<double>> A_T(r, vector<double>(d_in));
        for (int i = 0; i < d_in; i++) {
            for (int j = 0; j < r; j++) {
                A_T[j][i] = A[i][j];
            }
        }
        vector<vector<double>> d_B = mat_mult(A_T, XdY); // A^T·X^T·dY: (r × d_out)
        for (auto& row : d_B) {
            for (auto& val : row) {
                val *= scale / batch_size; // 批量平均
            }
        }

        // 2. 计算A的梯度：d_A = X^T · dY · B^T · scale
        vector<vector<double>> B_T(d_out, vector<double>(r));
        for (int i = 0; i < r; i++) {
            for (int j = 0; j < d_out; j++) {
                B_T[j][i] = B[i][j];
            }
        }
        vector<vector<double>> dYB_T = mat_mult(dY, B_T); // dY·B^T: (batch × r)
        vector<vector<double>> d_A = mat_mult(X_T, dYB_T); // X^T·dY·B^T: (d_in × r)
        for (auto& row : d_A) {
            for (auto& val : row) {
                val *= scale / batch_size; // 批量平均
            }
        }

        // 3. 更新A和B（梯度下降）
        for (int i = 0; i < d_in; i++) {
            for (int j = 0; j < r; j++) {
                A[i][j] -= lr * d_A[i][j];
            }
        }
        for (int i = 0; i < r; i++) {
            for (int j = 0; j < d_out; j++) {
                B[i][j] -= lr * d_B[i][j];
            }
        }
    }

    // 获取融合后的完整权重（用于推理阶段，减少计算）
    vector<vector<double>> get_fused_weight() {
        vector<vector<double>> AB = mat_mult(A, B);
        double scale = alpha / r;
        for (auto& row : AB) {
            for (auto& val : row) {
                val *= scale;
            }
        }
        return mat_add(W0, AB);
    }
};
```

（注：LoRA的核心价值是参数高效微调，例如当\\\(d\_\{in\}=d\_\{out\}=1024\\\)、\\\(r=8\\\)时，仅需训练\\\(1024×8 \+ 8×1024 = 16384\\\)个参数，远少于全参微调的\\\(1024×1024=1048576\\\)个参数）





### 5\. LN（层归一化）与RMSN（Root Mean Square Normalization）

#### 思路

13. **层归一化（LN）**（🔶1\-188、🔶1\-1438）：

    - 目的：减少内部协变量偏移，稳定训练。

    - 步骤：计算层输入的均值\\\(\\mu\\\)和方差\\\(\\sigma^2\\\)，通过\\\(y = \\gamma \\cdot \\frac\{x \- \\mu\}\{\\sqrt\{\\sigma^2 \+ \\epsilon\}\} \+ \\beta\\\)归一化（\\\(\\gamma\\\)和\\\(\\beta\\\)为可学习参数，\\\(\\epsilon\\\)避免除零）。

14. **RMS归一化**（简化版LN，无均值减法）：

    - 目的：减少计算量，保留更多信号特征。

    - 步骤：计算输入的均方根\\\(rms = \\sqrt\{\\frac\{1\}\{d\}\\sum x\_i^2 \+ \\epsilon\}\\\)，通过\\\(y = \\gamma \\cdot \\frac\{x\}\{rms\} \+ \\beta\\\)归一化（无均值减法，减少一半计算）。

#### C\+\+代码

```C++
#include <vector>
#include <cmath>
#include <random>
using namespace std;

// 层归一化（Layer Normalization）
struct LayerNorm {
    int dim; // 特征维度
    double eps; // 平滑项
    vector<double> gamma; // 缩放参数（可学习）
    vector<double> beta; // 偏移参数（可学习）

    LayerNorm(int dim, double eps = 1e-5) {
        this->dim = dim;
        this->eps = eps;
        // 初始化参数：gamma初始为1（保持原始缩放），beta初始为0（保持原始偏移）
        gamma.resize(dim, 1.0);
        beta.resize(dim, 0.0);
    }

    // 前向传播
    vector<vector<double>> forward(const vector<vector<double>>& X) {
        int batch_size = X.size();
        vector<vector<double>> Y(batch_size, vector<double>(dim));

        for (int i = 0; i < batch_size; i++) {
            // 1. 计算当前样本的均值 μ
            double mu = 0.0;
            for (int j = 0; j < dim; j++) {
                mu += X[i][j];
            }
            mu /= dim;

            // 2. 计算方差 σ²
            double var = 0.0;
            for (int j = 0; j < dim; j++) {
                var += pow(X[i][j] - mu, 2);
            }
            var /= dim;

            // 3. 归一化并应用可学习参数
            for (int j = 0; j < dim; j++) {
                double normalized = (X[i][j] - mu) / sqrt(var + eps);
                Y[i][j] = gamma[j] * normalized + beta[j];
            }
        }
        return Y;
    }
};

// RMS归一化（Root Mean Square Normalization）
struct RMSNorm {
    int dim; // 特征维度
    double eps; // 平滑项
    vector<double> gamma; // 缩放参数（可学习）
    vector<double> beta; // 偏移参数（可学习，可选，部分实现无beta）

    RMSNorm(int dim, double eps = 1e-5, bool use_beta = true) {
        this->dim = dim;
        this->eps = eps;
        gamma.resize(dim, 1.0);
        if (use_beta) {
            beta.resize(dim, 0.0);
        }
    }

    // 前向传播
    vector<vector<double>> forward(const vector<vector<double>>& X) {
        int batch_size = X.size();
        bool use_beta = !beta.empty();
        vector<vector<double>> Y(batch_size, vector<double>(dim));

        for (int i = 0; i < batch_size; i++) {
            // 1. 计算均方根 rms
            double rms = 0.0;
            for (int j = 0; j < dim; j++) {
                rms += pow(X[i][j], 2);
            }
            rms = sqrt(rms / dim + eps);

            // 2. 归一化并应用可学习参数（无均值减法）
            for (int j = 0; j < dim; j++) {
                Y[i][j] = gamma[j] * (X[i][j] / rms);
                if (use_beta) {
                    Y[i][j] += beta[j];
                }
            }
        }
        return Y;
    }
};
```

（注：LN在Transformer中广泛应用，RMSNorm在LLaMA、GPT\-4等模型中被采用，因其计算效率更高，且在大模型训练中表现出更好的稳定性）





### 6\. 熵、KL散度、交叉熵

#### 思路

15. **熵（Entropy）**（🔶1\-1740）：衡量随机变量的不确定性，公式为\\\(H\(P\) = \-\\sum\_\{i\} P\(x\_i\) \\cdot \\log P\(x\_i\)\\\)（离散型），值越大不确定性越高。

16. **KL散度（Kullback\-Leibler Divergence）**：衡量两个概率分布\\\(P\\\)（真实分布）和\\\(Q\\\)（近似分布）的差异，公式为\\\(KL\(P\|\|Q\) = \\sum\_\{i\} P\(x\_i\) \\cdot \\log \\frac\{P\(x\_i\)\}\{Q\(x\_i\)\}\\\)，非对称且非负，KL=0表示两分布完全一致。

17. **交叉熵（Cross\-Entropy）**：衡量模型预测分布\\\(Q\\\)与真实分布\\\(P\\\)的匹配程度，公式为\\\(CE\(P, Q\) = \-\\sum\_\{i\} P\(x\_i\) \\cdot \\log Q\(x\_i\)\\\)，且\\\(CE\(P, Q\) = H\(P\) \+ KL\(P\|\|Q\)\\\)（当\\\(P\\\)固定时，最小化交叉熵等价于最小化KL散度）。

#### C\+\+代码

```C++
#include <vector>
#include <cmath>
#include <algorithm>
using namespace std;

// 确保概率分布归一化（避免计算错误）
void normalize_dist(vector<double>& dist) {
    double sum = 0.0;
    for (double p : dist) {
        sum += p;
    }
    if (sum < 1e-9) {
        sum = 1.0; // 避免全零分布
    }
    for (double& p : dist) {
        p /= sum;
    }
}

// 1. 计算离散概率分布的熵（H(P)）
double entropy(const vector<double>& P) {
    vector<double> dist = P;
    normalize_dist(dist);
    double H = 0.0;
    for (double p : dist) {
        if (p < 1e-12) continue; // 避免log(0)
        H -= p * log2(p); // 以2为底，单位为比特；也可用自然对数（log），单位为奈特
    }
    return H;
}

// 2. 计算KL散度（KL(P||Q)）
double kl_divergence(const vector<double>& P, const vector<double>& Q) {
    if (P.size() != Q.size()) {
        throw invalid_argument("P and Q must have the same size");
    }
    vector<double> P_norm = P, Q_norm = Q;
    normalize_dist(P_norm);
    normalize_dist(Q_norm);

    double kl = 0.0;
    for (int i = 0; i < P_norm.size(); i++) {
        double p = P_norm[i];
        double q = Q_norm[i];
        if (p < 1e-12) continue; // P为0时无贡献
        if (q < 1e-12) q = 1e-12; // 避免log(0)
        kl += p * log2(p / q);
    }
    return kl;
}

// 3. 计算交叉熵（CE(P, Q)）
double cross_entropy(const vector<double>& P, const vector<double>& Q) {
    if (P.size() != Q.size()) {
        throw invalid_argument("P and Q must have the same size");
    }
    vector<double> P_norm = P, Q_norm = Q;
    normalize_dist(P_norm);
    normalize_dist(Q_norm);

    double ce = 0.0;
    for (int i = 0; i < P_norm.size(); i++) {
        double p = P_norm[i];
        double q = Q_norm[i];
        if (p < 1e-12) continue; // P为0时无贡献
        if (q < 1e-12) q = 1e-12; // 避免log(0)
        ce -= p * log2(q);
    }
    return ce;
}

// 交叉熵在分类任务中的应用（真实标签为one-hot向量，预测为概率分布）
double categorical_cross_entropy(const vector<int>& y_true, const vector<vector<double>>& y_pred) {
    int batch_size = y_true.size();
    int num_classes = y_pred[0].size();
    double ce = 0.0;

    for (int i = 0; i < batch_size; i++) {
        int true_class = y_true[i];
        if (true_class < 0 || true_class >= num_classes) {
            throw invalid_argument("Invalid true class index");
        }
        vector<double> pred_dist = y_pred[i];
        normalize_dist(pred_dist);
        double q = pred_dist[true_class];
        if (q < 1e-12) q = 1e-12;
        ce -= log2(q); // 真实分布P为one-hot，仅true_class处为1，其余为0
    }
    return ce / batch_size; // 批量平均
}
```

（注：在大模型训练中，交叉熵是分类任务（如文本生成的token预测）的核心损失函数，KL散度常用于模型蒸馏、RLHF中的策略约束（如PPO的KL惩罚项）🔶1\-279、）





### 7\. PPO（Proximal Policy Optimization）

#### 思路

18. 基于文档中麻将AI项目的PPO实践（🔶1\-300到🔶1\-357），PPO核心是通过限制策略更新幅度提高训练稳定性。

19. 核心公式：

    - 裁剪目标函数：\\\(L^\{CLIP\}\(\\theta\) = \\hat\{\\mathbb\{E\}\}\_t\\left\[ \\min\\left\( r\_t\(\\theta\)\\hat\{A\}\_t, \\text\{clip\}\(r\_t\(\\theta\), 1\-\\epsilon, 1\+\\epsilon\)\\hat\{A\}\_t \\right\) \\right\]\\\)，其中\\\(r\_t\(\\theta\) = \\frac\{\\pi\_\\theta\(a\_t\|s\_t\)\}\{\\pi\_\{\\theta\_\{old\}\}\(a\_t\|s\_t\)\}\\\)（新旧策略概率比），\\\(\\hat\{A\}\_t\\\)为优势函数，\\\(\\epsilon\\\)为裁剪参数（通常0\.1\~0\.2）。

    - 总损失：\\\(L^\{TOTAL\}\(\\theta\) = L^\{CLIP\}\(\\theta\) \- c\_1 L^\{VF\}\(\\theta\) \+ c\_2 L^S\(\\theta\)\\\)，其中\\\(L^\{VF\}\\\)为价值函数损失（预测状态价值与目标价值的MSE），\\\(L^S\\\)为熵奖励（鼓励策略探索），\\\(c\_1, c\_2\\\)为权重。

20. 步骤：

    - 数据收集：用旧策略\\\(\\theta\_\{old\}\\\)收集轨迹\\\(\(s\_t, a\_t, r\_t, s\_\{t\+1\}, \\log \\pi\_\{old\}\(a\_t\|s\_t\), V\_\{old\}\(s\_t\)\)\\\)。

    - 优势估计：用GAE（广义优势估计）计算\\\(\\hat\{A\}\_t\\\)。

    - 策略更新：最小化总损失，对每个批次执行多次梯度更新（如10次），固定\\\(\\theta\_\{old\}\\\)直到下一轮数据收集。

#### C\+\+代码（核心逻辑）

```C++
#include <vector>
#include <cmath>
#include <algorithm>
#include <numeric>
using namespace std;

// 策略网络输出（动作概率分布+状态价值）
struct PolicyOutput {
    vector<double> action_probs; // 动作概率分布
    double value; // 状态价值V(s)
};

// PPO核心类
struct PPO {
    int state_dim; // 状态维度
    int action_dim; // 动作维度
    double eps; // 裁剪参数（1-eps, 1+eps）
    double c1; // 价值函数损失权重
    double c2; // 熵奖励权重
    double lr; // 学习率
    int num_updates; // 每次数据收集后的更新次数
    vector<double> theta; // 当前策略参数
    vector<double> theta_old; // 旧策略参数（用于计算r_t(theta)）

    PPO(int state_dim, int action_dim, double eps = 0.2, double c1 = 0.5, 
        double c2 = 0.01, double lr = 3e-4, int num_updates = 10) {
        this->state_dim = state_dim;
        this->action_dim = action_dim;
        this->eps = eps;
        this->c1 = c1;
        this->c2 = c2;
        this->lr = lr;
        this->num_updates = num_updates;
        // 初始化策略参数（简化为向量，实际为神经网络权重）
        theta.resize(state_dim * action_dim + state_dim, 0.01); // 策略网络+价值网络参数
        theta_old = theta;
    }

    // 策略网络前向传播（简化：线性层输出动作概率和价值）
    PolicyOutput policy_forward(const vector<double>& s, const vector<double>& params) {
        PolicyOutput out;
        // 1. 计算动作概率（softmax输出）
        vector<double> logits(action_dim, 0.0);
        for (int a = 0; a < action_dim; a++) {
            for (int i = 0; i < state_dim; i++) {
                logits[a] += s[i] * params[i * action_dim + a]; // 策略网络线性层
            }
        }
        // Softmax归一化
        double max_logit = *max_element(logits.begin(), logits.end());
        double sum_exp = 0.0;
        out.action_probs.resize(action_dim);
        for (int a = 0; a < action_dim; a++) {
            out.action_probs[a] = exp(logits[a] - max_logit);
            sum_exp += out.action_probs[a];
        }
        for (double& p : out.action_probs) {
            p /= sum_exp;
        }

        // 2. 计算状态价值（线性层输出）
        out.value = 0.0;
        int val_param_start = state_dim * action_dim;
        for (int i = 0; i < state_dim; i++) {
            out.value += s[i] * params[val_param_start + i]; // 价值网络线性层
        }
        return out;
    }

    // 广义优势估计（GAE）计算优势函数A_t
    vector<double> compute_gae(const vector<double>& rewards, const vector<double>& values, 
                               double gamma = 0.99, double lambda = 0.95) {
        int T = rewards.size();
        vector<double> deltas(T), gae(T);
        double gae_sum = 0.0;

        // 计算时序差分误差delta_t = r_t + gamma*V(s_{t+1}) - V(s_t)
        for (int t = 0; t < T-1; t++) {
            deltas[t] = rewards[t] + gamma * values[t+1] - values[t];
        }
        deltas[T-1] = rewards[T-1] - values[T-1]; // 最后一步无s_{T+1}，V(s_{T+1})=0

        // 反向计算GAE
        for (int t = T-1; t >= 0; t--) {
            gae_sum = deltas[t] + gamma * lambda * gae_sum;
            gae[t] = gae_sum;
        }
        // 优势函数归一化（稳定训练）
        double mean = accumulate(gae.begin(), gae.end(), 0.0) / T;
        double std = 0.0;
        for (double a : gae) {
            std += pow(a - mean, 2);
        }
        std = sqrt(std / T + 1e-8);
        for (double& a : gae) {
            a = (a - mean) / std;
        }
        return gae;
    }

    // 计算PPO总损失
    double compute_loss(const vector<vector<double>>& states, const vector<int>& actions, 
                       const vector<double>& old_probs, const vector<double>& advantages, 
                       const vector<double>& target_values) {
        int batch_size = states.size();
        double clip_loss = 0.0, vf_loss = 0.0, entropy_loss = 0.0;

        for (int i = 0; i < batch_size; i++) {
            PolicyOutput out = policy_forward(states[i], theta);
            double new_prob = out.action_probs[actions[i]];
            double old_prob = old_probs[i];
            if (old_prob < 1e-12) old_prob = 1e-12;

            // 1. 裁剪损失L^{CLIP}
            double r_t = new_prob / old_prob;
            double clip_r_t = clamp(r_t, 1 - eps, 1 + eps);
            clip_loss += min(r_t * advantages[i], clip_r_t * advantages[i]);

            // 2. 价值函数损失L^{VF}（MSE）
            vf_loss += pow(out.value - target_values[i], 2);

            // 3. 熵损失L^S（鼓励探索，取负后加入总损失）
            double entropy = 0.0;
            for (double p : out.action_probs) {
                if (p < 1e-12) continue;
                entropy -= p * log2(p);
            }
            entropy_loss += entropy;
        }

        // 平均损失并组合总损失（注意符号：裁剪损失最大化→取负后最小化，熵损失最大化→取负）
        clip_loss = -clip_loss / batch_size; // 原目标是最大化，转为最小化需取负
        vf_loss = c1 * vf_loss / batch_size;
        entropy_loss = -c2 * entropy_loss / batch_size; // 熵越大越好，损失中为负权重
        return clip_loss + vf_loss + entropy_loss;
    }

    // 策略更新（简化的梯度下降，实际需用Adam等优化器）
    void update(const vector<vector<double>>& states, const vector<int>& actions, 
                const vector<double>& old_probs, const vector<double>& advantages, 
                const vector<double>& target_values) {
        // 保存旧策略参数
        theta_old = theta;

        // 多次更新策略
        for (int iter = 0; iter < num_updates; iter++) {
            // 简化：计算损失对参数的梯度（这里用数值梯度模拟，实际用自动微分）
            vector<double> grad(theta.size(), 0.0);
            double eps_grad = 1e-5;
            double loss_orig = compute_loss(states, actions, old_probs, advantages, target_values);

            for (int i = 0; i < theta.size(); i++) {
                // 数值梯度：f(x+eps) - f(x-eps) / (2*eps)
                theta[i] += eps_grad;
                double loss_plus = compute_loss(states, actions, old_probs, advantages, target_values);
                theta[i] -= 2 * eps_grad;
                double loss_minus = compute_loss(states, actions, old_probs, advantages, target_values);
                theta[i] += eps_grad; // 恢复原参数

                grad[i] = (loss_plus - loss_minus) / (2 * eps_grad);
            }

            // 梯度下降更新参数
            for (int i = 0; i < theta.size(); i++) {
                theta[i] -= lr * grad[i];
            }
        }
    }

    // 数据收集（用旧策略收集轨迹）
    void collect_trajectories(vector<vector<double>>& states, vector<int>& actions, 
                             vector<double>& rewards, vector<double>& old_probs, vector<double>& values) {
        // 简化：假设环境交互得到轨迹，这里仅模拟数据（实际需结合环境step函数）
        int T = 100; // 轨迹长度
        states.resize(T, vector<double>(state_dim, 0.0));
        actions.resize(T, 0);
        rewards.resize(T, 0.0);
        old_probs.resize(T, 0.0);
        values.resize(T, 0.0);

        for (int t = 0; t < T; t++) {
            // 模拟状态（如麻将AI的手牌、场面信息）
            for (int i = 0; i < state_dim; i++) {
                states[t][i] = (rand() % 100) / 100.0; // 0~1随机值
            }
            // 旧策略预测
            PolicyOutput out = policy_forward(states[t], theta_old);
            // 采样动作（根据概率分布）
            double rand_val = (rand() % 1000) / 1000.0;
            double sum_prob = 0.0;
            int action = 0;
            for (int a = 0; a < action_dim; a++) {
                sum_prob += out.action_probs[a];
                if (rand_val <= sum_prob) {
                    action = a;
                    break;
                }
            }
            actions[t] = action;
            old_probs[t] = out.action_probs[action];
            values[t] = out.value;
            // 模拟奖励（如麻将的得分）
            rewards[t] = (rand() % 20 - 10) / 10.0; // -1~1随机奖励
        }
    }

    // 完整训练步骤
    void train_step() {
        // 1. 收集轨迹
        vector<vector<double>> states;
        vector<int> actions;
        vector<double> rewards, old_probs, values;
        collect_trajectories(states, actions, rewards, old_probs, values);

        // 2. 计算优势函数和目标价值（V_target = A_t + V(s_t)）
        vector<double> advantages = compute_gae(rewards, values);
        vector<double> target_values(advantages.size());
        for (int i = 0; i < advantages.size(); i++) {
            target_values[i] = advantages[i] + values[i];
        }

        // 3. 更新策略
        update(states, actions, old_probs, advantages, target_values);
    }
};
```

（注：PPO在麻将AI项目中成功处理了非完美信息博弈的策略学习，通过12小时强化学习训练达到竞争性水平，其核心优势是实现简单、样本效率高、训练稳定，是大模型RLHF中策略优化的常用算法）





### 8\. DPO（Direct Preference Optimization）

#### 思路

21. 基于文档中DPO的原理（🔶1\-81、🔶1\-100、🔶1\-280到🔶1\-282），DPO是RLHF的简化版，无需显式训练奖励模型，直接从人类偏好数据（偏好回答\\\(y\_w\\\)、非偏好回答\\\(y\_l\\\)）优化策略。

22. 核心公式：

    - DPO损失函数：\\\(L\(\\theta\) = \-\\hat\{\\mathbb\{E\}\}\_\{\(x,y\_w,y\_l\)\}\\left\[ \\log\\left\( \\sigma\\left\( \\beta \\cdot \\log \\frac\{\\pi\_\\theta\(y\_w\|x\)\}\{\\pi\_\{ref\}\(y\_w\|x\)\} \- \\beta \\cdot \\log \\frac\{\\pi\_\\theta\(y\_l\|x\)\}\{\\pi\_\{ref\}\(y\_l\|x\)\} \\right\) \\right\) \\right\]\\\)，其中\\\(\\pi\_\{ref\}\\\)为参考策略（通常是SFT模型），\\\(\\beta\\\)为温度参数（控制策略与参考策略的偏离程度），\\\(\\sigma\\\)为sigmoid函数。

23. 步骤：

    - 准备偏好数据：每个样本包含输入\\\(x\\\)、人类偏好的回答\\\(y\_w\\\)、非偏好的回答\\\(y\_l\\\)。

    - 固定参考策略\\\(\\pi\_\{ref\}\\\)，优化目标策略\\\(\\pi\_\\theta\\\)，最小化DPO损失（使偏好回答的对数优势大于非偏好回答）。

    - 无需采样轨迹，直接用偏好数据更新，简化RLHF流程。

#### C\+\+代码（核心逻辑）

```C++
#include <vector>
#include <cmath>
#include <algorithm>
using namespace std;

// 文本生成模型的输出（token序列的对数概率）
double get_log_prob(const vector<int>& tokens, const vector<double>& params, int vocab_size) {
    // 简化：假设params为语言模型参数，这里用随机对数概率模拟（实际需模型前向传播）
    double log_prob = 0.0;
    for (int token : tokens) {
        // 模拟token的对数概率（-5~0，概率0.0067~1）
        log_prob += (rand() % 500) / 100.0 - 5.0;
    }
    return log_prob;
}

// DPO核心类
struct DPO {
    int vocab_size; // 词表大小
    double beta; // 温度参数（控制偏离程度，通常0.1~1.0）
    double lr; // 学习率
    vector<double> theta; // 目标策略参数（如语言模型权重）
    vector<double> theta_ref; // 参考策略参数（通常为SFT模型）

    DPO(int vocab_size, double beta = 0.5, double lr = 1e-5) {
        this->vocab_size = vocab_size;
        this->beta = beta;
        this->lr = lr;
        // 初始化参数（简化为向量，实际为语言模型权重）
        theta.resize(10000, 0.01); // 假设模型参数维度为10000
        theta_ref = theta; // 初始参考策略与目标策略相同（后续可替换为SFT模型）
    }

    // Sigmoid函数（数值稳定版）
    double sigmoid(double x) {
        if (x >= 0) {
            return 1.0 / (1.0 + exp(-x));
        } else {
            return exp(x) / (1.0 + exp(x));
        }
    }

    // 计算单个偏好样本的DPO损失
    double dpo_sample_loss(const vector<int>& x_tokens, const vector<int>& y_w_tokens, 
                          const vector<int>& y_l_tokens) {
        // 1. 计算目标策略的对数概率：log π_θ(y|x)
        double log_p_theta_yw = get_log_prob(y_w_tokens, theta, vocab_size);
        double log_p_theta_yl = get_log_prob(y_l_tokens, theta, vocab_size);

        // 2. 计算参考策略的对数概率：log π_ref(y|x)
        double log_p_ref_yw = get_log_prob(y_w_tokens, theta_ref, vocab_size);
        double log_p_ref_yl = get_log_prob(y_l_tokens, theta_ref, vocab_size);

        // 3. 计算优势项：β·(log π_θ(y_w|x)/π_ref(y_w|x) - log π_θ(y_l|x)/π_ref(y_l|x))
        double adv = beta * ((log_p_theta_yw - log_p_ref_yw) - (log_p_theta_yl - log_p_ref_yl));

        // 4. DPO损失：-log(sigmoid(adv))
        double loss = -log(sigmoid(adv) + 1e-12); // 加1e-12避免log(0)
        return loss;
    }

    // 计算批量DPO损失
    double compute_batch_loss(const vector<vector<int>>& x_tokens_list, 
                             const vector<vector<int>>& y_w_tokens_list, 
                             const vector<vector<int>>& y_l_tokens_list) {
        int batch_size = x_tokens_list.size();
        double total_loss = 0.0;
        for (int i = 0; i < batch_size; i++) {
            total_loss += dpo_sample_loss(x_tokens_list[i], y_w_tokens_list[i], y_l_tokens_list[i]);
        }
        return total_loss / batch_size; // 批量平均
    }

    // DPO策略更新（简化的梯度下降）
    void update(const vector<vector<int>>& x_tokens_list, 
               const vector<vector<int>>& y_w_tokens_list, 
               const vector<vector<int>>& y_l_tokens_list) {
        // 数值梯度计算（实际用自动微分框架如PyTorch/TensorFlow）
        vector<double> grad(theta.size(), 0.0);
        double eps_grad = 1e-6;
        double loss_orig = compute_batch_loss(x_tokens_list, y_w_tokens_list, y_l_tokens_list);

        for (int i = 0; i < theta.size(); i++) {
            // 数值梯度：f(x+eps) - f(x-eps) / (2*eps)
            theta[i] += eps_grad;
            double loss_plus = compute_batch_loss(x_tokens_list, y_w_tokens_list, y_l_tokens_list);
            theta[i] -= 2 * eps_grad;
            double loss_minus = compute_batch_loss(x_tokens_list, y_w_tokens_list, y_l_tokens_list);
            theta[i] += eps_grad; // 恢复原参数

            grad[i] = (loss_plus - loss_minus) / (2 * eps_grad);
        }

        // 梯度下降更新参数
        for (int i = 0; i < theta.size(); i++) {
            theta[i] -= lr * grad[i];
        }
    }

    // 准备偏好数据（模拟：输入x、偏好回答y_w、非偏好回答y_l的token序列）
    void prepare_preference_data(vector<vector<int>>& x_tokens_list, 
                                vector<vector<int>>& y_w_tokens_list, 
                                vector<vector<int>>& y_l_tokens_list, 
                                int batch_size = 32, int seq_len = 50) {
        x_tokens_list.resize(batch_size, vector<int>(seq_len));
        y_w_tokens_list.resize(batch_size, vector<int>(seq_len));
        y_l_tokens_list.resize(batch_size, vector<int>(seq_len));

        for (int i = 0; i < batch_size; i++) {
            // 模拟输入x的token序列（0~vocab_size-1）
            for (int j = 0; j < seq_len; j++) {
                x_tokens_list[i][j] = rand() % vocab_size;
            }
            // 模拟偏好回答y_w（假设与x语义更匹配，token序列略有不同）
            for (int j = 0; j < seq_len; j++) {
                y_w_tokens_list[i][j] = (x_tokens_list[i][j] + rand() % 3 - 1 + vocab_size) % vocab_size;
            }
            // 模拟非偏好回答y_l（与x语义匹配度低，token序列差异更大）
            for (int j = 0; j < seq_len; j++) {
                y_l_tokens_list[i][j] = (x_tokens_list[i][j] + rand() % 10 - 5 + vocab_size) % vocab_size;
            }
        }
    }

    // 完整DPO训练步骤
    void train_step(int batch_size = 32) {
        // 1. 准备偏好数据
        vector<vector<int>> x_tokens_list, y_w_tokens_list, y_l_tokens_list;
        prepare_preference_data(x_tokens_list, y_w_tokens_list, y_l_tokens_list, batch_size);

        // 2. 计算损失并更新策略
        update(x_tokens_list, y_w_tokens_list, y_l_tokens_list);

        // 3. （可选）监控损失变化
        double current_loss = compute_batch_loss(x_tokens_list, y_w_tokens_list, y_l_tokens_list);
        cout << "Current DPO Loss: " << current_loss << endl;
    }
};
```

（注：DPO相比传统RLHF（PPO\+奖励模型），省去了奖励模型训练和轨迹采样步骤，计算成本更低，且在大模型偏好对齐任务中表现出与RLHF相当的效果，是当前大模型对齐的主流方法之一🔶1\-282、）
