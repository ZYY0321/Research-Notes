# 怎么把大表示例放进 Testing-Survey

这次云端 Agent 挂在 Research-Notes 上，所以写不了 Testing-Survey。你这边环境列表里已经有独立的 `ZYY0321/Testing-Survey`，用下面任一方式即可。

---

## 方式 A：本地 Cursor（推荐）

### 1. 把文件拷到本地

如果本机还没有 Research-Notes：

```bash
git clone https://github.com/ZYY0321/Research-Notes.git
cd Research-Notes
git checkout cursor/user-log-followup-0ef9
# 或者等 PR #2 合并后直接用 main
```

要拷的文件在：

```text
Research-Notes/for-testing-survey/examples/
  README.md
  llm-testing-table.md
  field-table.md
```

### 2. 打开 Testing-Survey，粘贴下面的提示词

在本机 Cursor 打开 `ZYY0321/Testing-Survey` 仓库，新建对话，把「提示词」整段贴进去。

---

## 方式 B：用 Testing-Survey 的云端 Agent

1. 打开 Cursor Cloud Agents：https://cursor.com/agents  
2. 点 **New Run**，仓库选 **ZYY0321/Testing-Survey**（不要选 Research-Notes）  
3. 把下面「提示词」贴进去跑  

这样 Agent 会挂在 Testing-Survey 环境上，就有写权限。

---

## 方式 C：网页上传（最快，不用 Agent）

1. 打开 https://github.com/ZYY0321/Testing-Survey  
2. 点 Add file → Upload files  
3. 建目录 `examples/`，上传三个文件：  
   - `README.md`  
   - `llm-testing-table.md`  
   - `field-table.md`  
4. 在 `README.md` 首页第二段「论文见 catalog…」那句后面加一句：  

```markdown
大表的写法示例和填写要求见 [examples/](examples/README.md)。
```

---

````text
请把 Research-Notes 里准备好的两张大表示例放进这个 Testing-Survey 仓库，开一个 PR，不要直接改 main。

我维护两个仓库：
- ZYY0321/Research-Notes：个人研究笔记，分支 cursor/user-log-followup-0ef9（或已合并的 main）里有目录 for-testing-survey/examples/

- 做完把 PR 链接发我。

如果拉不到 Research-Notes，告诉我，我改用网页上传。
````
