## 一段话介绍
WildAWM 不用闭源模型写环境。它先虚构人物和多日活动，再让编码代理把网站、工具服务和本地文件一天天叠进一台可重置的电脑；网站画面借用 15 个 WebHarbor 镜像。任务必须同时用到 GUI、MCP 工具和命令行。每道题配一个可执行验证器，成功定义为 N 条二元条件全部通过。题要经过执行：至少有一个代理能做完，不能所有代理都会，两个裁判要一致，还要用假的结果反馈去探验证器会不会迎合。341 道题里 100 道做 SFT、208 道做 RL、33 道留作域内验证。两个 Qwen 模型只在这些世界里训练，八个外部榜（网页、claw、电脑使用）都涨。作者同时写明，涨幅集中在教师模型够得着的难度上，最难的四分之一没有明显增益。

## 动机
作者认为环境供给成了瓶颈：真人数据贵，真实系统难重置，探索动作还有副作用。已有合成工作往往只做浏览器、只做工具或只做终端，而且依赖闭源模型。

原文（第 1 节）：“Synthesized tasks should be solvable under the synthesized environment state, sufficiently challenging to provide useful learning signals, and paired with reliable verifiers … all without relying on simplistic assumptions such as ‘a frontier model is necessarily correct.’”

## 方法（或资源构成）
世界是人物 c 在第 d 天之后的电脑状态，记为 W(c,d)，用来初始化和重置。生成器是跑在 OpenCode 里的 GLM-5.2。同一天的状态要两次独立重放一致，服务还得健康，另一个编码代理再对照日程查一致性。任务生成时同时写出说明、验证器、评分量和提示。提示只用于估计「有提示和无提示的差距」，不给求解的学生模型当训练输入里的答案（求解门用提示来证明存在一条可执行路径）。验证器读初始状态、终态和最终回答。五道门没过的候选退回生成器，最多改两轮。

训练用 OpenCode，带 GUI 和 MCP 工具。奖励里有格式惩罚和清单部分分。作者比较了去掉这些项的消融（表 8）。

具体例子（表 3 的案例）：音视频技师要在安装队开工前锁定一批设备。批准在前一天的聊天里，规格在本地文件里。代理先用 MCP 看消息，再用命令行合并表格，然后必须看商品图才能在两个规格相同的候选里选对，最后回到命令行和 MCP。单界面做不完。

## 实验
- 想回答：开源模型能否造出可解、够难、验证器站得住的跨界面题；只在这些题上训练是否提升外部榜。
- 数据：36 个人物、640 个世界状态（表 2）。341 道题。域内验证 33 道。外部八个榜：Online-Mind2Web、WebArena、QwenClawBench、ClawEval、CUA-Gym、OSWorld-Verified、OSWorld 2.0、Agents’ Last Exam。合成期平均成功率 21.3%（第 3.2 节）。
- 主结果：表 5。35B-A3B：平均 42.84→53.42。其中 OSWorld-Verified 33.16→49.22，WebArena 53.54→67.26。4B：平均 21.83→30.04。文中写 GPT-6-Astra 在他们的题上 pass@1 大约 60%，八次尝试后仍有 27.3% 的题失败（第 5.3 节，图 4）。验证器与多种代理裁判：和多数票一致率 0.95，Cohen’s κ 0.90，样本是 100 条随机 rollout。HTML 里这张表的标题是 Table 6；正文有一处写成 Table 7。我按表题旁的数字引用，表号冲突见核对说明。去掉反事实探测后，4B 的 SFT 在域内验证从 21.59 降到 13.64（消融表，HTML 表题 Table 7）。
- 能支持的：这套合成题对这两个 Qwen、这八个榜有平均增益。支持不了的：增益来自超越教师的新策略。第 5.4 节写，最难四分位（教师也觉得难）没有清晰增益；跨界面切换率主要在 SFT 教师轨迹之后出现（18.4%→24.7%），不用教师轨迹的 RL 反而降到 15.7% 左右。

## 局限
- 作者没有单列 Limitations。结论只复述了贡献。附录式的限制要靠行为分析自己读出来：增益不超过教师够得着的难度；验证器可靠性是相对其他模型裁判，不是相对人。
- 我看到的：验证器和任务由同一类模型写成。五道门能拦住「所有模型都会」的送分题，也能用假反馈探迎合，但 0.95 的一致率是模型和模型比。若几个裁判共享同一种盲区，一致只是共同出错。清单全过才算成功，部分分仍可能让模型专做容易核的条目。表 5 的外部榜使用 OpenCode 脚手架；作者注明 CUA-Gym、OpenForgeRL 的一些对照数字来自原论文、脚手架不同，只能参考。合成世界的网站是镜像加手写后端，和真实网站的权限、登录、副作用不是同一分布，所以 OSWorld 上的涨分不能直接说成学会了那些真实应用。

## 品味判断
1. 问题来自环境工业的一个具体缺口：个人电脑上的任务跨界面，而合成管道按界面拆开。质检三条（可解、够难、验证器可靠）是先写下来再做门，不是看完结果再解释。有开源编码模型和容器的团队可以缩规模做；341 道和八榜是资源题。
2. 最能说服人的是表 5 的同基座、八榜全涨，配上第 5.4 节那句最难四分位没有增益。后者防止把平均分读成「开源模型已经会自我进化超过老师」。
3. 可模仿的实验：每道合成题至少用两个不同家族的代理执行。保留「有人做成、不是人人做成」。另做一次反事实：告诉裁判一个故意错误的结论，看验证器或模型裁判改不改口。训练后按「教师是否能解」把测试题分层，分别报增益。
4. SPADE 训练的是出题器本身，环境是 Gym 代码，不是这台带像素 GUI 的电脑。GUI-Genesis 重建的是轻量网页。WildAWM 没有和「同一计算预算下直接在 OSWorld 上在线 RL」比，所以外部涨分还不能说合成世界比真环境更省。

## 和 CUA 评测 / 换路鲁棒性的关系（公开层面）
跨界面任务的成功不能由单一 GUI 终屏定义。他们强制 GUI、命令行、工具都走到，并用状态验证器而不是截图。换路评测可以借用「反事实探测」：给裁判一个错误结论，看它是否仍维持原判。
