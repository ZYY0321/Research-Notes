# 主张台账：我们到底发现了什么（宁少不多）

判断标准：①能说清是什么机制；②能用已有数据复算；③能推出一个可被推翻的预测。只满足「跑出一个数」的不算。

挂回主线：**观察通道不完备 + 动作静默失败 → 先用阳性对照 / 独立通道确认「状态读对了、动作生效了」再下结论。**

## H2 否定证据不携带信息，肯定证据携带（最该先讲）

- 主张：在观察通道不完备的系统里，「滑动后框没变」这种阴性结果必须配同视口阳性对照才有信息量；肯定证据可信，否定证据不可信。
- 证据【存档重判，138 框真机滑动】：滑后「框里变了→判能滑出」69 次错 3（4%）；滑后「框里没变→判真截断」37 次错 11（30%）。差约 7.5 倍。
- 机制：学弟 AB 分析把「没动」拆成四因——候选本无更多内容 / 手势没生效、方向错、到边界 / 滑的是外层容器 / 候选变了或消失。
- 可被推翻：给每次滑动加同视口参照物重判，「没变」的误判率应明显低于 30%。
- 弱点：分子只有 11，n 小，汇报时主动报分母。
- 今日待做：把 37 次「没变」逐条归入四因（见 `experiments/E-今日_否定证据四因分解.md`）。

## H1 观察通道的失效可枚举；能下结论时几乎不出错

- 主张：布局树不是「不可靠」，是**可靠性不均匀，且不均匀可以按机制穷举**。
- 证据【存档重判，开发期，判据看过第一轮结果后改过两处】：179 个去重框里布局树能下结论的 103 个（58%），103/103 对；真截断 47 个里 21 个落在盲区。盲区机制：子组件自裁切不导出 / 省略号与自裁切布局树同构 / 被兄弟组件盖住 / 行框与字形不一致 / 懒加载项不在树里 / 翻页容器当前页不导出。
- 旁证【规则扫描，未对照截图】：大众点评 794 屏 212,460 节点，24% 被父容器裁掉，5.4% 标可见但透明度 0。macOS 7 应用 45 窗口，画面对得上比例 Blender 2% → VS Code 88%（分母由视觉模型数，只看排序）。
- 可被推翻：换 App 集合、按机制重新分类，盲区占比应稳定在 40% 上下，不需要新增机制类别。
- 弱点：103/103 不是留出集。判据没有拟合参数，所以「留一重算」意义有限。**今日按 App 拆开后发现**（`evidence/恒定关系按App拆分.md`）：判截断 26 个里 18 个来自构造的样例 App，真实商业 App 只有 8 个；商业 App 真截断 23 个里 15 个（65%）在盲区，12306 与滴滴整类沉默。所以这条的准确说法是「能说话时不错，而真截断恰恰集中在它沉默的地方」。还要补的是新 App 留出集。
- **禁止写法**：「静态准确率 100%」。

## H3 页面同一性不能用布局指纹定义（路线级天花板）

- 主张：按布局模板认页面，同时过合与过拆；这不是调参问题。
- 证据：唯品会 35 个模板只对上人工 spec 46 页里的 10 页【真值，1 个 App】；10 个模板各混几个功能，15 个功能各被拆成多个模板（购物车、商品详情各拆 6 个）。去重实验以 GPT 命名的 27 个功能 / 181 步为参照【模型标签】：阈值 0.4–0.75 调和分数停在 72–77%；换信号也不破（结构 73、文字 74、dHash 54–64、结构+文字 76）。
- 可被推翻：第 2、3 个 App 重复阈值扫描，若某 App 能到 90% 以上，则是唯品会特例。`mobilegym-mock` 里已有 9 个应用的路由状态真值，不用真机即可算。
- 弱点：只有 1 个 App 有人工 spec 真值。
- 附：文献里「覆盖率」单位互不相同（Activity 36.94% / 方法覆盖 +26% / 路由 / 我们的 spec 页面），不可直接比。

## H4 失败的主要形态是「做了但没生效，且没人发现」

- 主张：智能体与测试工具的主要失败不是「不会做」，是动作返回成功与状态真实改变之间没有契约；以及模型很少主动披露自己用了旁路。
- 证据【规则扫描，无模型调用】：去重 2,531 条轨迹 / 16,404 个受阻决策点；M01「动作静默无效」6,731（约 41%），目标不可见或不可达 3,567，输入被吞或被改 2,981。规则口径下得分 1 的「写文件/控制类」路线 1,147 条，最终答复里提及用了脚本或命令行的仅 49 条（关键词判定）。
- 旁证【单例】：LLMDroid 点底栏前后都是教学浮层、记成测过；HapTest 滚动步长 60px 而容器只能滚 38px 直接退出；FuncDroid 点「京东超市」前后都是首页；轨迹收集里 agent 谎报到达。
- 可被推翻：换后端 M01 绝对比例会变，但「返回成功≠状态改变」的契约缺失不会消失。
- 弱点：M01 比例依赖规则定义，必须写「按我们的规则口径」；披露为关键词判定会漏判。
- **今天对导师不要主讲训练与规模**；只作为「失败形态」证据。
