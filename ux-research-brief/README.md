# ux-research-brief

GUI 显示缺陷检测研究的**口径与叙事仓库**：给学弟共享，也给不能做实验的远程 Claude Code 当工作底稿。不含大数据，不含密钥，不含华为原始数据（见 `NEVER.md`）。

## 先读这三个

1. `STATE.md`：现在主攻什么、这周卡在哪、下一步。
2. `CLAIMS.md`：目前能站住的 4 条发现（H1–H4），各自的证据、弱点、可被推翻的预测。
3. `numbers.csv`：全部数字的唯一来源，带分母、口径、等级、来源路径、禁止写法。

Claude Code 另读 `CLAUDE.md`。

## 目录

| 目录 | 放什么 |
|---|---|
| `evidence/` | 某个数字或结论的证据页、口径矛盾清单、今日离线统计结果 |
| `data_small/` | 能进 git 的小数据：标注 CSV、抽样 JSON、少量样例图与布局树 |
| `experiments/` | 实验卡：设计 / 变量 / 指标 / 放弃条件 / 状态 |
| `related/` | 文献划界、8 个工具复现报告摘要（来自 Testing-Survey）；每张表一行说明覆盖范围 |
| `reports/` | 按日期的汇报稿；稿里数字尽量写 `numbers.csv` 的 id |
| `handoff/` | 给学弟 / 合作方的当前有效任务，旧的进 `handoff/archive/` |

## 与其他仓库的关系

- `UX-Agent`（本地，45GB）：工程与原始数据，本仓只用路径引用。
- `Testing-Survey`（与学弟共享）：任务派发与学弟自己的复现工作区；复现报告摘要搬进本仓 `related/`。
- 个人仓不相关，不引用。

## 证据等级

真值 / 规则扫描 / 存档重判 / 模型标签 / 单例。不许升级。
