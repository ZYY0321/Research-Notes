# 新页面前景留出验证（2026-11-22）

算法固定为f37cc58中的foreground实现，先抽样、保存不含预测的图片和目视框，再运行测量；本轮没有修改像素算法或阈值。目录整理只改变导入路径。算法文件SHA已核对与抽样前相同。

## 新样本来自哪里

来自此前真实15例没有使用的6个页面：云音汇（开源CloudMusic-HarmonyOSNext）的“我的、设置、缓存”，以及MultiShopping的商品详情、规格弹窗、详情评价区域。云音汇是新增应用；商城属于已有应用的新页面。共26个不重复文字目标，均排除了旧15例文字及跨页面重复文字。不是新增26款应用，也没有声称代表所有商业软件。

使用已有正常基线的原始snapshot图片与UI树，不使用报告中的som标注图。历史截图实际编码是JPEG，裁片保存PNG只为便于阅读，没有消除原有压缩痕迹。每份原截图SHA、节点框、路径都在[samples.json](samples.json)。正常基线表示尚未注入本轮修改，画面原有覆盖或不完整情况仍保留。

抽样规则沿用可见Text、bounds=origBounds、宽20—1000px、高15—150px；排除顶部/底部系统区域。每页按树顺序取首尾及中间等间隔的最多5项，缓存页在去重后只有1项。该规则不覆盖超宽或很高的文字区域。

先保存[盲标框](blind-labels.json)，再测量。助手目视标注使用4px容差，没有独立人类逐像素真值。21号“已选”被可见覆盖物穿过，事先标为无法可靠标注，保留在26例中但不进入25例框误差分母；4号原文字已有部分截断，只标当前可见字形，不把它当完整文本。

## 固定算法结果

|调用方式|可评分|返回测量|与目视框差≤4px|超出4px|
|---|---:|---:|---:|---:|
|默认foreground|25|25|20|5|
|已有exclude_boundary=True选项|25|25|22|3|

另1项不可评分的“已选”，两种方式均返回unsupported_background。默认模式在可评分样本中的粗粒度符合率为20/25（80%）；边界排除模式为22/25（88%）。两种方式是预先存在的调用选项，这里分别报告，不对每个样本事后择优拼成一个成绩。主规划只在识别到相应圆角文字背景时选择边界排除，并非全局启用。

默认模式的5项不符合中，2项差5/6px，接近目视标注精度边界；另3项明显误框：灰色“1/1”圆角标签、红色“立即购买”、带边框的“查看更多评价”，误差分别27/34/59px。后两项的边界排除能改善到2px；“1/1”仍差6px。云音汇页尾两行文字靠近组件边缘，边界排除的误差反而由6px增至14px，说明该选项也可能移除贴边笔画。

这些新结果支持普通文字、小字号、粗体、彩色文字及多行文字的一部分迁移效果，同时暴露真实组件背景和边框仍有误测。未按这批结果继续调阈值，避免把留出测试变成又一轮调参样本。

## 有限修复与后续回归（2026-11-23）

根据用户要求，只修复原因明确、不会依靠样本特例的部分：exclude_boundary原先删除一切碰边的连通前景，现在要求连通区域至少接触两条边。这样保留圆角角落和环绕边框的剔除，同时保留仅碰一边的笔画。默认未启用边界排除的调用不受影响。

云音汇页尾文字的边界排除误差从14px降至6px，未通过4px标准，继续保留失败；“查看更多评价”边框的2px结果保持。“1/1”标签6px、评价标题5px未继续添加特例。启用边界排除的总体仍为22/25符合，改善的是对贴边文字的破坏程度，而非为了提高统计比例。

112个旧人工例的分组结果保持一致；旧真实15例仍由测试核验基本文字可测、插画拒绝。全量305项测试检查源码、规划、证据与新增边界行为。上述原始留出结果保持不变；本节使用同一批样本指导了修复，因此后续结果称为回归。见[修复后输出](after-boundary-fix.json)和[人工回归](synthetic-regression-after-fix.json)。
